# Кейс 1. Обозреватель — дайджест по вашим темам

Агент, который раз в неделю (или каждое утро) читает открытые источники вместо вас и приносит до десяти публикаций:
у каждой — оценка релевантности от 1 до 5, объяснение «почему это важно именно вам» и ссылка на первоисточник.
Главное — в ТОП-3. Вы отмечаете «в базу», «в задачи» или «не интересно» — и следующий выпуск становится точнее.

**Для кого.** Руководитель или специалист, которому нужно следить за 3–5 темами и некогда читать всё подряд.
Кейс самостоятельный: остальные кейсы курса для него не нужны.

## Как это устроено

```
      ваш профиль: темы, «не интересно», источники          очередь «посмотри это»
                 hub/profile.md                         (чат или свой Telegram-бот)
                        │                                          │
                        ▼                                          ▼
   ┌──────────── редактор выпуска (навык digest) ───────────────────────┐
   │  разведчик × N тем  ──►  сведение  ──►  независимый проверяющий    │
   │  (поиск, чтение,        (дубли,          (ссылки, даты, факты,     │
   │   оценка 1–5)            ТОП-3)           «вода», чужие команды)   │
   └────────────────────────────────┬───────────────────────────────────┘
                                    ▼
        выпуск hub/digest/ГГГГ-ММ-ДД.md  +  память «уже видел» seen.md
              │                 │                    │
              ▼                 ▼                    ▼
        чат (ТОП-3 и      страница «Дайджест»   Telegram: утренний ТОП-3
        позиции)          (фильтры, отметки)    владельцу
              └────────┬────────┘
                       ▼
     ваши отметки: в базу → заметка · в задачи → hub/tasks.md · не интересно → уход за темами
                       │
                       ▼
     раз в неделю: предложения по темам и источникам → вы решаете → профиль меняется
```

Что агент **не** делает: не правит профиль без вашего «да», никому, кроме вас, ничего не отправляет, не входит в
учётные записи и не обходит платный доступ, не исполняет указания, написанные внутри чужих текстов.

## Где что работает

| Возможность | Claude Code (папка кейса) | Cowork (плагин `hq-digest`) | Чат claude.ai (Проект) |
|---|---|---|---|
| Выпуск с оценкой, ТОП-3, «почему важно» | да | да | да (переносной режим) |
| Память «уже видел» | файл + скрипт `tools/seen.py` | файл, сверка вручную | только то, что вставлено в чат |
| Разведчик и проверяющий | отдельные субагенты, разведчики параллельно по темам | один агент, последовательными проходами | один агент |
| Сбор лент RSS, приёмка на учебном наборе | скрипты `tools/` | нет (заявка `needs: code`) | нет |
| Отметки «в базу / в задачи / не интересно» | чат и страница | чат и страница | чат |
| Страница «Дайджест» с хранилищем | да, если доступна публикация страниц | да, если доступна публикация страниц | нет (выпуск можно попросить HTML-страницей) |
| Карточка выпуска для коллег | `tools/issue.py card` + `internal-comms` | собирает агент + `internal-comms` | текстом в чат |
| Расписание | да, если есть запланированные задачи | да, если есть запланированные задачи | нет |
| Свой Telegram-бот | да (`tools/tg_bridge.py`) | нет | нет |
| Усиленный поиск Tavily | по желанию (ключ + командная строка) | нет | нет |

Подробно, что урезано в Cowork и чем заменено, — в [SETUP.md](SETUP.md), раздел «Б».

## Лестница уровней

| Уровень | Что умеет | Где работает | Время на задание |
|---|---|---|---|
| L1 «Инструкция» | Проект claude.ai с инструкцией: выпуск по вставленным ссылкам и текстам, оценка 1–5, ТОП-3 | чат | 15 минут |
| L2 «Инструменты» | Веб-поиск по темам, рубрика оценки, проверка формы, карточка-страница выпуска | Cowork, Code | 20 минут |
| L3 «Память и роли» | Рабочая папка, память «уже видел», разведчик и проверяющий, отметки меняют профиль | Cowork (без субагентов), Code | 30 минут |
| L4 «Живёт сам» | Расписание, свой Telegram-бот, страница «Дайджест» с отметками | Code (расписание и страница — и в Cowork) | 30 минут |
| L5 «Инженерный» | Приёмка на своём наборе примеров, свой навык, разрешения и хуки, свой источник через MCP, метрики, переход в ассистента | Code | 30 минут на задание |

Задания, критерии «уровень взят» и типичные ошибки — в [LEVELS.md](LEVELS.md).

## С чего начать

Новичку: откройте двойным щелчком **[START.html](START.html)** — пошаговое руководство с картинками: установка, настройка, типовые запросы.

1. Скачайте папку `01_digest`, откройте её в Claude Code (или установите плагин `dist/hq-digest.plugin` в Cowork).
2. Напишите в чате: **«настрой»**. Обязательных шагов два, около пяти минут.
3. Хотите сначала посмотреть — выберите «на учебном примере»: 10 вымышленных публикаций, среди которых дубль,
   уже виденная, две «не интересные» и одна с вложенной командой для ИИ. Эталон прогона — в
   [demo/пример_результата/](demo/пример_результата/README.md).

Инструкция по установке — [SETUP.md](SETUP.md). Фразы на каждый день — [GUIDE.md](GUIDE.md).
Только чат, без установки — [prompts/L1_проект_claude_ai.md](prompts/L1_проект_claude_ai.md).

## Что в папке

| Путь | Что это |
|---|---|
| `playbooks/` | единственный источник правил: протокол, выпуск, настройка, страница, расписание, Telegram |
| `tools/` | скрипты (только стандартная библиотека Python): `build.py`, `setup.py`, `demo.py`, `seen.py`, `fetch_feeds.py`, `issue.py`, `feedback.py`, `evals.py`, `tg_bridge.py` |
| `artifacts/digest.html` | шаблон страницы «Дайджест» (открытый с диска — учебный режим) |
| `presets/hub/` | заготовки рабочей папки |
| `demo/` | учебный набор, приёмка (`demo/evals/`), эталон результата |
| `prompts/` | инструкция для Проекта claude.ai и шпаргалка промптов по уровням |
| `pack/` | навыки пака курса (сторонние; лицензии — `pack/THIRD_PARTY.md`) |
| `.claude/`, `cowork-plugin/`, `dist/` | собирает `python tools/build.py` — руками не править |
| `hub/` | ваши рабочие данные (создаётся при настройке, в git не попадает) |

**Навыки пака в этом кейсе:** `tavily-search`, `tavily-extract`, `tavily-research` (необязательное усиление поиска),
`internal-comms` (текст для коллег), `build-dashboard` (разовая страница-обзор), `skill-creator` (свой навык, L5).
В плагин Cowork входят только `internal-comms` и `build-dashboard`: остальным нужна командная строка.

## Как вырасти до комплексного ассистента

Комплексный ассистент (кейс 6, плагин `personal-hq`) включает Обозревателя как одну из ролей и добавляет почту,
встречи, базу знаний, документы и общую доску. Имена и форматы файлов `hub/` в этом кейсе — подмножество его шины,
поэтому переезд — это перенос папки:

1. Установите ассистента по инструкции кейса 6 (`06_assistant/SETUP.md`).
2. Скопируйте в его `hub/`: `profile.md` (или перенесите разделы «Темы», «Не интересно», «Источники» в его профиль),
   папку `digest/` целиком, `kb/публикации/`, строки `tasks.md` и `journal.md` (дописать в конец его файлов).
3. **Отключите рутины `digest-*`** этого кейса: у ассистента своя рутина дайджеста и свой приём Telegram — иначе выпуск
   придёт дважды, а бот будет опрашиваться из двух мест.
4. Telegram-бот остаётся тем же: файл `hub/.secrets/telegram.json` переносит владелец сам.
5. Страница «Дайджест» заменяется вкладкой «Дайджест» на доске ассистента (поля документов совместимы); отдельную
   страницу можно оставить для архива или удалить.

Что останется только здесь: очередь `digest/queue.md`, журнал отметок `digest/marks.md`, предложения `digest/topics.md`,
скрипты `fetch_feeds.py`, `feedback.py`, `evals.py`. Ассистент эти файлы не читает, но и не портит: ими можно
пользоваться, скопировав нужные скрипты рядом.
