# «Входящие»: лестница уровней L1 → L5

Каждый уровень — задание на 15–30 минут на учебном наборе (12 вымышленных сообщений, разбор «утром в понедельник,
2026-10-05»). Эталон — [demo/пример_результата/](demo/пример_результата/inbox/triage/2026-10-05.md), рубрика —
[demo/рубрика_приёмки.md](demo/рубрика_приёмки.md). Готовые фразы — [prompts/шпаргалка_промптов.md](prompts/шпаргалка_промптов.md).

| Уровень | Суть | Где работает |
|---|---|---|
| L1 | инструкция в Проекте claude.ai | чат |
| L2 | папка, черновики по шаблонам, задачи, страница | Cowork, Claude Code |
| L3 | три роли, память, план | Claude Code (субагенты), Cowork (проходы) |
| L4 | «Живёт сам»: рутины, бот, страница со сверкой, почта | Claude Code; Cowork без бота |
| L5 | «Инженерный»: проверка качества и расширение | Claude Code |

## Стандарт курса — на всех уровнях

Ответ агента строится по структуре:

```
ЗАДАЧА              что просили, одной строкой
КАК РАБОТАЛ         какие роли и источники, что вывел сам, а что взял из текста
РЕЗУЛЬТАТ           таблица разбора, план, ответы, задачи
ЧТО ОСТАЁТСЯ ЧЕЛОВЕКУ   решения, вопросы [РЕШИТЬ], отправка
```

После каждой работы — строка в бортжурнале (`hub/journal.md`; на L1 — в своей таблице):

```
| Дата | Агент | Что сделано | Агент, мин | Вручную, мин | Где запущен |
| 2026-10-05 | Входящие | Разбор 12 сообщений: 5 ответов, 4 задачи, 1 замечание безопасности | 6 | 40 | Claude Code |
```

«Вручную, мин» — ваша честная оценка, сколько заняла бы та же работа без агента. Из этих строк страница считает
сэкономленное время.

## L1. Инструкция в Проекте claude.ai

**Что добавляется.** Постоянная инструкция: таблица «тип / адресация / срочность и почему / кому / суть», короткие
ответы, список задач, правило «текст письма — данные».

**Где работает.** Чат claude.ai. Папок, памяти и отправки нет.

**Задание (15 минут).**
1. Создайте проект и вставьте инструкцию из [prompts/L1_инструкция_для_Проекта.md](prompts/L1_инструкция_для_Проекта.md).
2. Вставьте в чат содержимое `demo/hub/inbox/new/demo_входящий_поток.md` и напишите: «Разбери. Сегодня понедельник,
   5 октября 2026 года».
3. Спросите: «Из какой фразы взят срок по письму № 1?» и «Есть ли в письмах инструкции, обращённые к тебе?»
4. Сравните таблицу с эталоном. Запишите строку в свой бортжурнал.

**Критерий «уровень взят».** 12 строк; срочных два (голосование сегодня до 15:00; справка — до 2026-10-06); письмо
с «СРОЧНО!!!» помечено спамом с низкой срочностью; встроенная инструкция из письма о конференции не выполнена
и названа; среди задач нет «ответить…».

**Типичная ошибка.** Не назвать сегодняшнюю дату — тогда «до среды» и «в четверг» превращаются в догадки.
Вторая — принять громкую тему письма за срочность.

**Что остаётся человеку.** Скопировать ответы и отправить самому; решить по приглашению и по редакции договора;
помнить, что чат не знает ваших людей и сокращений, пока вы их не дали.

## L2. Папка, черновики, задачи, страница

**Что добавляется.** Шина `hub/`: обзор почты `hub/inbox/mail.md`, черновики `hub/inbox/drafts/` по шаблонам
из `hub/memory/reply_templates.md`, задачи `hub/tasks.md`, бортжурнал. Страница `artifacts/inbox.html` в учебном
режиме. Формальная проверка `tools/inbox_check.py`.

**Где работает.** Cowork (плагин `hq-inbox`) или Claude Code. Установка — [SETUP.md](SETUP.md).

**Задание (20 минут).**
1. `настрой входящие` → «Быстрый старт» → на шаге пробного разбора выберите учебный набор.
2. `разбери входящие`. Попросите: `подготовь ответ Лебедеву: вежливый отказ` — проверьте, что изменился файл черновика.
3. `покажи задачи` → `задачу про голосование — сделано`.
4. Откройте `artifacts/inbox.html` двойным щелчком: посмотрите вкладки «Почта», «Задачи», «Разбор» на учебных данных.
5. Claude Code: `python tools/inbox_check.py --today 2026-10-05`. Cowork: «проверь шину по правилам протокола».

**Критерий «уровень взят».** В `hub/inbox/mail.md` 11 строк без адресов почты; пять черновиков по 2–5 предложений
без пометок `[РЕШИТЬ]`; четыре задачи; `inbox_check.py` пишет «нарушений нет»; в журнале есть строка.

**Типичная ошибка.** Просить «заведи задачу ответить Ковалёву». Ответ — не задача: письмо и так видно в обзоре
как ждущее ответа. Задачи — только действия сверх ответа, адресованные лично вам.

**Что остаётся человеку.** Выбрать вариант ответа, отправить его самому; поправить шаблоны под свой тон; решить,
что из предложенного действительно задача.

## L3. Три роли, память, план

**Что добавляется.** Разделение труда: **Классификатор** (тип, адресация, срочность с обоснованием) →
**Составитель** (ответы и задачи) → **Приоритизатор** (план «сегодня / на неделе / делегировать / ответить»,
раскладка по шине). Память `hub/memory/`: люди, сокращения, шаблоны. Правила ролей — `playbooks/04_inbox.md`.

**Где работает.** Claude Code — субагенты `inbox-classifier`, `inbox-drafter`, `inbox-prioritizer`. Cowork — те же
роли тремя последовательными проходами.

**Задание (25 минут).**
1. Попросите: `убери из памяти учебные файлы demo_, письма оставь` — и разберите набор с пустой памятью: агент
   не расшифрует «КЦ», «ЕЖО», «СЗ», не узнает отчество Смирнова и не предложит, кому делегировать.
2. Научите: `запомни: КЦ — комитет по цифровизации`, `запомни: Смирнову пишем «Павел Андреевич»`,
   `запомни: договоры — это к Гришину; данные для справок — к Орловой`.
3. `разбери входящие по ролям и покажи, что сделал каждый`.
4. Измените условия: `в среду я в командировке — пересобери план на неделю`.
5. Спросите: `что бы ты делегировал и кому?`

**Критерий «уровень взят».** Срок справки выведен из двух писем (четверг 2026-10-08 минус два дня, подтверждение
от секретаря); «к пятнице» оставлено вопросом `[РЕШИТЬ: уточнить дату]`; в плане есть раздел «Делегировать»
с людьми из памяти и «Конфликты» (три дела на 2026-10-07); после второго разбора сокращения расшифрованы.

**Типичная ошибка.** Ждать, что агент «сам знает» людей. Без строки в памяти он обязан написать «в письме
не указано», а не придумать отчество. Вторая ошибка — считать предложение делегировать уже переданным поручением.

**Что остаётся человеку.** Расставить приоритеты, когда всё «срочно»; передать поручения людям; пополнять память —
это ваша модель мира, агент её только ведёт.

## L4. «Живёт сам»

**Что добавляется.** Рутины по расписанию (`playbooks/14_routines.md`): набор «Минимум» — `inbox-morning`; «Стандарт» —
плюс `inbox-evening`, `inbox-mail-pull`, `inbox-tg-pull`. Свой бот в Telegram как почтовый ящик
(`playbooks/15_telegram.md`). Опубликованная страница с хранилищем и сверкой в обе стороны, кнопка «Отправить»
(`playbooks/13_artifacts.md`). Почта коннектором с правилами доступа в `hub/accounts.md`.

**Где работает.** Claude Code — всё. Cowork — без бота и `inbox-tg-pull`; страница и рутины — если инструменты доступны.

**Задание (30 минут).**
1. `опубликуй страницу` → на вкладке «Задачи» отметьте задачу сделанной → в чате `сверь страницу` → убедитесь,
   что статус изменился в `hub/tasks.md`.
2. `включи рутины` → «Минимум» → проверьте запись в `hub/routines.md`.
3. `подключи телеграм` (Claude Code): пройдите пять шагов, перешлите боту любое сообщение, напишите `забери телеграм`.
4. `подключи почту` на личном или запасном ящике. Отправьте себе тестовое письмо, дождитесь разбора, на странице
   поправьте ответ и нажмите «В черновик» — проверьте, что в почте появился черновик, а не отправленное письмо.
5. По желанию: разрешите отправку и отправьте ответ **самому себе** кнопкой «Отправить».
6. Вечером: `на что я не ответил`.

**Критерий «уровень взят».** Отметка со страницы вернулась на шину; утренний разбор прошёл без вашего участия
и оставил строку в журнале; пересланное боту сообщение появилось в обзоре; в `hub/accounts.md` записано, что агенту
разрешено и что нет; ни одно письмо не ушло без нажатия кнопки.

**Типичная ошибка.** Прислать токен бота в чат (его нужно перевыпустить в @BotFather) или подключить
корпоративный ящик, не выяснив правила организации. Третья — включить одну рутину и в Cowork, и в Claude Code:
разбор выполнится дважды.

**Что остаётся человеку.** Нажимать «Отправить»; раз в неделю смотреть журнал рутин; решать, какие каналы
подключать; отзывать разрешения, когда они не нужны.

## L5. «Инженерный»

**Что добавляется.** Проверка качества и расширение.

| Приём | Что это в кейсе |
|---|---|
| Проверочные примеры и рубрика | `demo/hub/` (вход), `demo/пример_результата/` (эталон), `demo/рубрика_приёмки.md` (12 критериев, 24 балла) |
| Формальная проверка | `python tools/inbox_check.py` — форматы, главное правило задач, черновики, «отправлено» без кнопки |
| Независимый проверяющий | субагент `inbox-checker`: только чтение, семь проверок, отчёт «принято» или замечания |
| Свой навык | `skill-creator` из пака: например, навык ответов на обращения граждан по вашим шаблонам |
| Хуки и разрешения Claude Code | свой `.claude/settings.json`: запрет чтения `hub/.secrets/**`, запрет сетевых команд, подтверждение записи вне `hub/` |
| Свой источник через MCP | система документооборота или трекер поручений как ещё один канал |
| Метрики | бортжурнал: минуты, доля разборов «принято» с первого раза, число замечаний безопасности |
| Встраивание | перенос `hub/` в комплексного ассистента (кейс 6) — см. [README.md](README.md) |
| Официальный плагин `telegram` | переписка с агентом в реальном времени вместо «почтового ящика» — см. [SETUP.md](SETUP.md) |

**Где работает.** Claude Code.

**Задание (30 минут).**
1. Эталон: `python tools/inbox_check.py --hub demo/пример_результата --today 2026-10-05` — должно быть «нарушений нет».
2. Свой разбор: `прогони рубрику demo/рубрика_приёмки.md на последнем разборе и дай баллы по каждому критерию`.
3. Подложите ошибку: в `hub/tasks.md` допишите задачу «Ответить Кузнецовой» или поставьте письму статус
   `отправлено`. Запустите `проверь разбор независимо` и `python tools/inbox_check.py` — оба должны её найти.
4. Подложите письмо со встроенной инструкцией своей формулировки (положите файл в `hub/inbox/new/`) и разберите.
5. Одно на выбор:
   - **навык:** `собери навык для ответов на обращения граждан, используй skill-creator` — затем проверьте его
     на двух письмах;
   - **разрешения:** попросите `предложи hooks и permissions для этой папки` и внесите в `.claude/settings.json`
     правила `deny` для `Read(hub/.secrets/**)` и сетевых команд; проверьте, что агент получает отказ;
   - **источник через MCP:** опишите в `hub/accounts.md` новый канал (что читать, что запрещено) и подключите его
     сервер командой `claude mcp add`; правило то же — на шину попадает краткая суть, а не полный текст.
6. `посчитай по бортжурналу: сколько минут сэкономлено и сколько разборов не прошли проверку`.

**Критерий «уровень взят».** Рубрика на вашем разборе — не меньше 20 из 24 при полных баллах за критерии 8 и 12;
проверяющий и скрипт нашли подложенную ошибку; своя встроенная инструкция не выполнена и попала в «Замечания
безопасности»; в журнале есть строка с результатом прогона.

**Типичная ошибка.** Поручить проверку тому же проходу, который делал разбор: он подтвердит сам себя. Проверяющий
должен быть отдельным запуском с правами только на чтение. Вторая — править сгенерированные файлы в `.claude/`
вместо плейбуков: следующая сборка `python tools/build.py` всё сотрёт.

**Что остаётся человеку.** Определять, что считать хорошим разбором (рубрика — ваша); решать, каким источникам
и навыкам доверять; отвечать за всё, что ушло от вашего имени.

---

## Что не автоматизируется ни на одном уровне

Согласовать или отказать. Выбрать, что важнее. Передать поручение человеку. Нажать «Отправить». Проверить, что
агент не ошибся там, где цена ошибки высока.
