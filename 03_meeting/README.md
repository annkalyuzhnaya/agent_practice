# Кейс 3. Подготовка к встрече: бриф и мемо

Агент, который **до встречи** собирает бриф на одну страницу, а **после** превращает ваши заметки в мемо, задачи,
обновлённое досье и черновик письма. Самостоятельный учебный кейс: папку можно скопировать отдельно — она работает сама.

## Для кого

Руководители и специалисты, у которых несколько встреч в неделю с подрядчиками, заказчиками, партнёрами.
Программировать не нужно: вы пишете в чат обычными словами. Все учебные данные — вымышленные.

## Что вы получите

| Режим | На входе | На выходе |
|---|---|---|
| **А. До встречи** | досье и решения из `hub/kb/`, переписка и вводные, открытые источники | бриф: главное в 5 строк, кто это, история отношений, интересы сторон, повестка, вопросы, карта возражений, что нельзя обещать, что не подтверждено |
| **Б. После встречи** | ваши заметки (чат, страница, бот) | мемо: решения, договорённости, открытые вопросы; задачи «кто — что — срок» в `hub/tasks.md`; дополнения к досье; черновик письма; сверка с прошлыми обещаниями |

Три правила, на которых всё держится: **у факта есть источник** (иначе — «Не подтверждено»); чего агент решать
не вправе — **`[РЕШИТЬ: …]`**; агент **ничего не отправляет** — только черновики.

## Как это устроено

```
 вводные, переписка          досье, решения, прошлые мемо         открытые источники
 hub/inbox/new/                    hub/kb/  hub/meetings/               интернет
        │                                  │                               │
        └───────────────┬──────────────────┘                               │
                 Роль 1. Архивист                              Роль 2. Исследователь
                        └───────────────────┬──────────────────────────────┘
                                 Роль 3. Адвокат дьявола
                                            │
                                      Сборка брифа ──► Роль 4. Проверяющий фактов
                                            │
        ┌───────────────────────────────────┼─────────────────────────────────┐
  hub/meetings/…_бриф.md          страница «Встречи»              выжимка в Telegram
                                            │
                                   ═══ ВСТРЕЧА ═══
                                            │
                          заметки (чат · страница · бот)
                                            │
     мемо ──► задачи hub/tasks.md ──► досье hub/kb/ ──► черновик письма ──► календарь
                                            │
                       контроль исполнения к следующей встрече
```

## Лестница уровней

| Уровень | Что умеет агент | Среда | Критерий «взят» |
|---|---|---|---|
| L1. Чат | бриф и мемо по инструкции в Проекте | чат claude.ai | в учебном брифе найдены расхождение писем и порог комиссии |
| L2. Навык | помнит встречи, ведёт задачи и досье | Code, Cowork | после мемо обновились задачи, календарь, досье; письмо — черновик |
| L3. Команда ролей | четыре субагента, скрипты, оркестрация | Code | видны результаты четырёх ролей; `check` — «ПРИНЯТО» |
| L4. Автономность | расписание, бот, страница, календарь | Code; частично Cowork | бриф появился накануне сам; выжимка пришла в Telegram |
| L5. Инженерия | evals, рубрика, свой навык, хуки, свой источник, метрики | Code | есть балл по рубрике, процент `eval` и своя проверка |

Подробно, с заданиями на 15–30 минут, — [LEVELS.md](LEVELS.md).

## С чего начать

1. [SETUP.md](SETUP.md) — выберите вариант (Claude Code, Cowork или чат) и установите за 5–10 минут.
2. Напишите агенту «настрой», затем «покажи на примере».
3. [GUIDE.md](GUIDE.md) — готовые фразы и список того, чего агент не делает.
4. [prompts/шпаргалка_промптов.md](prompts/шпаргалка_промптов.md) — промпты по уровням;
   [prompts/L1_инструкция_для_проекта.md](prompts/L1_инструкция_для_проекта.md) — вариант без установки.

## Что в папке

| Папка или файл | Что это |
|---|---|
| `playbooks/` | правила агента — единственный источник; из них собирается всё остальное |
| `tools/` | `build.py` (сборка), `setup.py` (создать `hub`), `demo.py` (учебный набор), `meetings.py` (скрипты кейса), `tg_bridge.py` (бот) |
| `artifacts/meetings.html` | шаблон страницы «Встречи»; открывается с диска в учебном режиме |
| `presets/hub/` | заготовки шины: профиль, пустые таблицы, шаблон досье |
| `demo/` | учебный набор, проверки `evals.json`, рубрика приёмки, эталон в `demo/пример_результата/` |
| `prompts/` | инструкция для Проекта claude.ai и шпаргалка промптов |
| `pack/` | сторонние навыки (не править руками): `task-management`, `internal-comms`, `tavily-research`, `skill-creator` |
| `.claude/`, `cowork-plugin/hq-meeting/`, `dist/hq-meeting.plugin` | создаёт `python tools/build.py`; руками не править |
| `hub/` | ваши данные; появляется после `python tools/setup.py`, в git не попадает |

Навыки кейса: `meeting` (основной) и `setup` (мастер настройки). Субагенты: `meeting-archivist`, `meeting-researcher`,
`meeting-devil`, `meeting-checker` и `meeting-prep` (вся работа одним исполнителем).

**Что из пака не идёт в плагин Cowork и почему:** `tavily-research` (нужна программа `tvly` в терминале) и
`skill-creator` (нужен Python для прогона проверок). В Claude Code доступны все четыре навыка.

## Как вырасти до комплексного ассистента

Кейс 6 «Личный ассистент» — это тот же агент встреч, но в команде: почту разбирают Входящие, досье ведёт Библиотекарь,
документы готовит Документ-инженер, день собирает оркестратор, всё видно на общей доске. Кейс 3 сделан так, чтобы
переход был переносом папки, а не переделкой.

**Что совместимо без изменений.** Имена и форматы шины здесь — подмножество шины кейса 6: `hub/profile.md`,
`hub/calendar.md`, `hub/tasks.md`, `hub/journal.md`, `hub/meetings/`, `hub/kb/контрагенты/`, `hub/kb/решения/`,
`hub/kb/_противоречия.md`, `hub/inbox/new|done|drafts`, `hub/handoff/`, `hub/accounts.md`, `hub/routines.md`,
`hub/artifacts.md`. Брифы, мемо, задачи и досье ассистент кейса 6 читает как свои.

**Порядок перехода.**
1. Отключите рутины этого кейса: «отключи все рутины» (`meet-eve`, `meet-memo`, `meet-weekly`, `meet-tg-pull`,
   `meet-cal-pull`) — иначе брифы и напоминания задвоятся с рутинами `hq-*`.
2. Установите кейс 6 по его `SETUP.md` — появится папка ассистента со своей шиной `hub`.
3. Скопируйте из `hub` этого кейса в `hub` ассистента: `meetings/`, `kb/контрагенты/`, `kb/решения/`, строки
   `calendar.md` и `tasks.md` (дописать в конец таблиц, не заменяя файл), строки `journal.md`. Проще всего попросить
   ассистента: «перенеси данные из папки кейса “Встречи” — вот путь».
4. В профиле ассистента повторите раздел «Что нельзя обещать без согласования» — он нужен агенту встреч и там.
5. Бот: один токен — один получатель сообщений. Используйте бота в кейсе 6, а здесь мост больше не запускайте.
6. Страница «Встречи» остаётся рабочей, но обновлять её будет некому: в кейсе 6 встречи показывает общая доска.

**Что изменится в работе.** Роль «Архивист» заменит Библиотекарь с настоящей базой знаний; вводные перестанут
приходить вручную — их положит агент «Входящие»; бриф накануне войдёт в утреннюю сводку «Мой день». Раздельные роли
(исследователь, адвокат дьявола, проверяющий) и приёмка по рубрике — то, что вы приносите в кейс 6 отсюда.
Как оркестрация устроена здесь и там — [LEVELS.md](LEVELS.md), уровень L3.

## Ограничения, о которых стоит знать заранее

- Агент не слышит встречу: мемо строится только из ваших заметок или расшифровки.
- Сведения из интернета приводятся со ссылкой, но проверять важное нужно самому.
- Скрипт приёмки проверяет форму и наличие фактов, а не их смысл.
- Расписание работает, пока приложение Claude открыто на компьютере.
- Голосовые сообщения боту не расшифровываются.
