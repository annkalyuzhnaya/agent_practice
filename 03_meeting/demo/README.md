## Порядок упражнения

1. `python tools/demo.py load` — вводные на шине.
2. Агенту: «Сегодня 6 октября 2026. Подготовь бриф к завтрашней встрече с Северным контуром».
3. Сверьте бриф с `пример_результата/2026-10-07_северный-контур_бриф.md` по рубрике.
4. `python tools/demo.py after` — заметки «после встречи».
5. Агенту: «Встреча прошла, заметки во входящих — оформи мемо, задачи и письмо».
6. Сверьте с `пример_результата/` (мемо, черновик письма, `изменения_на_шине.md`).
7. `python tools/demo.py clean` — убрать учебные материалы.

Без Python (Cowork, чат): попросите агента «покажи на примере» — он разложит те же файлы сам; в чате claude.ai —
приложите файлы из `hub/` этого набора к разговору.
