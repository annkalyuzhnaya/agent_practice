# digest

Работает в папке кейса «Обозреватель» (там, где лежат `tools/` и `hub/`).

## Порядок

1. Прочитай `references/00_protocol.md` (правила, карта `hub/`, формат ответа) и `references/01_digest.md` (режимы, рубрика, шаги выпуска, роли, формат выпуска).
2. Определи режим по таблице «Режимы» и действуй по его шагам. Страница — `references/03_page.md`, расписание — `references/04_cron.md`, Telegram — `references/05_telegram.md`, модели — `references/06_models.md`.
3. Папки `hub/` нет или профиль не заполнен — сначала навык `digest-setup`.
4. Скрипты запускай сам из папки кейса: `python tools/…`. Передавай человеку смысл их сообщений, а не текст.
5. Ответ — четыре блока: ЗАДАЧА → КАК РАБОТАЛ → РЕЗУЛЬТАТ → ЧТО ОСТАЁТСЯ ЧЕЛОВЕКУ; затем строка в `hub/journal.md`.
