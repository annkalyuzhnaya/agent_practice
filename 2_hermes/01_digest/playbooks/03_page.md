# Страница «Дайджест»

Страница — один самодостаточный файл `hub/page/digest.html`. Её собирает скрипт из файлов рабочей папки; ни сервера,
ни внешнего хранилища, ни публикации в интернете нет. Источник правды — файлы `hub/`, страница — только их вид.

## Сборка и показ

- `python tools/page.py` — собрать страницу из всех выпусков, отметок, очереди и предложений по темам. Запускай после
  каждого выпуска (шаг 8), после отметок и по словам «обнови страницу».
- **Показать человеку.** Назови путь `hub/page/digest.html` одной строкой. В приложении Hermes Desktop файл открывается
  в панели предпросмотра справа от чата (и виден в списке Artifacts); в веб-панели и в терминале — человек открывает
  файл в браузере двойным щелчком.
- Нет Python — собери такой же HTML сам: заголовок, ТОП-3, позиции с оценкой, темой и ссылкой.

## Что на странице

| Блок | Откуда |
|---|---|
| Выбор выпуска, фильтры по теме, оценке и отметке | `hub/digest/ГГГГ-ММ-ДД.md` |
| Позиции: оценка, «почему важно», «что сделать», ссылка, знак ТОП-3 | файл выпуска |
| Отметка у позиции (в базу / в задачи / не интересно) | `hub/digest/marks.md` |
| «Пропущено», «Не удалось открыть», «Что остаётся человеку» | файл выпуска |
| Очередь «посмотри это» и предложения по темам | `hub/digest/queue.md`, `hub/digest/topics.md` |
| Кто что исполнял | `hub/models.json` |

## Отметки

Страница ничего не записывает. Кнопки «в базу», «в задачи», «не интересно» **копируют готовую фразу** («в базу 2»);
человек вставляет её в чат Hermes или отправляет боту — дальше режим Б плейбука выпуска. После записи отметок
пересобери страницу, чтобы они стали видны.

## Границы

- Страница — личная: в ней задачи и отметки владельца. Коллегам уходит не она, а карточка выпуска (режим Г), и
  пересылает её человек.
- Не выкладывай страницу в интернет и не поднимай для неё сервер, даже если человек просит «чтобы открывалась с
  телефона»: предложи Telegram (ТОП-3 приходит туда) или карточку файлом.
