# Установка Обозревателя в Hermes

Hermes Agent — открытая программа-агент (Nous Research), которая работает на вашем компьютере и подключается к моделям
по ключу API. Подписка Claude для ежедневной работы Обозревателя не нужна: вы платите провайдеру модели за
фактический расход.

Работать можно в любом из трёх окон — у них общие настройки, навыки и история:

| Окно | Как открыть | Кому подходит |
|---|---|---|
| **Hermes Desktop** — приложение | ярлык приложения или `hermes desktop` | основной путь: чат, файлы и страница рядом, настройки кнопками |
| **Веб-панель** | `hermes dashboard` → откроется `http://127.0.0.1:9119` | тот же чат в браузере плюс вкладки настроек, расписания, расхода |
| **Терминал** | `hermes` в папке кейса | тем, кому привычнее командная строка |

> Установка командой, веб-панель и команды `hermes …` проверены на Windows 11 с Hermes Agent 0.21.5 (октябрь 2026
> года); названия разделов приложения Hermes Desktop взяты из документации. Hermes быстро меняется: если раздел
> называется иначе, смотрите справку приложения или `hermes --help`.

> **Проще всего — поручить установку Claude.** Откройте папку кейса в Claude (Claude Code или вкладка Code в Claude
> Desktop) и вставьте готовый запрос из [START.html](START.html), раздел 2: Claude сам проверит Git и Python,
> установит Hermes, подключит навыки, пропишет адрес и модель, поставит шлюз в автозапуск и откроет веб-панель. Вам
> останется ввести ключ API на вкладке Keys. Шаги ниже — то же самое вручную.

## Шаг 1. Установить Hermes

- **Приложение:** скачайте установщик Hermes Desktop с сайта <https://hermes-agent.nousresearch.com/> и запустите.
- **Или командой** — веб-панель и терминал без приложения. Откройте обычное окно PowerShell (Пуск → PowerShell):

```powershell
irm https://hermes-agent.nousresearch.com/install.ps1 | iex
```

Установка идёт 5–15 минут: установщик сам скачивает всё, что нужно Hermes (свой Python, Node, браузер для чтения
страниц), в `%LOCALAPPDATA%\hermes`. Заранее нужен только Git: <https://git-scm.com/>.

После установки **откройте новое окно терминала** (в старом команда `hermes` ещё не видна) и проверьте:

```powershell
hermes --version
```

Скриптам кейса нужен обычный Python 3.9+ (хватает стандартной библиотеки): `python --version`. Python, который
установщик ставит для самого Hermes, — внутренний, командой `python` он не вызывается.

> Запускайте установщик в отдельном окне PowerShell, а не в терминале внутри другого приложения (например, Claude
> Desktop из Microsoft Store). Иначе установка обрывается на шаге «Downloading Python» с ошибкой
> `Missing expected target directory for Python minor version link`: таким приложениям Windows подменяет папку
> `AppData`.

## Шаг 2. Подключить модель

При первом запуске приложение спросит провайдера. Ключ вводите **в окне Hermes**, не в чат:

- приложение: **Settings → Providers**;
- веб-панель: вкладка **Keys** — ключ провайдера; вкладка **Models** → Main model → Change — модель по умолчанию;
- терминал: `hermes setup`, затем `hermes model`.

Подойдёт любой провайдер, к которому Hermes умеет подключаться: агрегатор моделей, прямой доступ к разработчику,
свой адрес, совместимый с OpenAI, локальная модель. Для начала достаточно одной модели; роли разведёте позже.
Как выбрать провайдера и модель, получить ключ и что значат ошибки 401, 402, 404 — подробно и со снимками панели в
[START.html](START.html), раздел 3.

**Свой адрес, совместимый с OpenAI** (сервис, которого нет в списке провайдеров). Три настройки — на вкладке Config
или командами (адрес и модель — пример):

```bash
hermes config set model.provider custom
hermes config set model.base_url "https://llm.example.ru/api/v1"
hermes config set model.default "vendor/model-name"
```

Ключ для такого адреса Hermes ищет в переменной, названной по имени сайта: для `llm.example.ru` это
`EXAMPLE_API_KEY` (второе с конца слово адреса, заглавными буквами). Заведите её в веб-панели: вкладка **Keys** →
внизу страницы блок **Add a custom key** → впишите имя переменной → **+ Add**. Появится карточка с пометкой Not set:
вставьте ключ в поле Enter value… и нажмите **Save** — пометка сменится на Set. Ключ от другого сервиса (например,
`OPENAI_API_KEY`) Hermes на чужой адрес не отправляет.

## Шаг 3. Открыть папку кейса

Скопируйте папку `01_digest` (эту) в удобное место — отдельно, не внутрь другого проекта git.

Hermes прочитает `AGENTS.md` и увидит навыки в `.hermes/skills/`. Навыки из папки он подключает при двух условиях:
папка — проект git и вы один раз подтвердили, что доверяете её навыкам. Выполните в скопированной папке (путь — ваш):

```bash
git init
hermes skills trust "D:/путь/к/01_digest"
```

Путь указывайте явно: без него команда берёт рабочую папку из настроек Hermes (`terminal.cwd`), а не ту, где вы стоите.

Проверка: `hermes skills list` в этой папке покажет навыки `digest` и `digest-setup` с пометкой `project`. Без
`git init` команда `hermes skills trust` отвечает «Not inside a git checkout», и навыки не подключаются — тогда агент
работает по `AGENTS.md` и читает правила из файлов: медленнее, но так же.

Затем откройте папку:

- приложение: **Settings → Workspace** — добавьте папку; или запуск `hermes desktop --cwd "путь к папке"`;
- веб-панель: вкладка **Chat** → список **Workspace** на боковой панели → Other path… → путь к папке. Чтобы папка
  кейса была рабочей по умолчанию (в чате, у шлюза и в Telegram): `hermes config set terminal.cwd "D:/путь/к/01_digest"`;
- терминал: перейдите в папку и запустите `hermes`.

Навыки подхватываются при старте разговора: после `hermes skills trust` начните новый чат (New chat).

Окно Hermes при этом выглядит как обычно: кейс не меняет интерфейс, это папка с правилами, которые агент читает в
начале разговора. Признаки, что кейс подключён: в шапке чата указан путь к папке кейса, а счётчик навыков (skills)
на четыре больше, чем на вкладке **Skills** — она показывает только общие навыки Hermes, без навыков папки. Как
Обозреватель агент заговорит в ответ на первое сообщение — для этого должна быть подключена модель (шаг 2).

Чтобы навыки кейса были видны и на вкладке **Skills**, добавьте их папку в общий список (путь — ваш):

```bash
hermes config set skills.external_dirs '["D:/путь/к/01_digest/.hermes/skills"]'
```

## Шаг 4. Настроить

Напишите в чат: **«настрой»**. Агент ведёт настройку сквозным опросом до конца: два обязательных шага (рабочая папка
и профиль, около пяти минут), затем по желанию модели под роли, пробный выпуск, страница, расписание и Telegram — на
каждом можно ответить «пропустить». Хотите сначала посмотреть — выберите учебный пример: 10 вымышленных публикаций с
ловушками и автоматическая приёмка.

**Полный запрос — всё за один разговор.** Если агент после первого шага остановился и ждёт, или вы хотите сразу
задать правила, вставьте в новый чат этот текст целиком:

```text
Настрой себя как Обозревателя полностью, за один разговор, без пауз между шагами.

Действуй по плейбуку настройки (навык digest-setup, файл 02_setup.md) и чек-листу hub/setup.md. Сначала выполни
python tools/setup.py status и продолжай с первого незавершённого шага. Пройди подряд все шаги: 0 — рабочая папка и
среда, 1 — профиль, 2 — модели под роли, 3 — пробный выпуск, 4 — страница, 5 — расписание, 6 — Telegram.

Правила работы:
1. Закончил шаг — отметь его в hub/setup.md и в том же сообщении задай первый вопрос следующего шага. Не жди слова
   «продолжи» и не заканчивай ответ отчётом.
2. Всё, что можешь сделать сам (команды, проверки, создание файлов), делай без вопросов.
3. Меня спрашивай только о том, чего не знаешь: один вопрос за раз, с нумерованными вариантами. Спрашивай, пока не
   соберёшь все детали шага: роль и задачи на месяц, темы по приоритету, что не интересно, источники, период,
   модели по ролям, набор и время расписания.
4. Если в hub/ лежат учебные данные (демо-профиль), убери их командой python tools/demo.py clean и заполни профиль
   по моим ответам.
5. Ключи и токены в чат не проси. Назови раздел окна Hermes, куда мне их ввести, дождись моего «готово» и проверь,
   что заработало.
6. На создание заданий расписания и подключение Telegram даю согласие этим сообщением; набор заданий и время
   уточни у меня. Фоновая служба Hermes не запущена — скажи команду и дождись «готово».
7. Шаг невозможно выполнить или я ответил «пропустить» — запиши «отложено» с причиной и сразу переходи дальше.

В конце покажи чек-лист: что сделано, что отложено и почему, и три фразы на каждый день.
```

## По желанию

| Что | Где в окне Hermes | Слово в чате |
|---|---|---|
| Разные модели под роли | модель разговора — список Model на панели чата; модель разведчиков — Settings / вкладка **Config**, раздел Delegation | «настрой модели» |
| Страница «Дайджест» | файл `hub/page/digest.html`: приложение — панель предпросмотра справа, раздел Artifacts; веб-панель — откройте файл в браузере | «сделай страницу» |
| Расписание | раздел **Cron** | «включи расписание» |
| Telegram | приложение: **Messaging**; веб-панель: **Channels** → Telegram → Quick setup → Create with QR | «подключи телеграм» |
| Расход по моделям | какие модели работали — веб-панель, вкладка **Models**; точная цена — в личном кабинете провайдера (счётчик Hermes скрыт и занижает расход) | — |
| Отдельный профиль под Обозревателя | раздел **Profiles** | — |

## Чтобы ассистент работал в фоне

Окно чата и фоновая работа — разные программы. Веб-панель и приложение — только окна: закрыли терминал, из которого
запущена `hermes dashboard`, — панель перестала открываться, но на расписание и Telegram это не влияет. За них
отвечает фоновая служба Hermes — **шлюз**. Поставьте его в автозапуск один раз:

```bash
hermes gateway install --start-now --start-on-login
```

На Windows команда спросит разрешение администратора (окно UAC), чтобы создать задание Планировщика; если отказаться,
шлюз встанет в папку «Автозагрузка» — этого достаточно. Шлюз стартует при входе в Windows и работает без открытых
окон, пока включён компьютер. Проверка — `hermes gateway status`, журнал — `logs\gateway.log` в домашней папке
Hermes, снять с автозапуска — `hermes gateway uninstall`. Запуск в открытом окне без автозапуска — `hermes gateway run`.

Веб-панель запускайте, когда нужно окно: `hermes dashboard` в отдельном окне PowerShell (пока окно открыто, панель
работает; запущена ли она — `hermes dashboard --status`). Чтобы панель тоже стартовала сама, положите в папку
автозагрузки (Win+R → `shell:startup`) файл `hermes-panel.cmd` из двух строк (путь — ваш):

```bat
cd /d "D:\путь\к\01_digest"
hermes dashboard --no-open --skip-build
```

## Отличия от версии для Claude

| В версии для Claude | В Hermes |
|---|---|
| субагенты `scout`, `digest-checker` | дочерние агенты `delegate_task`; проверяющий — отдельный запуск на другой модели |
| одна модель на всё | модель под каждую роль (`hub/models.json`) |
| формы с вариантами | вопрос с нумерованными вариантами |
| страница в claude.ai с хранилищем | локальный файл `hub/page/digest.html`; отметки — фразой в чат |
| запланированные задачи Claude | cron Hermes, модель закрепляется за заданием |
| свой скрипт-мост Telegram | шлюз Hermes: бот — второе окно того же разговора |
| плагин Cowork | навыки `.hermes/skills/` в формате agentskills.io |

Рабочая папка `hub/` — того же формата: её можно перенести из версии для Claude копированием (кроме `hub/.secrets/`).

## Если что-то не так

| Признак | Что сделать |
|---|---|
| Агент не знает, что он Обозреватель | окно открыто не в папке кейса — выберите её (шаг 3) |
| Команда `hermes` не найдена сразу после установки | откройте новое окно терминала |
| Установка обрывается на «Downloading Python» | запустите установщик в отдельном окне PowerShell (шаг 1) |
| Навык `digest` не находится | папка кейса — не проект git или не подтверждено доверие (шаг 3); причину назовёт `python tools/setup.py status` |
| `hermes skills trust` отвечает «Not inside a git checkout» | сначала `git init` в папке кейса (шаг 3) |
| «Не могу искать в интернете» | не подключён веб-поиск: веб-панель, вкладка **Keys** — ключ одного из поисковых сервисов (Tavily, Exa, Firecrawl, Brave) |
| Бот в Telegram отвечает не как Обозреватель | рабочая папка шлюза — не папка кейса: `python tools/hermes.py config` покажет нужную настройку |
| Веб-панель перестала открываться | закрыто окно, из которого она запущена: снова `hermes dashboard`; на шлюз и расписание это не влияет (раздел «Чтобы ассистент работал в фоне») |
| Прошлый разговор не открывается | на вкладке **Sessions** список Overview — только сводка, строки не нажимаются. Продолжить: вкладка **Chat** → список Sessions на боковой панели, или **Sessions** → History → кнопка Resume in Chat; в терминале — `hermes -c` (последний разговор) |
| Задание по расписанию не сработало | раздел Cron — журнал запуска; компьютер был выключен или шлюз не запущен |
| Общая диагностика | `hermes doctor` |
