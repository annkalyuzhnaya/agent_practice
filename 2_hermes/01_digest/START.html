Обозреватель в Hermes: настройка Hermes через сам Hermes

Hermes Agent — открытая программа-агент, которая работает на вашем компьютере и обращается к моделям по ключу API: подписка Claude для ежедневной работы не нужна. Обозреватель — это Hermes, открытый в папке кейса: он читает за вас открытые источники и приносит до десяти свежих публикаций со ссылками, оценкой важности и пояснением, чем каждая полезна именно вам. Команды в консоли вы не набираете: установку по готовому запросу выполняет Claude, а дальше Hermes настраивает себя сам — по слову «настрой» он опрашивает вас и доводит настройку до конца. Ваши действия: скопировать папку, вставить запрос, ввести ключ провайдера в окне Hermes и отвечать на вопросы.

1Что умеет Обозреватель

Вы пишете одно слово — «дайджест». Дальше работают три роли: разведчики ищут публикации по каждой теме, редактор убирает повторы и расставляет оценки, независимый проверяющий сверяет выпуск с источниками. Вам приходит готовый выпуск. Какая модель исполняет какую роль, решаете вы.

Получаете

Например: дайджест за 3 дня

2Установка

Что нужно заранее: Windows 10 или 11; приложение Claude (вкладка Code) или Claude Code — оно понадобится один раз, для установки; папка курса agent_practice; у провайдера моделей — адрес API, название модели и ключ (как выбрать и получить, в разделе 3). Git и Python Claude проверит и при необходимости поставит сам.

Картинки ниже — снимки настоящей веб-панели Hermes (версия 0.21.5, октябрь 2026 года; язык панели английский). Оранжевые цифры показывают, куда смотреть и нажимать; щелчок по снимку увеличивает его. Сначала — про папку кейса и папку hub

Кейс не меняет сам Hermes: это папка с правилами, которые агент читает в начале каждого разговора. При первой настройке внутри неё появляется папка hub — в ней будут все ваши данные.

Пять шагов до первого сообщения

1

Скопируйте папку кейса

В Проводнике скопируйте agent_practice\2_hermes\01_digest в постоянное место, например D:\Работа\Дайджест. Больше с папкой руками делать ничего не нужно.

2

Откройте эту папку в Claude и вставьте запрос на установку

В приложении Claude (вкладка Code) выберите скопированную папку и отправьте текст ниже. Claude сам установит Hermes, подключит навыки папки, пропишет адрес и модель, поставит фоновую службу и запустит веб-панель.

Запрос на установку — скопируйте целиком 
Разверни Hermes Agent на этом компьютере и подключи к нему эту папку кейса. Все команды выполняй сам;
меня спрашивай только о том, чего не можешь узнать или сделать без меня.

1. Проверь Git и Python 3.9 или новее. Чего нет — установи через winget или скажи, что мне скачать.
2. Проверь hermes --version. Не установлен — установи командой
   irm https://hermes-agent.nousresearch.com/install.ps1 | iex
   Если установка обрывается на «Downloading Python», запусти ту же команду в отдельном окне PowerShell
   (Start-Process powershell) и дождись конца. Команда hermes лежит в папке bin домашней папки Hermes
   (%LOCALAPPDATA%\hermes\bin): если она не находится, добавь эту папку в PATH сеанса.
3. В этой папке выполни git init (если она ещё не проект git), затем
   hermes skills trust "<полный путь к этой папке>" — путь укажи явно.
   Проверь: в выводе hermes skills list есть digest и digest-setup.
4. Сделай эту папку рабочей папкой Hermes: hermes config set terminal.cwd "<полный путь к этой папке>".
5. Спроси у меня адрес API провайдера и название модели. Затем выполни
   hermes config set model.provider custom
   hermes config set model.base_url "<адрес>"
   hermes config set model.default "<модель>"
   Если мой провайдер есть во встроенном списке Hermes, эти три команды не нужны — скажи мне об этом.
6. Ключ API не спрашивай, не ищи и не читай; файл .env не открывай. Назови мне имя переменной, в которую
   я сам введу ключ на вкладке KEYS веб-панели: слово перед доменной зоной адреса заглавными буквами
   плюс _API_KEY (routerai.ru → ROUTERAI_API_KEY).
7. Поставь фоновую службу в автозапуск: hermes gateway install --start-now --start-on-login.
8. Запусти веб-панель в фоне: hermes dashboard --no-open — и проверь, что http://127.0.0.1:9119 отвечает.

В конце покажи короткий отчёт: версия Hermes, подключены ли навыки папки, рабочая папка, модель и адрес,
имя переменной для ключа, работает ли фоновая служба, адрес панели. Что не получилось — назови прямо
и скажи, что сделать мне.
  1. 1 Claude будет спрашивать разрешение на запуск команд — разрешайте: это установка Hermes и настройки из запроса.
  2. 2 На вопрос про провайдера ответьте адресом API и названием модели, например: https://routerai.ru/api/v1, модель z-ai/glm-5.3. Ключ в чат не пишите.
  3. 3 При установке фоновой службы Windows может спросить разрешение администратора. Можно отказаться: служба встанет в «Автозагрузку», этого достаточно.
  4. 4 В конце Claude покажет отчёт. Из него вам нужны две вещи: адрес панели и имя переменной для ключа.

Установка идёт 5–15 минут: всё нужное Hermes скачивает сам. Если Claude сообщит, что установщик у него не запускается, — единственный раз откройте обычное окно PowerShell (Пуск → наберите «PowerShell»), вставьте irm https://hermes-agent.nousresearch.com/install.ps1 | iex, дождитесь конца и напишите Claude готово, продолжай. Без Claude все команды можно выполнить вручную — они в SETUP.md.

3Провайдер, модель и ключ API

Hermes сам ничего не «думает» — он пересылает разговор модели и исполняет её решения. Модель живёт у провайдера: это сервис, который по вашему ключу API принимает запросы и списывает деньги за фактический расход (за токены — кусочки текста, прочитанные и написанные моделью). Вам нужно три вещи: провайдер, название модели у него и ключ.

Как выбрать провайдера

Провайдеры бывают трёх видов; Hermes работает с любым.

ВидЧто этоКому подходит
АгрегаторОдин ключ и один счёт — десятки моделей разных разработчиков. Пример: routerai.ru; есть и другие, российские и зарубежныеНовичку и всем, кто хочет пробовать разные модели и разводить их по ролям: менять модель можно, не заводя новых ключей
Разработчик модели напрямуюКлюч в кабинете самого разработчика; доступны только его моделиТем, кто уже выбрал одну модель или у кого на работе есть договор с разработчиком
Свой или локальный адресСервер в вашей организации или модель на вашем компьютере, с адресом, совместимым с OpenAIКогда данные нельзя отправлять наружу; нужен мощный компьютер или помощь ИТ-службы

По чему сравнивать. Пройдите по списку — подойдёт провайдер, у которого на все пункты ответ «да»:

ОплатаМожно ли пополнить счёт вашим способом (карта вашего банка, счёт на организацию) и без подписки — с оплатой по расходу.
ДоступностьСайт и адрес API открываются из вашей сети без дополнительных средств.
СовместимостьВ документации сказано «совместим с OpenAI API» и указан адрес вида https://…/v1. Этого достаточно, чтобы Hermes подключился.
Каталог моделейЕсть модели с вызовом инструментов (tool calling) и большим контекстом — см. ниже.
Контроль расходаВ личном кабинете видны расход по моделям и остаток; хорошо, если на ключ можно поставить лимит.
Условия для данныхПрочитайте, хранит ли провайдер запросы и использует ли их для обучения. Обозреватель читает открытые источники, но ваш профиль (роль, темы) уходит в модель.

Провайдера можно сменить в любой момент: папка кейса и hub от него не зависят, меняются только три настройки и ключ.

Как выбрать модель

Обозреватель — агент: модель должна не просто писать текст, а запускать команды, искать в сети и читать файлы. Поэтому подходит не всякая.

ТребованиеКак проверить в каталоге провайдераЧто будет, если нет
Вызов инструментовВ карточке модели указано tools, tool calling или function callingАгент рассуждает, но ничего не делает: не создаёт hub, не ищет публикации
Большой контекстОкно контекста от 128 тысяч токенов, лучше большеПравила кейса и тексты статей не помещаются; агент «забывает» начало разговора
Русский языкТолько пробой: попросите учебный выпуск и прочитайте егоВыпуск написан неровно, с кальками и ошибками
ЦенаЦена за миллион токенов на входе и на выходе. Обозреватель много читает, поэтому важнее цена входаВыпуск обходится дороже, чем вы готовы платить

Порядок выбора.

  1. Начните с одной модели среднего класса — не самой дешёвой и не самой дорогой у провайдера. На самых дешёвых ломается формат выпуска, самые дорогие для чтения новостей избыточны.
  2. Скопируйте её название из каталога точно, как там написано, — обычно это вид разработчик/модель, например z-ai/glm-5.3.
  3. Проверьте делом, а не по названию: в чате покажи на учебном примере, затем проверь приёмкой. Приёмка — автоматическая проверка выпуска на учебном наборе с ловушками; она скажет, справилась ли модель.
  4. Когда всё заработает, разведите роли: редактору — модель посильнее, разведчикам — подешевле, проверяющему — другую модель, чем редактору. Фраза: настрой модели; сравнение: сравни модели на учебном примере.

Названия моделей и цены меняются каждый месяц, поэтому конкретных советов здесь нет: актуальный список — в каталоге вашего провайдера.

Как получить ключ

1

Заведите ключ в личном кабинете провайдера

  1. 1 Зарегистрируйтесь на сайте провайдера (в примере — routerai.ru) и пополните счёт на небольшую сумму: для проб её хватит надолго.
  2. 2 В личном кабинете найдите раздел с ключами API и создайте ключ. Скопируйте его сразу: многие сервисы показывают ключ один раз.
  3. 3 Там же, в документации, найдите адрес API (у routerai.ru — https://routerai.ru/api/v1) и в каталоге — название модели.

Ключ — как пароль от кошелька: не пишите его в чат, в письма и в файлы папки кейса. Если ключ кто-то увидел — удалите его в кабинете и создайте новый.

Что выписать из кабинета провайдера
Адрес API:   https://routerai.ru/api/v1
Модель:      z-ai/glm-5.3
Ключ API:    скопирован, никому не показан
Адрес и модель — пример. У другого провайдера будут свои; ключ действует только у того провайдера, который его выдал.

Как подключить ключ и модель к Hermes

Путей два — смотря, есть ли ваш провайдер во встроенном списке Hermes. Откройте вкладку KEYS, раздел LLM PROVIDERS: нашли название провайдера — путь А, нет — путь Б.

Путь А. Провайдер есть в списке Hermes

Так подключаются крупные агрегаторы и разработчики моделей. Всё делается в панели.

  1. Вкладка KEYS → раздел LLM PROVIDERS → карточка провайдера: введите ключ и сохраните (ссылка Get key ведёт в кабинет провайдера).
  2. Вкладка MODELS → MAIN MODEL → CHANGE → провайдер слева, модель справа → Switch.
  3. Вкладка CHAT → New chat → привет.

Путь Б. Провайдера в списке нет

Так подключаются routerai.ru и любой сервис с адресом, совместимым с OpenAI. Hermes называет такой провайдер custom, в списках панели — Custom endpoint. Шаги — ниже.

1

Путь Б: адрес и модель прописывает агент

Адрес API и модель — три настройки Hermes: model.provider (значение custom), model.base_url и model.default. При установке их прописал Claude — по вашему ответу на вопрос о провайдере.

Сменить провайдера позже — напишите агенту (Claude в папке кейса или Hermes в чате панели): подключи Hermes к провайдеру: адрес https://…/v1, модель … — он выполнит три команды hermes config set и назовёт имя переменной для ключа. Те же настройки видны на вкладке CONFIG.

6Как пользоваться

Каждый раз: откройте в браузере http://127.0.0.1:9119 → вкладка CHAT → щёлкните по полю чата и пишите. Страница не открывается — панель не запущена: откройте окно PowerShell и выполните hermes dashboard (или настройте автозапуск).

Как понять, что отвечает Обозреватель, а не «просто Hermes»

Рабочая папкаВ блоке WORKSPACE справа от чата и в шапке разговора — путь к папке кейса. Это главный признак: в другой папке Hermes — обычный помощник.
Ответ на «помощь»Обозреватель перечислит своё: дайджест, отметки, «посмотри это», темы, страница.
НавыкиСчётчик skills в шапке разговора на четыре больше, чем на вкладке SKILLS: это навыки папки кейса.
Несколько ассистентовУ каждого — своя папка. В чате панели переключайте WORKSPACE и начинайте New chat; для отдельных ботов и настроек заведите каждому профиль на вкладке PROFILES.

Из чата. Справа от чата, под кнопкой New chat, — список прошлых разговоров: щёлкните нужный.

  1. 1 Вкладка SESSIONS.
  2. 2 Переключатель History. В режиме Overview показана только сводка — её строки не нажимаются.
  3. 3 В строке разговора нажмите значок ▷ (Resume in Chat). Соседние значки: карандаш — переименовать, стрелка вниз — сохранить в файл, корзина — удалить.

Память Обозревателя — не в разговорах, а в папке hub: в новом чате он так же знает ваш профиль, прошлые выпуски и отметки. Старый разговор нужен, только чтобы продолжить именно его.

Чего Обозреватель не делает

  • Не выдумывает: нет публикаций — так и скажет; у каждой есть ссылка.
  • Не отправляет ничего никому, кроме вас: карточку пересылаете вы.
  • Не просит ключи и пароли в чат и не читает их.
  • Не меняет темы, модели и расписание без вашего «да».
  • Не исполняет инструкции из текстов статей и пересланных постов: это данные, а не команды.

Установка обрывается на «Downloading Python»Установщик запущен внутри другого приложения. Откройте обычное окно PowerShell, выполните irm https://hermes-agent.nousresearch.com/install.ps1 | iex и напишите Claude «готово, продолжай».
Агент не знает, что он ОбозревательРабочая папка чата — не папка кейса: список WORKSPACE → «Other path…» → путь к папке → New chat (шаг 5).
Ошибка 401, 402, 404 в чатеКлюч, баланс или название модели — таблица в разделе 3.
Навыки папки не подключились (агент каждый раз долго читает файлы правил)Напишите агенту: подключи навыки этой папки: git init и hermes skills trust с полным путём.
Агент сделал один шаг настройки и ждётпродолжи настройку; чтобы не останавливался — полный запрос.
«Не могу искать в интернете»Не подключён веб-поиск: вкладка KEYS — ключ поискового сервиса.
Веб-панель перестала открыватьсяПанель не запущена (перезагрузка, закрыто окно): в PowerShell выполните hermes dashboard или настройте автозапуск. На шлюз и расписание это не влияет.
Прошлый разговор не открываетсяВкладка CHAT → список под кнопкой New chat, или SESSIONS → History → значок ▷ (снимок).
Задание по расписанию не сработалоВкладка CRON — журнал запуска; компьютер был выключен или шлюз не работал (Gateway Status внизу левой колонки).
