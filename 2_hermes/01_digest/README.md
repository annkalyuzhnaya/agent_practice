# Кейс 1 для Hermes. Обозреватель — дайджест по вашим темам

Тот же Обозреватель, что в версии для Claude, собранный для **Hermes Agent**: работает на вашем компьютере, на любых
моделях по ключу API, с окном чата (приложение Hermes Desktop или веб-панель), расписанием и ботом Telegram.
Собрал и дорабатывает его Claude; для ежедневной работы Claude не нужен.

Агент раз в неделю (или каждое утро) читает открытые источники и приносит до десяти публикаций: оценка релевантности
от 1 до 5, «почему это важно именно вам», ссылка на первоисточник, ТОП-3. Ваши отметки делают следующий выпуск точнее.

## Как это устроено

```
   профиль hub/profile.md                    очередь «посмотри это» (чат или Telegram)
            │                                          │
            ▼                                          ▼
   ┌────────────── редактор выпуска (навык digest) — основная модель ─────────────┐
   │  разведчики × N тем        ──►  сведение  ──►  проверяющий                   │
   │  delegate_task, параллельно                    отдельный запуск Hermes       │
   │  модель подешевле                              на другой модели              │
   └──────────────────────────────────┬───────────────────────────────────────────┘
                                      ▼
            выпуск hub/digest/ГГГГ-ММ-ДД.md  +  память «уже видел»
              │                  │                         │
              ▼                  ▼                         ▼
        чат Hermes         страница-файл             Telegram: ТОП-3
                           hub/page/digest.html      от задания cron
```

Какая модель исполняет какую роль, решаете вы: `hub/models.json`, плейбук `playbooks/06_models.md`. Выбор проверяется
приёмкой на учебном наборе, а не мнением.

## С чего начать

1. Новичку — [START.html](START.html) (открывается в браузере двойным щелчком): установку выполняет Claude по
   готовому запросу, дальше — снимки веб-панели: выбор провайдера и модели, ключ API, настройка словом «настрой»,
   подключения, типовые ситуации.
2. Коротко и для опытных — [SETUP.md](SETUP.md): установить Hermes, подключить модель, открыть эту папку, написать
   «настрой».
3. Фразы на каждый день — [GUIDE.md](GUIDE.md).
4. Задания уровня 4 — [LEVELS.md](LEVELS.md).

## Что в папке

| Путь | Что это |
|---|---|
| `playbooks/` | единственный источник правил: протокол, выпуск, настройка, страница, расписание, Telegram, модели |
| `AGENTS.md`, `.hermes/skills/` | собирает `python tools/build.py` из плейбуков — руками не править |
| `tools/build.py`, `setup.py`, `hermes.py`, `page.py` | свои для Hermes: сборка, рабочая папка, модели и расписание, страница |
| `tools/` остальное, `demo/`, `presets/hub/` (кроме файлов о среде) | общие с версией для Claude; переносит `python 2_hermes/sync.py` — руками не править |
| `presets/models.json` | заготовка «модель под роль» |
| `pack/` | навыки пака `internal-comms`, `build-dashboard` и их лицензии; кладёт `python skills_pack/sync.py` из корня курса — руками не править |
| `START.html` | руководство новичка; написано вручную, скриптами не собирается |
| `hub/` | ваши рабочие данные (создаётся при настройке, в git не попадает) |

## Для автора курса

Правило изменилось → `playbooks/` → `python tools/build.py`. Общий скрипт изменился в версии для Claude →
`python 2_hermes/sync.py`. Проверки: `python tools/build.py --check`, `python 2_hermes/sync.py --check`,
`python tools/evals.py --issue demo/пример_результата/digest/2026-10-02.md`.

**Что проверено, а что нет.** Скрипты, сборка навыков, страница и приёмка проверены на эталонном выпуске. Пробная
установка на Windows 11 (Hermes Agent 0.21.5, октябрь 2026 года) проверила шаги `SETUP.md` без модели: установку
командой, подключение навыков папки (`git init` + `hermes skills trust`), вкладки веб-панели, названия настроек
`hermes config set` и флаги `hermes cron create`, `hermes chat`. Не проверено: разговор с моделью (ключ вводит
владелец), делегирование, срабатывание cron, шлюз Telegram и приложение Hermes Desktop — его разделы названы по
документации.
