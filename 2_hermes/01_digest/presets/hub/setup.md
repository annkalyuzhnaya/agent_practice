# Настройка Обозревателя (Hermes)

Чек-лист ведёт агент по плейбуку настройки. Статусы: `не начат`, `сделано`, `отложено`, `недоступно в этой среде`.
Обязательны только шаги 0 и 1; к остальным можно вернуться в любой день словами «продолжи настройку».

Приветствие: не показано

| Шаг | Обязательность | Статус | Дата | Примечание |
|---|---|---|---|---|
| 0. Рабочая папка создана | обязательный | не начат | | |
| 1. Профиль: темы и источники | обязательный | не начат | | |
| 2. Модели под роли | необязательный | не начат | | |
| 3. Пробный выпуск | необязательный | не начат | | |
| 4. Страница «Дайджест» | необязательный | не начат | | |
| 5. Расписание | необязательный | не начат | | |
| 6. Telegram | необязательный | не начат | | |

## Что умеет среда

Заполняет агент перед первым шагом (раздел «Шаг 0» плейбука настройки).
