Трек Hermes · оркестратор

Один собеседник над несколькими ассистентами Hermes

Оркестратор — это Claude в папке 2_hermes/orchestrator. Сам тематическую работу он не делает: ставит задачи вашим ассистентам Hermes, забирает их результаты и сводит в один план дня. Вы пишете мой день одному собеседнику вместо того, чтобы открывать каждого ассистента по очереди.

Тяжёлую работу делают ассистенты Hermes на своих моделях — возможно, дешёвых или локальных. Claude только дирижирует, поэтому расход подписки небольшой.

План дняhub/plan/ГГГГ-ММ-ДД.md · главное, сегодня, на неделе, что решить вам

Каждый ассистент ведёт свою папку hub/. Оркестратор поднимает его командой hermes chat -q "задача" в его папке, читает новый файл и кладёт копию в свою hub/results/.

2Кем рулить, если ассистент пока один

Оркестратор имеет смысл от двух ассистентов. Для занятия хватит тех, что уже есть в практике:

АссистентОткудаЧто даёт в «мой день»
Обозреватель2_hermes/01_digest — руководствоТОП-3 публикаций по вашим темам
Универсальный помощник2_hermes/manual/templates — руководство (собирается руками за 15–20 минут)ваши задачи и заметки на сегодня
Любая роль из кейсов ClaudeClaude соберёт по BUILD.md: откройте 2_hermes в Claude Code — собери ассистента для Hermesразбор входящих, бриф к встрече, ответы по базе, документы
Ассистентов нет совсем — оркестратор скажет об этом честно и предложит собрать. За отсутствующего ассистента он работу не делает.

3Быстрый старт

1

Подготовьте ассистентов

Hermes установлен и хотя бы один ассистент отвечает в своей папке (общая инструкция трека Hermes). Папки ассистентов — вне agent_practice, например D:/Hermes/Обозреватель и D:/Hermes/Помощник.

2

Откройте папку оркестратора в Claude Code

Приложение Claude → вкладка Code → новая сессия → папка 2_hermes/orchestrator.

3

Напишите настрой

Два обязательных шага: профиль (что важно утром, рабочие часы) и реестр флота. Про каждого ассистента оркестратор спросит: роль, где живёт, путь к папке, модель (можно оставить модель Hermes по умолчанию), где лежит результат. Ключи он не спрашивает — они живут у Hermes.

4

Напишите мой день

Оркестратор поднимет ассистентов по порядку, соберёт план и покажет его в чате. Разрешайте запуск команд hermes chat … — это и есть «поднять ассистента». Первый прогон — несколько минут: каждый ассистент работает на своей модели.

5Подробнее — по желанию

Как выглядит реестр флота
{
  "assistants": [
    { "name": "обозреватель", "role": "digest", "where": "local",
      "path": "D:/Hermes/Обозреватель", "reads": "hub/digest/", "model": "" },
    { "name": "помощник", "role": "assistant", "where": "local",
      "path": "D:/Hermes/Помощник", "reads": "hub/", "model": "" }
  ]
}

Ведёт его оркестратор, руками править не нужно. Все поля — в playbooks/20_fleet.md. Проверить без запуска: python tools/fleet.py show напечатает флот и точную команду для каждого ассистента.

Чем отличается от личного ассистента на Claude
Личный ассистент (трек Claude)Оркестратор над Hermes
роли — субагенты Claude в одной сессиироли — отдельные ассистенты Hermes, каждый на своей модели
всё на подписке Claudeнагрузка — на моделях по ключу API; Claude только дирижирует
всё на этом компьютереассистенты могут быть удалёнными
одна папка hub/у каждого ассистента своя hub/; оркестратор сводит их в свою
Если что-то не так
ПризнакЧто сделать
«hermes не найден»Hermes не в PATH на этой машине: откройте новое окно или поставьте Hermes (общая инструкция)
«папка ассистента не найдена»путь в реестре не тот: проверь флот покажет, где ошибка
Ассистент ответил как обычная модельв его папке нет AGENTS.md или путь указывает не туда
Удалённый ассистент молчиторкестратор отметит в плане «не выполнено и почему» и поднимет остальных
Подробно: SETUP.md — настройка, GUIDE.md — фразы, LEVELS.md — уровни, playbooks/ — правила оркестратора.
