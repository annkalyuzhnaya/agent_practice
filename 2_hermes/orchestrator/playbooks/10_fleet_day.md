# «Мой день» над флотом — комплексный сценарий

Оркестратор поднимает нужных ассистентов флота в правильном порядке и собирает из их выпусков один план дня.
Каждый ассистент работает по своим правилам в своей папке; оркестратор только ставит задачу и забирает результат.

```
  0 осмотр шины и флота
        │
        ├─► 1 Обозреватель (digest) ──┐
        ├─► 2 Входящие (inbox) ───────┤  независимые — можно поднимать подряд,
        │                             │  не дожидаясь ответа предыдущего
        ▼                             ▼
  3 Встреча (meeting) ← учитывает дайджест и разбор входящих
        │
        ▼
  4 Документ-инженер (docs) ← по заявкам из разбора входящих
        │
        ▼
  5 База знаний (kb) ← принять всё созданное
        │
        ▼
  6 План дня → человек решает
```

## Шаги

0. **Осмотр.** Прочитай `hub/profile.md`, `hub/fleet.json`, `hub/tasks.md`, последний план в `hub/plan/`.
   Определи среду по `hub/setup.md`. Реши, кто из флота нужен сегодня (по профилю и наличию входных данных).
1. **Поднимаешь каждого нужного ассистента** по `20_fleet.md`: ставишь задачу, забираешь свежий выпуск с его шины
   (локально, по SSH или из общей папки), кладёшь копию в `hub/results/ГГГГ-ММ-ДД_<role>.md`.
   - Ассистент работает по расписанию и уже сделал выпуск сегодня — не поднимай повторно, просто забери выпуск.
   - Ассистента нет во флоте для какой-то роли — пропусти шаг и отметь в плане «нет ассистента для …».
2. **Порядок.** Сначала независимые (дайджест, входящие). Затем те, кто опирается на них: встреча учитывает свежий
   дайджест и разбор входящих; документ-инженер — заявки из разбора; база знаний принимает всё созданное последней.
3. **Сбой.** Ассистент недоступен (папки нет, хост молчит, `hermes` не найден) — не выдумывай за него: запиши
   в плане «не выполнено и почему», оставь заявку в `hub/handoff/`, иди дальше.
4. **План дня** `hub/plan/ГГГГ-ММ-ДД.md`:
   - **Главное за 30 секунд** — 3 строки.
   - **Сегодня / На неделе / Делегировать** — из принесённых разборов и `hub/tasks.md`.
   - **Требует моего решения** — всё, что ассистенты пометили `[РЕШИТЬ]`, открытые противоречия базы.
   - **Встречи** — ссылки на брифы (из `results/`).
   - **ТОП-3 дайджеста.**
   - **Принёс от флота** — таблица: ассистент · что принёс · где запущен · ссылка на `results/`.
   - **Не выполнено и почему** — кто из флота не ответил.
   - **Что остаётся человеку.**
5. **Бортжурнал** — одна строка в `hub/journal.md` на весь сценарий.

## Правила оркестратора

- Ты дирижёр: сам роль ассистента не исполняешь. Нет ассистента для роли — честно напиши, не делай его работу за него
  (иначе теряется смысл флота и экономии). Исключение — мелкая сводка по уже принесённым файлам, это твоя работа.
- Задачу ассистенту формулируй полно и один раз: он тебя не переспросит (дочерний процесс без твоего контекста).
- Что в среде недоступно (SSH, общая папка) — бери из таблицы «Среда» `hub/setup.md`, не пробуй вслепую.
- Сценарий можно запускать несколько раз в день: уже принесённое не тяни заново, бери только новое.
- В итоговом сообщении покажи план прямо в чате: «Главное», «Сегодня», «Требует моего решения» — полностью,
  остальное по строке; путь к файлу плана — в конце. Дальше веди разговор по `11_chat.md`.
