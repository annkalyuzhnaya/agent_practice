# Настройка оркестратора над флотом Hermes

Оркестратор — это Claude в этой папке. Он не делает тематическую работу сам, а дирижирует **флотом** — тематическими
ассистентами Hermes (трек 3), каждый в своей папке со своей моделью. Оркестратор ставит им задачи, забирает выпуски
и собирает из них один «План дня».

> Что это за трек и чем отличается от трека 2 (оркестратор над клодовыми ассистентами) — в `README.md`.
> Перед настройкой стоит иметь хотя бы одного собранного Hermes-ассистента (трек 3, `../BUILD.md`).

## С чего начать

Откройте эту папку (`2_hermes/orchestrator/`) как проект в Claude Code и напишите в чат **«настрой»**.
Дальше оркестратор ведёт вас формами — вы только отвечаете. Руками в файлы лезть не нужно.

## Что произойдёт при настройке

1. **Шина.** Если `hub/` ещё нет, оркестратор создаст её из `presets/hub/` (профиль, пустой реестр флота, чек-лист,
   журнал, папки `results/`, `plan/`, `handoff/`). Личных данных в git нет — `hub/` не коммитится.
2. **Профиль (шаг обязательный).** Форма: ваша роль, что важно утром, темы, кому делегируете, рабочие часы, тон.
   Ответы оркестратор запишет в `hub/profile.md`.
3. **Реестр флота (шаг обязательный).** Оркестратор спросит про каждого ассистента: роль (дайджест / входящие /
   встреча / документы / база знаний / свой), где он живёт (эта машина или удалённо), путь к папке, модель и провайдер
   (можно оставить модель Hermes по умолчанию), как забирать результат. Запишет в `hub/fleet.json` (формат — в
   `playbooks/20_fleet.md`). Образец с одним ассистентом уже лежит в пресете — поправьте путь под свою систему.
4. **Проверка среды.** Оркестратор сам определит, есть ли `python` и `hermes` в PATH, доступны ли SSH и общая папка,
   и запишет это в таблицу «Среда» `hub/setup.md`. Дальше он не предложит того, чего в среде нет.
5. **Проверка флота (по желанию).** `python tools/fleet.py check` — для локальных ассистентов проверит, что папки на
   месте и `hermes` найден; для удалённых проверку подключения оркестратор сделает только после вашего «да».

## Как убедиться, что всё на месте

```bash
python tools/fleet.py show
```

Команда распечатает флот и точную строку запуска для каждого ассистента. Ничего не запускает — только показывает.

```bash
python tools/fleet.py check
```

Проверит среду и пути. «hermes НЕ найден» — значит Hermes не в PATH: локальных ассистентов не поднять, пока это
не поправить (оркестратор подскажет, где именно).

## Первый «Мой день»

Напишите **«мой день»**. Оркестратор по `playbooks/10_fleet_day.md` поднимет нужных ассистентов флота по порядку,
забёрет их выпуски в `hub/results/`, соберёт один план в `hub/plan/ГГГГ-ММ-ДД.md` и покажет его прямо в чате.
Нет ни одного ассистента во флоте — он честно скажет и предложит собрать (трек 3) или добавить существующего.

## Удалённые ассистенты

Если ассистент живёт на другой машине — настройте доступ по `playbooks/30_remote.md` (SSH, общая синхронизируемая
папка или Telegram-доставка) и запишите разрешения в `hub/accounts.md`. Удалённые команды оркестратор запускает
только после вашего «да» на точный текст. Ключи и пароли он не хранит и не просит.

## Чего оркестратор не делает

- Не исполняет тематическую работу за отсутствующего ассистента — честно пишет «нет ассистента для …».
- Ничего наружу без «да»: SSH-команды, чужой cron, письма, публикация.
- Не читает и не просит ключи API; `.env` ассистентов и `hub/.secrets/` не открывает.
- Не коммитит `hub/` в git.
