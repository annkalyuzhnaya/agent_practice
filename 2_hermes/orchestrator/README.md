# Трек 4. Личный помощник-оркестратор над ассистентами Hermes

Тот же замысел, что у «Личного ассистента» на Claude (`1_claude/06_assistant`), но роли исполняют **тематические
ассистенты Hermes** — те, что собраны в треке 3 (`2_hermes/01_digest` и другие). Они работают на своих моделях
по ключу API, могут жить на этом компьютере или быть **развёрнуты удалённо** (на домашнем сервере, втором компьютере,
в виртуальной машине). Оркестратор — один собеседник в Claude Code: он раскладывает задачу по ассистентам флота,
собирает их результаты на общую шину и выдаёт один план дня.

> **Новичку:** [START.html](START.html) — руководство (открывается двойным щелчком). **Начать:** [SETUP.md](SETUP.md) — собрать флот и подключить его. **Как пользоваться:** [GUIDE.md](GUIDE.md).
> **Куда расти:** [LEVELS.md](LEVELS.md).

## Зачем это

У тематических ассистентов Hermes каждый сам по себе: у каждого своя папка, свой чат, своё расписание. Оркестратор
даёт то, чего нет у отдельного ассистента, — **единую точку входа и общий план**. Вы пишете «мой день» одному
собеседнику, а он сам решает, кого из флота поднять, в каком порядке, и сводит ответы в один список.

Claude здесь — **дирижёр**, а не исполнитель: тяжёлую работу (дайджест, разбор почты, документы) делают ассистенты
Hermes на своих — возможно, дешёвых или локальных — моделях; Claude только ставит задачи, собирает результаты
и разговаривает с владельцем. Поэтому оркестратор экономен по расходу Claude и переносит основную нагрузку на флот.

## Как это устроено

```
                    вы ─ чат в Claude Code ─ Оркестратор
                                │
            ┌───────────────────┼───────────────────────┐
            ▼                   ▼                         ▼
   локальный ассистент   локальный ассистент     удалённый ассистент
   hermes chat -q …       hermes chat -q …         ssh host 'hermes …'
   (его папка = cwd)       (его папка = cwd)        или через Telegram/папку
            │                   │                         │
            └──────── каждый пишет в СВОЮ hub/ ───────────┘
                                │
                    оркестратор забирает свежие файлы
                                ▼
                    общая шина hub/  (этой папки)
                    profile · fleet.json · tasks · plan · journal · results · handoff
                                ▼
                       один план дня → вы решаете
```

- **Флот** — список ассистентов в `hub/fleet.json`: имя, роль, где живёт (локальная папка или удалённый хост),
  как вызвать, какая модель, как доставляет результат. Ведёт его оркестратор; правила — `playbooks/20_fleet.md`.
- **Шина `hub/`** этой папки — общая память оркестратора: профиль, задачи, планы, журнал и папка `results/`, куда
  он складывает то, что принёс от ассистентов. Каждый ассистент при этом ведёт **свою** шину в своей папке —
  оркестратор читает её и забирает нужное.
- **Удалённые ассистенты** подключаются по `playbooks/30_remote.md`: через SSH (оркестратор запускает `hermes`
  на том хосте), через общую синхронизируемую папку (облачный диск) или через Telegram-доставку. Что доступно
  в вашей среде — оркестратор определяет при настройке и записывает в `hub/setup.md`.

## Чем это отличается от оркестратора на Claude (трек 2)

| Трек 2 (`1_claude/06_assistant`) | Трек 4 (эта папка) |
|---|---|
| роли — субагенты Claude в одной сессии | роли — отдельные процессы Hermes, каждый на своей модели |
| всё на подписке Claude | основная нагрузка — на моделях флота по ключу API; Claude только дирижирует |
| все агенты на этом компьютере | ассистенты могут быть удалёнными (SSH, общая папка, Telegram) |
| связь — шина `hub/` одной папки | у каждого ассистента своя `hub/`; оркестратор сводит их в свою `hub/` |
| расписание — задачи claude.ai | расписание — `hermes cron` у каждого ассистента + оркестратор сводит их выпуски |

## Что в папке

| Путь | Что это |
|---|---|
| `playbooks/` | правила оркестратора: протокол шины, чат, «мой день» над флотом, реестр флота, удалённые ассистенты |
| `CLAUDE.md` | правила для Claude Code в папке ассистента (роль — оркестратор) |
| `tools/fleet.py` | показывает флот и печатает точные команды вызова каждого ассистента (локально и по SSH) |
| `presets/hub/` | заготовки шины: `fleet.json`, профиль, пустые `tasks.md`, `plan/`, `results/` |
| `SETUP.md`, `GUIDE.md`, `LEVELS.md` | установка, ежедневные фразы, уровни |
| `hub/` | ваши рабочие данные (создаётся при настройке, в git не попадает) |

## Что остаётся за владельцем

Оркестратор готовит и сводит — решения ваши. Письма и сообщения — только черновики; запуск удалённых команд, cron
и публикация — после явного «да». Ключи API живут у Hermes на каждой машине; Claude их не спрашивает и не читает.
