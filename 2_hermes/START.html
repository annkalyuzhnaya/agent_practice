Агент на Hermes: любые модели по ключу API

Одна инструкция для любого ассистента на Hermes: готового Обозревателя, универсального помощника, любой роли из кейсов Claude или своего агента. Hermes ставится один раз; дальше каждый ассистент — это своя папка с правилами.

Hermes Agent — открытая программа-агент на вашем компьютере. Подписка Claude для ежедневной работы не нужна: вы платите провайдеру модели за фактический расход.

1Принцип за минуту

Тот же, что в треке Claude, — меняется только программа и формат правил.

Папка ассистентаправила AGENTS.md (и навыки .hermes/skills/)
→
Hermesоткрыт в этой папке, читает правила
→
Модель по ключулюбой провайдер; можно разные модели на разные роли
→
Ваши данныев hub/ — того же формата, что у кейсов Claude

Что лежит в папках и как выглядят исходные файлы — на странице «С чем будем работать?».

2Поставить Hermes и подключить модель — один раз

1

Установите Hermes

Откройте отдельное окно PowerShell из «Пуска» (не терминал внутри другой программы) и вставьте:

irm https://hermes-agent.nousresearch.com/install.ps1 | iex

macOS — в Терминале: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | sh. Установка идёт 5–15 минут. Затем откройте новое окно и проверьте: hermes --version.

2

Откройте окно Hermes

hermes dashboard — откроется веб-панель http://127.0.0.1:9119. Пока окно команд открыто, панель работает.

3

Введите ключ модели

На занятии адрес, модель и ключ выдаст ведущий. Ключ вводится только в окне Hermes, не в чат:

  • провайдер из списка Hermes — вкладка Keys → раздел LLM Providers → карточка провайдера → ключ → Save;
  • свой адрес, совместимый с OpenAI, — три команды и ключ в переменной по имени сайта (routerai.ru → ROUTERAI_API_KEY): Keys → внизу Add a custom key.
hermes config set model.provider custom
hermes config set model.base_url "<адрес API>"
hermes config set model.default "<модель>"

Проверка: вкладка Chat → New chat → привет. Ответила — всё подключено. Ошибки 401 / 402 / 404 и как выбрать своего провайдера — руководство Обозревателя, раздел 3.

Не хочу вводить команды — поручить установку Claude

Откройте папку ассистента (шаг 3 ниже) в Claude Code и вставьте:

Установи Hermes Agent на этот компьютер и подключи к нему эту папку. Все команды выполняй сам.
1. Проверь hermes --version; нет — установи: irm https://hermes-agent.nousresearch.com/install.ps1 | iex
   (если обрывается на «Downloading Python» — запусти в отдельном окне PowerShell).
2. Если эта папка лежит внутри другого проекта git — спроси меня, куда её скопировать, скопируй и работай в копии.
3. hermes config set terminal.cwd "<полный путь к папке>".
4. Спроси у меня адрес API и модель и пропиши их (model.provider custom, model.base_url, model.default).
5. Ключ не спрашивай и не читай: назови имя переменной, куда я введу его на вкладке Keys.
6. Запусти веб-панель: hermes dashboard --no-open — и проверь, что http://127.0.0.1:9119 отвечает.
В конце — короткий отчёт: что сделано, что осталось мне.

Для Обозревателя есть готовый подробный запрос — в его руководстве, раздел 2.

4Подключите папку и начните

1

Скопируйте папку ассистента в постоянное место — вне agent_practice

Например, D:\Hermes\Обозреватель. Внутри скачанной практики Hermes ищет навыки не в папке ассистента, а в корне всей практики — и не находит.

2

Сделайте её рабочей папкой Hermes

hermes config set terminal.cwd "D:/Hermes/Обозреватель"

Или в окне Hermes: Chat → список Workspace слева → Other path… → путь к папке. Затем New chat.

3

Напишите настрой

Ассистент прочитает AGENTS.md, расспросит вас и создаст hub/. Проверка, что папка подхватилась: на кто ты? он называет свою роль, а не отвечает как обычная модель.

Навыки папки (по желанию): чтобы ассистент чётче держал роль

Правила из AGENTS.md работают и без этого. Навыки из .hermes/skills/ Hermes подключает, если папка — проект git и вы ей доверяете. В папке ассистента:

git init
hermes skills trust "D:/Hermes/Обозреватель"

Проверка: hermes skills list — навыки папки с пометкой project. git init делайте в самой папке ассистента, даже если рядом есть другой проект git.

5Подключить правила кейса Claude

Правила ролей уже написаны и проверены в треке Claude. Любому ассистенту Hermes — например, универсальному помощнику — можно добавить роль оттуда без Claude и без сборки.

1

Скопируйте два файла правил

В папке ассистента создайте папку правила и скопируйте в неё из agent_practice\1_claude\<кейс>\playbooks\:

  • 00_protocol.md — общие правила кейса и карта папки hub/;
  • плейбук роли: 01_digest.md, 02_kb.md, 03_meeting.md, 04_inbox.md или 05_docs.md.
2

Допишите в конец AGENTS.md (Блокнотом)

## Дополнительная роль: Входящие
Когда я прошу разобрать письма или сообщения — прочитай правила/00_protocol.md
и правила/04_inbox.md и действуй по ним.
Эти правила написаны для Claude. Субагентов у тебя нет — выполняй роли сам,
отдельными проходами. Формы с вариантами заменяй вопросом с нумерованными
вариантами. Если правило требует скрипта из tools/, которого здесь нет, —
сделай шаг вручную или прямо скажи, что он недоступен.

Название роли, слова-поводы и имя плейбука замените на свои.

3

Новый чат — и попробуйте

Например, вставьте письмо и напишите разбери. Учебные данные кейса лежат в 1_claude/<кейс>/demo/ — их можно скопировать в hub/ ассистента.

Так переносятся правила, но не скрипты и не независимый проверяющий: это упрощённый способ «попробовать роль». Полный перенос со всеми механизмами делает Claude по BUILD.md — третья карточка в разделе 3.
