# Руководство: собрать личного помощника на Hermes руками

Это руководство для тех, кто **не программист**. Мы соберём универсального личного помощника на Hermes Agent —
без Claude, своими руками. Claude в этом треке не участвует: всё, что нужно, вы сделаете сами по шагам ниже.
Каждый шаг говорит *что* делать, *в каком окне или папке*, *что именно вставить* и *что должно получиться*.

Получится помощник, который ведёт ваши задачи и заметки, отвечает на вопросы, готовит черновики и (если подключить
веб-поиск) ищет в интернете. Это «универсальный» помощник: не привязан к одной теме, в отличие от тематических
ассистентов трека 3.

> **Сколько времени.** Первая установка Hermes — 15–30 минут (большую часть ждёте загрузку). Сборка самого помощника
> по готовым заготовкам — ещё 15–20 минут.
>
> **Что понадобится.** Компьютер с Windows или macOS, интернет и ключ API какой-нибудь модели (как получить — шаг 5).
> Платить за подписку Claude не нужно: помощник работает на выбранной вами модели, вы платите её провайдеру за
> фактический расход.

## Два окна, между которыми вы будете переключаться

Всю дорогу встречаются два разных окна. Запомните их названия — дальше я называю их именно так:

- **Окно команд** — чёрное/синее окно, где команды печатают текстом и жмут Enter. На Windows это **PowerShell**,
  на macOS — **Терминал**. Как открыть — шаг 1. В нём мы установим Hermes и дадим несколько команд.
- **Окно Hermes** — это **веб-панель Hermes**: обычная страница в браузере с вкладками (Chat, Keys, Models и др.).
  В нём вы вводите ключ модели и разговариваете с помощником. Как открыть — шаг 5.

Когда в шаге написано «в окне команд» — печатайте в PowerShell/Терминале. «В окне Hermes» — работайте в браузере
на странице Hermes. Это разные окна, не перепутайте.

### Ещё три слова

- **Папка** — то же, что папка в проводнике. У помощника будет своя папка, внутри — файлы с его правилами и память.
- **Текстовый файл** — файлы `.md` и `.json`. Это просто текст, открываются Блокнотом. Ни Word, ни особых программ.
- **Команда** — одна строка, которую вы вставляете в окно команд и жмёте Enter. Копируйте строку **целиком**.

Застряли — в конце есть раздел **«Если что-то пошло не так»**.

## Шаг 1. Открыть окно команд

### Windows

1. Нажмите клавишу **Win** (значок Windows на клавиатуре) — откроется меню «Пуск».
2. Наберите на клавиатуре слово `PowerShell`.
3. В списке сверху появится **Windows PowerShell**. Щёлкните по нему. Откроется окно с текстом и мигающим
   курсором — это и есть **окно команд**.

> Откройте именно **отдельное окно PowerShell из «Пуска»**, а не встроенный терминал внутри другой программы
> (например, внутри Claude Desktop из Microsoft Store): иначе установка Hermes может оборваться с ошибкой про
> «Downloading Python».

### macOS

1. Нажмите **Cmd + Пробел** — откроется поиск Spotlight.
2. Наберите `Терминал` (или `Terminal`), нажмите Enter. Откроется **окно команд**.

### Как с ним работать

- Вы **вставляете одну строку и жмёте Enter**. Программа выполняет её и пишет ответ ниже.
- **Вставить скопированное:** в PowerShell — щёлкните правой кнопкой мыши по окну (текст из буфера вставится сам),
  или Ctrl+V. В Терминале macOS — Cmd+V.
- Ничего из команд этого руководства не ломает компьютер. Худшее при опечатке — сообщение об ошибке; прочитали,
  вставили строку заново.

Проверим, что окно слушается. Вставьте строку и нажмите Enter:

```
echo привет
```

Окно должно ответить `привет`. Ответило — идём дальше. **Это окно команд не закрывайте**, оно понадобится в шаге 2.

## Шаг 2. Установить Hermes

**Windows.** В **окне команд** (том, что открыли в шаге 1) вставьте одну строку и нажмите Enter:

```
irm https://hermes-agent.nousresearch.com/install.ps1 | iex
```

**macOS.** В окне команд вставьте:

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | sh
```

Дальше установщик работает сам 5–15 минут: он скачивает всё, что нужно Hermes (свой Python, браузер для чтения
страниц и прочее). В окне будут бежать строки — это нормально. Дождитесь, пока внизу снова появится обычный
курсор и строка-приглашение (значит, установка закончилась).

Теперь важный момент: **закройте это окно команд (крестиком) и откройте новое — таким же способом, как в шаге 1**
(Пуск → `PowerShell`, или Spotlight → `Терминал`). Новое окно нужно, потому что команда `hermes` становится видна
только во вновь открытых окнах команд.

В **новом окне команд** вставьте и нажмите Enter:

```
hermes --version
```

Должна появиться строка с номером версии, например `0.21.5`. Появилась — Hermes установлен. Это новое окно команд
тоже держите открытым.

> Можно поставить и приложение **Hermes Desktop** (установщик с <https://hermes-agent.nousresearch.com/>) — удобное
> окно с чатом. Но для сборки помощника достаточно окна команд и веб-панели, их и опишем.

## Шаг 3. Создать папку помощника и положить в неё заготовки

У помощника будет **своя папка** на диске. Внутри — файл с его правилами (`AGENTS.md`) и память (папка `hub`).
Готовые заготовки уже лежат в папке `templates/` рядом с этим руководством — их надо скопировать в новую папку.

Делаем это **в проводнике** (не в окне команд):

1. Откройте проводник: на Windows — «Этот компьютер» (значок папки на панели задач), на macOS — Finder.
2. Выберите место, где будет жить помощник, — например, диск `D:` на Windows или папку «Документы» на macOS.
   **Не кладите** папку внутрь другого проекта с программным кодом.
3. Создайте там новую папку: правой кнопкой мыши по пустому месту → **Создать** → **Папку**. Назовите её латиницей,
   например `my-assistant` (кириллицу в имени папки лучше не использовать).
4. В другом окне проводника откройте папку `templates/` из этого трека (путь:
   `2_hermes/manual/templates/`). Выделите **всё её содержимое**: файл `AGENTS.md`, папку `hub` и папку `.hermes`
   (выделить всё — Ctrl+A; на macOS Cmd+A). Скопируйте (Ctrl+C / Cmd+C).
5. Вернитесь в вашу новую папку `my-assistant` и вставьте (Ctrl+V / Cmd+V).

Папка `.hermes` начинается с точки и может быть скрыта. Показать скрытые файлы: в проводнике Windows — вкладка
**Вид** вверху → галочка **Скрытые элементы**; в Finder на macOS — нажмите **Cmd + Shift + точка**.

**Проверка.** Откройте вашу папку `my-assistant`. Внутри должны лежать: файл **AGENTS.md**, папка **hub**
(а в ней `profile.md`, `tasks.md`, `journal.md`, `models.json`, папки `notes` и `drafts`) и папка **.hermes**.
Всё на месте — идём дальше.

---

> ### 📋 Как узнать путь к вашей папке (понадобится дальше)
>
> В шагах 6 и 8 нужно будет указать Hermes, **где** лежит ваша папка, — то есть её «путь». Путь выглядит так:
> `D:/my-assistant` (Windows) или `/Users/имя/Documents/my-assistant` (macOS). Вот как его получить, не печатая вручную:
>
> **Windows:** откройте проводник, найдите папку `my-assistant`. Удерживая клавишу **Shift**, щёлкните по папке
> **правой** кнопкой мыши → в меню выберите **«Копировать как путь»**. Путь скопируется в буфер — потом вставите
> его Ctrl+V куда нужно.
> *Важно:* Windows копирует путь с обратными косыми чертами и кавычками, например `"D:\my-assistant"`. В командах
> Hermes замените обратные `\` на прямые `/` и уберите кавычки из скопированного (кавычки в самих командах уже
> проставлены). То есть `"D:\my-assistant"` превращается в `D:/my-assistant`.
>
> **macOS:** щёлкните по папке правой кнопкой, затем **зажмите клавишу Option (⌥)** — пункт меню сменится на
> **«Скопировать "my-assistant" как путь»**. Путь скопируется; косые черты там уже прямые, менять ничего не надо.
>
> Запишите этот путь на бумажке или держите в буфере — он нужен в шагах 6 и 8. Дальше я пишу его как
> `ВАШ_ПУТЬ` — подставляйте вместо него свой.

## Шаг 4. Вписать в профиль, кто вы

Помощник станет «вашим», когда вы впишете в его профиль, кто вы. Это обычный текстовый файл — правим Блокнотом.

1. В проводнике откройте вашу папку `my-assistant`, зайдите внутрь в папку **`hub`**.
2. Найдите там файл **`profile.md`**.
3. Щёлкните по нему **правой** кнопкой мыши → **Открыть с помощью** → **Блокнот**
   (на macOS: правой кнопкой → **Открыть в программе** → **TextEdit**).
4. В файле после двоеточий впишите: ваше имя, чем занимаетесь, на «ты» или на «вы» хотите общаться. Остальное
   можно оставить как есть.
5. Сохраните: **Ctrl+S** (на macOS **Cmd+S**) и закройте Блокнот.

Файлы `tasks.md` и `journal.md` в той же папке трогать не нужно — помощник заполнит их сам. Файл `AGENTS.md`
в корне папки тоже менять не обязательно: он уже описывает универсального помощника. Захотите позже поменять
его характер — откроете `AGENTS.md` тем же Блокнотом и поправите словами; никакую «сборку» запускать не надо.

> Почему Блокнот, а не Word: файлы `.md` — чистый текст. Word добавляет своё оформление и может их испортить.
> Блокнот (Windows) и TextEdit (macOS) сохраняют как есть. Привыкнете — бесплатный редактор **VS Code** удобнее,
> но он не обязателен.

## Шаг 5. Открыть окно Hermes и подключить модель

Чтобы помощник заговорил, Hermes нужно подключить к языковой модели по ключу API. Ключ — длинная строка-пароль
от провайдера модели. **Ключ вводится только в окно Hermes (браузер), никогда не в чат помощнику.**

### 5.1. Открыть окно Hermes (веб-панель)

В **окне команд** (том новом, что открыли в шаге 2) вставьте и нажмите Enter:

```
hermes dashboard
```

Окно команд напишет адрес и само откроет браузер на странице `http://127.0.0.1:9119`. Эта страница в браузере
и есть **окно Hermes** — с вкладками сверху (Chat, Keys, Models и другими).

> **Не закрывайте окно команд, из которого запустили `hermes dashboard`** — пока оно открыто, окно Hermes работает.
> Закроете окно команд — страница Hermes перестанет отвечать (не страшно: откроете снова той же командой).

### 5.2. Получить ключ модели

Нужен аккаунт у провайдера, к которому Hermes умеет подключаться (агрегатор моделей или прямой доступ к разработчику
модели). Зарегистрируйтесь у выбранного провайдера, пополните баланс и создайте **API key** в его личном кабинете —
получите строку вида `sk-...`. Скопируйте её.

> Какой провайдер взять для начала — любой популярный агрегатор, где по одному ключу доступно много моделей.
> На старте хватит одной модели среднего уровня.

### 5.3. Вставить ключ в окно Hermes

1. В окне Hermes (браузер) щёлкните по вкладке **Keys** вверху.
2. Найдите в списке вашего провайдера, вставьте ключ в его поле и нажмите **Save** (Сохранить).
3. Перейдите на вкладку **Models** и выберите модель по умолчанию: Main model → **Change** → выберите модель.

**Проверка.** В окне Hermes откройте вкладку **Chat** и напишите в поле внизу `привет`. Модель должна ответить.
Ответила — ключ подключён. Если вместо ответа ошибка: **401** — ключ неверный или не сохранён; **402** — на балансе
у провайдера нет денег; **404** — выбрана модель, которой у провайдера нет.

## Шаг 6. Указать Hermes вашу папку

Сейчас Hermes отвечает «вообще», как обычная модель. Чтобы он стал **вашим помощником**, надо указать ему работать
в вашей папке — тогда он прочитает `AGENTS.md` и начнёт вести вашу память в `hub/`.

Сделаем это командой. В **окне команд** вставьте строку, но **вместо `ВАШ_ПУТЬ` подставьте путь к вашей папке**
(как его получить — в рамке 📋 после шага 3). Кавычки оставьте:

```
hermes config set terminal.cwd "ВАШ_ПУТЬ"
```

Пример, как это выглядит в готовом виде на Windows (у вас путь будет свой):

```
hermes config set terminal.cwd "D:/my-assistant"
```

Нажмите Enter. Окно команд коротко подтвердит, что настройка записана (например, напечатает `terminal.cwd` и путь).

Теперь откройте окно Hermes заново, чтобы оно подхватило папку: закройте вкладку браузера с Hermes и в окне команд
снова дайте `hermes dashboard`. (Либо в окне Hermes на вкладке **Chat** слева в списке **Workspace** выберите
**Other path…** и вставьте туда ВАШ_ПУТЬ — это то же самое, но мышкой.)

**Проверка** — в следующем шаге: помощник должен представиться как помощник, а не как обычная модель.

## Шаг 7. Первый разговор

В окне Hermes откройте вкладку **Chat**. Вверху страницы должно быть видно, что рабочая папка — ваша `my-assistant`
(если там другая папка — вернитесь к шагу 6). В поле ввода внизу напишите:

```
Привет! Представься: кто ты и что умеешь?
```

Помощник должен ответить, что он ваш личный помощник, и перечислить, что умеет (вести задачи и заметки, готовить
черновики и т. д.). Это значит, что он прочитал `AGENTS.md` из вашей папки. Если он отвечает как обычная
безымянная модель — папка не подхватилась, вернитесь к шагу 6.

Теперь проверим память. Напишите по очереди (каждую строку — отдельным сообщением):

- `Запиши задачу: позвонить в банк в четверг.` — помощник добавит строку в файл `hub/tasks.md`.
- `Запомни, что мой проект называется «Весна» и стартует 1 ноября.` — создаст заметку в папке `hub/notes/`.
- `Какие у меня задачи?` — перечислит то, что записал.

Загляните проводником в вашу папку `my-assistant` → `hub`: в `tasks.md` появилась задача, в `notes/` — файл
с заметкой. Помощник работает и помнит между разговорами. **Базовый помощник готов.**

## Что дальше (всё по желанию)

Базовый помощник уже работает. Ниже — необязательные улучшения; делайте, что нужно.

### Включить навык (чтобы помощник был «сообразительнее»)

В заготовках есть **навык** `assistant` (папка `.hermes/skills/assistant`) — это те же правила помощника, собранные
так, чтобы Hermes подхватывал их автоматически в начале разговора. **Для работы помощника это не обязательно:** он
и так читает правила из `AGENTS.md`. Навык просто помогает модели чётче держать роль.

Чтобы Hermes доверял навыку из вашей папки, папка должна быть «проектом Git». **Git — отдельная бесплатная
программа, и для самого Hermes она не нужна — только для этого необязательного шага.** Если хотите:

1. Поставьте Git: Windows — установщик с <https://git-scm.com/> (в установщике везде **Next**, в конце **Install**);
   macOS — в окне команд дайте `git --version`, система сама предложит установить, согласитесь.
   После установки **закройте окно команд и откройте новое** (новые программы видны только в новых окнах).
2. В новом окне команд дайте **две команды по очереди**, подставив ВАШ_ПУТЬ (кавычки оставьте):

   ```
   git -C "ВАШ_ПУТЬ" init
   ```
   ```
   hermes skills trust "ВАШ_ПУТЬ"
   ```

   Первая делает папку «проектом Git», вторая разрешает Hermes пользоваться навыком из неё.
3. Проверка: дайте `hermes skills list` — в списке должен появиться навык **assistant** с пометкой `project`.

Если `hermes skills trust` отвечает «Not inside a git checkout» — значит первая команда не отработала: проверьте,
что ВАШ_ПУТЬ указан верно (с прямыми `/`), и повторите обе.

### Остальные улучшения

- **Поиск в интернете** — в окне Hermes, вкладка **Keys**, добавьте ключ одного из поисковых сервисов
  (Tavily, Exa, Firecrawl или Brave). Без него помощник отвечает только по своим знаниям и вашим заметкам.
- **Работа по расписанию и в фоне** — поставьте фоновую службу Hermes (шлюз) в автозапуск: в окне команд
  `hermes gateway install --start-now --start-on-login` (на Windows спросит разрешение администратора). Тогда
  можно просить «каждое утро собирай список задач на день» (в окне Hermes — раздел **Cron**).
- **Писать помощнику из Telegram** — в окне Hermes вкладка **Channels** → Telegram → Quick setup. Бот станет
  вторым окном того же помощника.
- **Приложение Hermes Desktop** — то же самое в виде отдельного приложения вместо веб-панели в браузере.
- **Поменять характер помощника** — откройте `AGENTS.md` (в корне вашей папки) Блокнотом и правьте правила словами.
  Нужен узкий тематический ассистент (дайджест, разбор почты и т. п.) — это трек 3, там помощника соберёт Claude.

## Если что-то пошло не так

| Признак | Что сделать |
|---|---|
| `hermes` «не является командой» сразу после установки | закройте окно команд и откройте новое (шаг 2) |
| Установка Hermes оборвалась на «Downloading Python» | запускайте установщик в отдельном окне PowerShell из «Пуска», не внутри другой программы (шаг 1) |
| Помощник отвечает как обычная модель, не как помощник | окно Hermes работает не в вашей папке — повторите шаг 6 и переоткройте окно Hermes |
| Модель молчит, ошибка **401** | ключ на вкладке Keys неверный или не сохранён (шаг 5.3) |
| Модель молчит, ошибка **402** | на балансе у провайдера нет денег |
| Окно Hermes (веб-панель) перестало открываться | вы закрыли окно команд, из которого дали `hermes dashboard` — дайте команду снова (шаг 5.1) |
| «Не могу искать в интернете» | не подключён веб-поиск — добавьте ключ поискового сервиса (раздел «Что дальше») |
| `hermes skills list` не показывает `assistant` | это необязательный навык: папка не «проект Git» или не доверена — см. «Включить навык» |
| «Not inside a git checkout» | сначала `git -C "ВАШ_ПУТЬ" init`, потом `hermes skills trust "ВАШ_ПУТЬ"` |
| Не получается узнать путь к папке | см. рамку 📋 «Как узнать путь к вашей папке» после шага 3 |
| Общая проверка «всё ли в порядке» | в окне команд дайте `hermes doctor` — Hermes сам проверит установку и подскажет |

называется иначе, загляните в справку приложения или дайте в окне команд `hermes --help`.
