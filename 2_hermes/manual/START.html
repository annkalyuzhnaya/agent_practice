Трек 5 · Hermes своими руками

Собрать личного помощника на Hermes — руками, без Claude

Пошаговый старт для тех, кто не программист. Claude в этом треке не участвует: всё нужное вы сделаете сами. Получится универсальный помощник, который ведёт ваши задачи и заметки, отвечает на вопросы и готовит черновики.

Первая установка Hermes — 15–30 минут (в основном ждёте загрузку). Сборка помощника по готовым заготовкам — ещё 15–20 минут. Нужны: компьютер с Windows или macOS, интернет и ключ API какой-нибудь модели.

Главное. Это страница-введение. Полное руководство со всеми командами и объяснениями — в файле MANUAL.md рядом с этой страницей (откройте его Блокнотом или прямо здесь, ссылкой). Ниже — общая карта пути, чтобы вы понимали, что вас ждёт.

1Два окна и три слова

Всю дорогу вы переключаетесь между двумя окнами — запомните их названия, в шагах они встречаются постоянно.

Окно команд

Чёрное/синее окно, где команды печатают текстом и жмут Enter. На Windows — PowerShell, на macOS — Терминал. В нём ставят Hermes и дают команды.

Окно Hermes

Веб-панель Hermes — страница в браузере с вкладками (Chat, Keys, Models). В нём вводят ключ модели и разговаривают с помощником. Это не окно команд.

Папка

Та же, что в проводнике. У помощника будет своя папка, внутри — файлы с правилами и ваша «память».

Текстовый файл

Файлы .md и .json — это просто текст. Открываются Блокнотом. Ни Word, ни особых программ не нужно.

2Путь из семи шагов

Каждый шаг подробно расписан в MANUAL.md — там сказано, в каком окне и в какой папке что делать. Здесь только суть, чтобы видеть целое.

1

Открыть окно команд

Windows: «Пуск» → наберите PowerShell → откройте. macOS: Cmd+Пробел → Терминал. Проверка — вставьте echo привет, окно отвечает «привет». Это окно не закрывайте.

2

Установить Hermes

В окне команд одна строка:

irm https://hermes-agent.nousresearch.com/install.ps1 | iex

(macOS: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | sh). Ждите 5–15 минут. Затем закройте окно команд и откройте новое такое же (Пуск → PowerShell), в нём проверьте hermes --version — покажет номер версии.

3

Создать папку и скопировать заготовки

В проводнике создайте папку, например my-assistant. Скопируйте в неё всё содержимое папки templates/ рядом с этим руководством: файл AGENTS.md, папку hub и папку .hermes. В MANUAL.md тут же — как узнать «путь» к этой папке (пригодится в шаге 6).

4

Вписать, кто вы

В папке my-assistant зайдите в папку hub, откройте файл profile.md Блокнотом, впишите имя, чем заняты, на «ты» или «вы». Сохраните. Так помощник станет вашим.

5

Открыть окно Hermes и подключить модель

В окне команд дайте hermes dashboard — откроется окно Hermes в браузере. На вкладке Keys вставьте ключ API вашего провайдера, на вкладке Models выберите модель. Ключ вводится только в окно Hermes, не в чат. Окно команд при этом не закрывайте.

6

Указать Hermes вашу папку

В окне команд (вместо ВАШ_ПУТЬ — путь к вашей папке из шага 3):

hermes config set terminal.cwd "ВАШ_ПУТЬ"

Например hermes config set terminal.cwd "D:/my-assistant". Затем переоткройте окно Hermes (hermes dashboard) — теперь оно работает в вашей папке и прочитает AGENTS.md.

7

Первый разговор

В окне Hermes на вкладке Chat напишите «Привет! Представься». Затем «Запиши задачу…», «Запомни, что…», «Какие у меня задачи?». Помощник отвечает и сохраняет всё в папку hub/. Базовый помощник готов.

Важно для Windows. Запускайте установщик Hermes в отдельном окне PowerShell из «Пуска», а не во встроенном терминале другой программы, — иначе установка может оборваться на «Downloading Python». И помните: только что установленный hermes виден лишь в новом окне команд.

3Что лежит в заготовках

Папка templates/ — это скелет помощника. Вот что вы копируете к себе:

templates/ ├─ AGENTS.md — описание помощника (Hermes читает его в начале разговора) ├─ .hermes/ │ └─ skills/assistant/ — навык помощника: SKILL.md и references/protocol.md └─ hub/ — «память» помощника ├─ profile.md — кто вы (это вы и заполняете) ├─ tasks.md — задачи (помощник ведёт сам) ├─ journal.md — бортжурнал ├─ models.json — какая модель на какую роль (необязательно) ├─ notes/ — заметки └─ drafts/ — черновики

4Когда базовый помощник готов

Всё ниже — по желанию. Базовый помощник из семи шагов уже работает.

Включить навык (Git)

Необязательно: помощник работает и так, по AGENTS.md. Для самого Hermes Git не нужен — только чтобы подключить навык из папки. Как — в MANUAL.md, «Включить навык».

Поиск в интернете

Вкладка Keys → ключ Tavily / Exa / Firecrawl / Brave.

Работа по расписанию

Шлюз в автозапуск: hermes gateway install --start-now --start-on-login, затем раздел Cron.

Telegram

Вкладка Channels → Telegram → Quick setup. Бот — второе окно помощника.

Сменить характер

Правьте AGENTS.md Блокнотом словами. Нужен узкий тематический ассистент — это трек 3, там помогает Claude.

Полное руководство со всеми объяснениями и разделом «Если что-то пошло не так» — MANUAL.md. Проверено на Windows 11 с Hermes Agent 0.21.5 (октябрь 2026). Hermes быстро меняется — при расхождениях смотрите hermes --help и hermes doctor.
