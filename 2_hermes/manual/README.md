# Трек 5 — универсальный Hermes-ассистент руками (без Claude)

Здесь собрано всё, чтобы человек **без навыков программирования** собрал себе личного помощника на Hermes Agent
**самостоятельно, без Claude**. Это главное отличие трека: в треках 3 и 4 ассистентов собирает Claude, а здесь
человек проходит путь руками по детальной инструкции — что такое командная строка, как её открыть, какие строки
вставить, что должно получиться, как открыть и поправить файлы.

## С чего начать

Откройте **[START.html](START.html)** двойным щелчком — это страница-введение с картой пути. Полное руководство
со всеми командами и объяснениями — **[MANUAL.md](MANUAL.md)**.

## Что внутри

| Файл / папка | Что это |
|---|---|
| `START.html` | страница-введение для новичка: два окна и три слова, семь шагов кратко, карта заготовок |
| `MANUAL.md` | подробное пошаговое руководство (установка Hermes, сборка помощника, первый разговор, что дальше) |
| `templates/` | готовый скелет помощника — его человек копирует в свою новую папку |
| `templates/AGENTS.md` | описание универсального помощника (Hermes читает его в начале разговора) |
| `templates/.hermes/skills/assistant/` | навык помощника: `SKILL.md` и `references/protocol.md` |
| `templates/hub/` | «память» помощника: профиль, задачи, заметки, черновики, журнал, `models.json` |

## Чем этот трек отличается от остальных

- **Трек 3** — Claude собирает тематического Hermes-ассистента за человека (`../BUILD.md`).
- **Трек 4** — Claude-оркестратор дирижирует готовыми Hermes-ассистентами (`../orchestrator/`).
- **Трек 5 (этот)** — человек собирает **универсального** помощника сам, по инструкции, без Claude.

Помощник получается не тематический, а общего назначения: задачи, заметки, вопросы, черновики, при желании —
веб-поиск, расписание и Telegram. Захочет человек узкого ассистента (дайджест, разбор почты) — руководство
подскажет перейти к треку 3.

## Для сопровождающих практику

- Заготовки в `templates/` — обычные текстовые файлы, никакой сборки (`build.py`) здесь нет: Hermes читает
  `AGENTS.md` и навык напрямую. Это сделано намеренно, чтобы человек видел и правил всё руками.
- Личных данных тут нет и не должно быть. Когда человек копирует `templates/` к себе и заполняет `hub/`, его данные
  живут в его папке, а не в этом репозитории.
- Проверено на Windows 11 с Hermes Agent 0.21.5 (октябрь 2026). При смене версии Hermes сверяйте команды установки
  и названия вкладок веб-панели с `../01_digest/SETUP.md`, где те же шаги расписаны для тематического кейса.
