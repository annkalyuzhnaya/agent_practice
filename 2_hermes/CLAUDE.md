# Трек Hermes — папка-мастерская

Это корень трека Hermes. Здесь **Claude собирает ассистентов для среды Hermes Agent**: тематических (треки 3 и 5)
и оркестратор над ними (трек 4). Готовый образец тематического ассистента — кейс `01_digest/` (Обозреватель).

## Что делать, когда человек пишет в этой папке

1. **«Собери ассистента для Hermes», «сделай гермес-ассистента», «новый кейс», любой запрос про нового тематического
   ассистента** → веди по `BUILD.md`:
   - Предложи формой (`AskUserQuestion`, вопрос «Какого ассистента собрать?») один из пяти готовых сценариев
     (Обозреватель · База знаний · Встреча · Входящие · Документ-инженер) **или** вариант «Опишу своего» в поле «Другое».
   - Выбран готовый сценарий → собери кейс, перенеся правила из папки-источника трека Claude по шагам `BUILD.md`.
   - «Опишу своего» → задай три вопроса (что делает · на каких материалах · что отдаёт) и напиши плейбуки с нуля
     по образцу `01_digest/playbooks/01_digest.md`.
   - Сценарий «Обозреватель» уже собран — предложи его доработать или взять как образец, а не собирать заново.

2. **«Собери оркестратор», «личный помощник над гермес-ассистентами», «свяжи моих ассистентов»** → это трек 4:
   работай в папке `orchestrator/` по её `CLAUDE.md`.

3. **«Хочу собрать Hermes руками / без Claude / сам»** → это трек 5: скажи, что готовое руководство для не-программистов
   лежит в `manual/` (`manual/START.html` — открыть двойным щелчком), и помоги только если он попросит.

4. **Просьба доработать готовый кейс** (правила, скрипты, страница) → работай как инженер: правь `playbooks/`
   в папке кейса, затем `python tools/build.py`; общие скрипты — в треке Claude, затем `python 2_hermes/sync.py`.

Вопросы с выбором задавай формой (`AskUserQuestion`), а не сплошным текстом.

## Что где лежит

- `BUILD.md` — инструкция сборки тематического ассистента (твой основной рецепт для пункта 1).
- `01_digest/` — готовый кейс-образец: его устройство повторяет любой новый кейс.
- `orchestrator/` — трек 4: Claude-оркестратор над несколькими Hermes-ассистентами (локальными и удалёнными).
- `manual/` — трек 5: руководство «собрать универсального Hermes-ассистента руками», для не-программистов.
- `sync.py` — переносит в кейсы трека среда-независимые скрипты и данные из трека Claude (`1_claude/`); запускается
  из корня репозитория: `python 2_hermes/sync.py`. Руками перенесённое не правь — правь источник.
- `README.md` — карта трека и таблица «чем заменено то, что было в Claude».

## Жёсткие правила

- Источник правды кейса — его `playbooks/`. `AGENTS.md` и `.hermes/skills/` собирает `tools/build.py`; руками не править.
- Ключи API не спрашивай, не ищи и не читай; `.env` и `hub/.secrets/` не открывай. Владелец вводит ключ сам
  на вкладке KEYS веб-панели Hermes; ты только называешь имя переменной.
- Личные данные (`hub/`) в репозитории не создавать и в git не добавлять.
- Ничего не коммитить и не публиковать без просьбы. Cron, Telegram и публикацию страницы включать только после «да».
