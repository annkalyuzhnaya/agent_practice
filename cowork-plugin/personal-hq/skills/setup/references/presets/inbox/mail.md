# Обзор почты

Одна строка на письмо или сообщение. Статусы: `новое` → `ответ утверждён` → `в черновиках почты` / `игнор`; для писем, где ответ не нужен, — `без ответа`. Ответы предлагает агент, утверждает владелец (на вкладке «Почта» доски или в чате); отправляет письма только владелец.
