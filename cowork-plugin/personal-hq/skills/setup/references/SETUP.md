# Личный ассистент: установка и настройка

Эта инструкция проводит от пустого компьютера до работающего ассистента. Читать всё подряд не обязательно:
выполните раздел 2 (установка, 5–10 минут) — дальше ассистент сам поведёт вас по шагам в чате.

**Главное про папки.** Их две, и они живут отдельно:

| Папка | Что это | Что в ней |
|---|---|---|
| **Исходник** (`agent_practice`) | «установочный диск» системы | правила, скрипты, заготовки; ваших данных в ней нет |
| **Папка ассистента** (например, `Документы\Личный ассистент`) | место, где ассистент живёт | копия системы и папка `hub` с вашими письмами, заметками и планами |

Папка ассистента создаётся **один раз, при первом запуске** — вы только выбираете место. Дальше вы всегда работаете
в ней, а исходник нужен лишь для обновлений. Приветствие и рассказ «что будет» ассистент тоже показывает один раз.

## 1. Что вы получите

Одного собеседника в чате — **ассистента**, за которым работают пять агентов:

| Вы пишете или вставляете | Ассистент делает |
|---|---|
| письмо, сообщение, список дел | определяет срочность, выделяет задачи, адресованные лично вам, готовит короткий ответ |
| «у меня встреча с … в четверг» | вносит в календарь и готовит одностраничный бриф |
| «что нового по моим темам» | собирает дайджест из открытых источников |
| «запомни, что …», «что мы решили по …» | ведёт базу знаний и отвечает по ней со ссылками |
| файл Word или Excel | собирает отчёт по шаблону, вносит точечную правку, сравнивает версии |
| «мой день» | делает всё перечисленное и выдаёт один план дня |

Ассистент **сам ничего не отправляет и не удаляет** — он готовит черновики, а решения остаются за вами. Письмо уходит, только когда вы нажали «Отправить» на доске.

## 2. Установка

### Что понадобится

| | Обязательно | Зачем |
|---|---|---|
| Приложение Claude для компьютера (Windows или macOS) с платной подпиской | да | в нём работает ассистент |
| Папка-исходник `agent_practice` на вашем компьютере (для Claude Code) | да | из неё ассистент устанавливается и обновляется |
| Python 3.10 или новее | для Claude Code — да; для Cowork — нет | работа с Word и Excel, поиск по базе, Telegram |
| Obsidian | нет | удобный просмотр базы знаний |
| Telegram | нет | пересылать сообщения ассистенту и получать сводки |
| Учётная запись Google или Microsoft | нет | подключить личную почту и календарь |

### Выберите, где будете работать

| | Claude Code (вкладка «Code») | Cowork |
|---|---|---|
| Кому подходит | хотите все возможности | не хотите ставить Python |
| Что умеет | всё | всё, кроме Telegram, точечной правки документов и трёх рутин |
| Установка | 5–10 минут | 3 минуты |

**Совет: начните с Claude Code.** Cowork можно подключить позже — настройка общая, повторять её не придётся.

### Вариант А. Claude Code

1. **Получите исходник.** Скопируйте или распакуйте папку `agent_practice` в удобное место, например `D:\Work\agent_practice`.
2. **Проверьте Python.** Откройте «Терминал» (Windows: Пуск → наберите «Терминал») и выполните:
   ```bash
   python --version
   ```
   Видите `Python 3.10` или новее — всё готово. Видите ошибку — скачайте Python с python.org; при установке
   на Windows поставьте галочку **«Add python.exe to PATH»**, затем закройте и снова откройте приложение Claude.
3. **Откройте исходник в Claude.** В приложении Claude перейдите на вкладку **Code** → «Новая сессия» → выберите папку `agent_practice`.
4. **Напишите в чат:**
   ```
   настрой ассистента
   ```
   Ассистент поздоровается, объяснит, что будет, и спросит формой, **где ему жить**. Выберите предложенное место
   (`Документы\Личный ассистент`) или впишите свой путь в «Другое». Путь лучше выбрать постоянный: на него будут
   ссылаться рутины. Ассистент создаст папку и скопирует в неё всё нужное. Библиотеки для Word и Excel он предложит
   установить сам — достаточно ответить «Установить».
5. **Перейдите в папку ассистента.** «Новая сессия» → выберите созданную папку → напишите `настрой ассистента`.
   Настройка продолжится с профиля, без повторного приветствия. **С этого момента вы всегда открываете эту папку**,
   а не исходник.

По ходу настройки Claude будет спрашивать разрешение на запуск команд (`python tools/install.py` и подобных) —
это его обычная предосторожность. Нажимайте «Разрешить».

### Вариант Б. Cowork

1. **Установите плагин.** Откройте Cowork в приложении Claude и перетащите в чат файл `personal-hq.plugin`
   (лежит в исходнике: `agent_practice/dist/`). Появится карточка плагина — нажмите «Установить».
   В Cowork исходником служит сам плагин — папка `agent_practice` больше не нужна.
2. **Выберите рабочую папку.** Если ассистент уже установлен через Claude Code — укажите его папку.
   Если нет — создайте новую пустую папку (например, `Документы\Личный ассистент`) и укажите её: она станет папкой ассистента.
3. **Напишите в чат:** `настрой ассистента` (или `/setup`). Ассистент спросит, создать ли здесь папку `hub` с вашими данными.

## 3. Как идёт настройка

Ассистент ведёт вас как мастер установки: **один шаг — один экран**.

- **Перед каждым шагом — карточка:** зачем шаг, что сделает ассистент, что нужно от вас, обязателен ли он.
- **Каждый вопрос — форма с вариантами.** Щёлкните нужный вариант. Совет по умолчанию стоит первым и помечен «(советую)».
- **Свой ответ** — в поле **«Другое»** внизу формы: туда печатают темы, имена, своё время. Что именно вписать
  и в каком виде, сказано в самом вопросе, с примером.
- **«Позже»** есть у каждого необязательного шага. Вернуться — словами «продолжи настройку».
- **Когда нужно что-то сделать вне чата** (нажать «подключить», создать бота), ассистент даёт нумерованную инструкцию
  и ждёт ответа «Готово — проверь». После этого он проверяет сам и говорит, что получилось.
- **Ничего не включается без вашего «да»**: ни подключения, ни рутины, ни публикация страницы.
- Настройку можно прервать в любой момент — прогресс сохраняется.

В начале ассистент спросит режим:

| Режим | Что входит | Время |
|---|---|---|
| **Быстрый старт** | только обязательное: папка и профиль | 5 минут |
| **Полная настройка** | все шаги | 15–20 минут |

### Все шаги

| Шаг | Обязателен? | Время | Что делает ассистент | Что нужно от вас |
|---|---|---|---|---|
| 0. Создать папку ассистента | **да** | 1–2 мин | создаёт отдельную папку, копирует в неё систему и заготовки | выбрать место |
| 1. Профиль | **да** | 3–4 мин | записывает, кто вы и как вам помогать | ответить на две формы |
| 2. Каналы | нет | 2–10 мин | подключает календарь, почту, Telegram | нажать «подключить»; для Telegram — создать бота |
| 3. Рутины | нет | 2 мин | создаёт запуск по расписанию | выбрать набор и время |
| 4. Доска | нет | 1 мин | публикует вашу личную страницу с задачами | закрепить страницу |
| 5. Obsidian | нет | 2 мин | — (всё уже подготовлено) | открыть папку в Obsidian |
| 6. Пробный запуск | нет | 5–10 мин | показывает «Мой день» на учебных примерах | посмотреть результат |
| 7. Итог | — | 1 мин | показывает, что включено и что вы теперь можете | — |

## 4. Шаги подробно

### Шаг 0. Создать папку ассистента — обязательный
Ассистент спрашивает формой, где ему жить, и создаёт там отдельную папку. В неё копируются правила и скрипты,
а внутри появляется папка `hub` — там будут храниться ваши письма, встречи, заметки и планы.
Вторым вопросом ассистент спросит, **положить ли учебные примеры** (8 писем, заметки, документы). Для обучения
отвечайте «Да»: на них можно сразу попробовать всё, не вставляя свои материалы. Убрать их — «убери учебные примеры».
Исходник `agent_practice` при этом не меняется. От вас — выбрать место и разрешить запуск команды.
Требования к месту: папка новая или пустая, не внутри исходника. То же без чата:
```bash
python tools/install.py "C:\Users\Имя\Documents\Личный ассистент" --demo
```
`--demo` — положить учебные примеры; без него папка будет пустой. Запуск без пути спросит и место, и примеры.
В Cowork папкой ассистента становится выбранная рабочая папка — ассистент спросит подтверждение и создаст в ней `hub`.

### Шаг 1. Профиль — обязательный
Две формы по четыре вопроса.

| Вопрос | Обязателен? | Как отвечать |
|---|---|---|
| Роль | да | выбрать вариант или вписать должность в «Другое» |
| Чем заняты в ближайший месяц | нет | лучше одной фразой в «Другое» |
| Рабочие часы и часовой пояс | да | выбрать; своё время — в «Другое», например `9:30–18:30` |
| Темы для дайджеста | да | «Предложи по моей роли» или свои темы через запятую в «Другое» |
| Источники новостей | нет | «Подбери сам» или адреса сайтов через запятую |
| Кому делегируете | нет | в «Другое»: `Ирина — договоры; Олег — отчёты` |
| Тон писем | нет | выбрать вариант |

В конце ассистент покажет профиль целиком и спросит, всё ли верно. Позже профиль меняется словами:
«добавь тему …», «делегирую … такому-то».

### Шаг 2. Каналы — необязательный
Без каналов всё работает: письма вы вставляете в чат, встречи называете словами. Каналы убирают это копирование.

| Канал | Что даёт | Что ассистенту разрешено | Где доступен |
|---|---|---|---|
| Календарь | встречи сами попадают в план, брифы готовятся заранее | только чтение | Claude Code, Cowork |
| Личная почта | письма разбираются без копирования | читать и готовить черновики; отправлять — только ответы по вашей кнопке «Отправить» на доске; не удалять | Claude Code, Cowork |
| Telegram | пересылаете боту сообщения, получаете сводки | забирать пересланное; писать вам | только Claude Code |

**Календарь и почта.** Ассистент покажет карточку подключения. Вы: 1) нажимаете «Подключить»; 2) в открывшемся окне
входите в свою учётную запись и разрешаете доступ; 3) возвращаетесь в чат и выбираете «Готово — проверь».
Рабочую (корпоративную) почту подключайте, только если это разрешено правилами вашей организации.

**Telegram** — четыре действия, ассистент ведёт по одному:
1. В Telegram откройте чат **@BotFather** → отправьте `/newbot` → придумайте имя бота (любое) → придумайте адрес,
   оканчивающийся на `bot` (например `anna_helper_bot`). В ответ придёт длинная строка — **токен**.
2. Ассистент создаст и откроет файл `hub/.secrets/telegram.json`. В строке `"token": ""` вставьте токен между
   кавычками и сохраните файл (Ctrl+S). **В чат токен не присылайте** — ассистент его не просит и не читает.
3. Откройте своего бота в Telegram и отправьте ему `/start`.
4. Ассистент покажет, кого увидел бот, — подтвердите в форме, что это вы.

Бот не видит ваши личные переписки — только то, что вы ему переслали или написали. Отвечает он не мгновенно:
ассистент проверяет его по расписанию и в начале разговора.

### Шаг 3. Рутины — необязательный
Рутина — работа, которую ассистент делает сам по расписанию. Наборы:

| Набор | Что входит |
|---|---|
| Минимум | утренний план дня |
| **Стандарт** (советуем) | утренний план, брифы накануне встреч, итог дня, обзор недели по пятницам |
| Полный | плюс уход за базой знаний, дайджест недели, сбор почты и Telegram |

В форме вы выбираете набор, время утреннего запуска и дни. Ассистент покажет итоговое расписание и создаст задачи
после вашего «Да, создать». **Рутины работают, пока приложение Claude открыто на компьютере**; пропущенный запуск
выполнится при следующем открытии. Одну рутину включайте только в одной среде — иначе она выполнится дважды.

### Шаг 4. Доска — необязательный
Доска ассистента — ваша личная страница в браузере: задачи, вопросы на решение, встречи, дайджест, рутины.
На ней можно отмечать сделанное и отвечать кнопками. Видите её только вы. После публикации откройте ссылку
и закрепите страницу (значок булавки).

### Шаг 5. Obsidian — необязательный
1. Установите Obsidian (obsidian.md), если его нет.
2. Нажмите «Открыть папку как хранилище» и выберите папку `hub` внутри папки ассистента.
3. На вопрос о доверии ответьте «Доверять». Откроется заметка «Главная» со ссылками на задачи, встречи и базу знаний.

### Шаг 6. Пробный запуск — необязательный
Ассистент загрузит учебный набор (8 писем, заметки, документы), выполнит «Мой день» и покажет план дня.
После показа предложит убрать учебные примеры.

### Шаг 7. Итог
Ассистент покажет: что включено, что отложено, готовые фразы для начала и форму «С чего начнём?».

## 5. После настройки

Памятка по ежедневной работе — в [GUIDE.md](GUIDE.md). Самое главное:

- **Пишите обычным языком.** Команды и папки знать не нужно.
- **Пять фраз для начала:** «мой день» · вставить письмо и написать «что с этим делать» · «у меня встреча с … в четверг
  в 15:00» · «запомни, что …» · «что срочного».
- **«помощь»** — ассистент напомнит, что умеет. **«что ещё не настроено»** — покажет отложенные шаги.

## 6. Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `python` не найден | установите Python с python.org с галочкой «Add python.exe to PATH», перезапустите приложение Claude |
| «Нет библиотек документов» | ответьте ассистенту «Установить» или выполните `pip install -r requirements.txt` в папке ассистента |
| Ассистент отвечает как обычный Claude | проверьте, что открыта именно папка ассистента (Claude Code) или установлен плагин и выбрана эта папка (Cowork); напишите «настрой ассистента» |
| Ассистент говорит «это папка-исходник» | вы открыли `agent_practice`; откройте новую сессию в папке ассистента — её путь он назовёт |
| Забыли, где папка ассистента | в исходнике выполните `python tools/install.py where` |
| «Папка не пуста» при установке | выберите новую или пустую папку — в чужие папки ассистент не устанавливается |
| Вместо форм — вопросы текстом | так бывает, если в среде нет форм: отвечайте цифрой варианта, как подсказано в вопросе |
| Не нашли поле для своего ответа | это пункт «Другое» в конце списка вариантов |
| Карточка подключения почты или календаря не появилась | откройте настройки приложения Claude → «Коннекторы», подключите там и скажите ассистенту «проверь подключение» |
| Бот в Telegram молчит | это нормально: он не отвечает мгновенно. Напишите ассистенту «забери телеграм» |
| `tg_bridge.py check` сообщает об ошибке | токен вставлен не полностью или с пробелом — проверьте файл `hub/.secrets/telegram.json` |
| Рутина не сработала | приложение Claude было закрыто; откройте его — пропущенный запуск выполнится |
| В Cowork недоступен Telegram или правка документов | это делается в Claude Code; ассистент оставит заявку и выполнит её там |

Состояние настройки без чата (Claude Code, в папке ассистента):
```bash
python tools/setup.py status
```

## 7. Изменить или начать заново

- **Поменять ответы:** скажите в чате — «измени рабочие часы», «отключи вечернюю рутину», «подключи почту».
- **Пройти шаг заново:** «настрой шаг 3 заново» (или назовите шаг: «рутины», «каналы»).
- **Обновить ассистента** (вышла новая версия исходника): откройте сессию в исходнике и напишите «обнови ассистента»
  или выполните там `python tools/install.py`. Обновятся правила и скрипты; ваши данные в `hub` не затрагиваются.
- **Перейти на другой компьютер:** перенесите папку ассистента целиком — в ней есть всё для работы; рутины создайте
  заново («включи рутины»). Исходник перенесите, если хотите получать обновления.
- **Начать с чистого листа:** в папке ассистента переименуйте `hub` (например в `hub_старое`) и напишите
  «настрой ассистента». Старые данные останутся в переименованной папке. Либо установите ассистента в другую папку:
  `python tools/install.py "новый путь"`.
