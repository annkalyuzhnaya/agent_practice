# Личный ассистент (personal-hq)

Плагин для Claude Cowork: личные агенты, связанные общей шиной данных.

| Навык | Что делает |
|---|---|
| `hq` | Оркестратор в чате: пишите ему как помощнику, он сам подключает остальных |
| `setup` | Мастер настройки: ведёт по шагам с формами — профиль, каналы (почта, Telegram, календарь), рутины, доска, Obsidian |
| `my-day` | Комплексный сценарий: дайджест → входящие → встречи → документы → база знаний → план дня |
| `digest` | Обозреватель: дайджест по вашим темам |
| `kb` | База знаний: ответы по вашим материалам, заметки, противоречия |
| `meeting` | Бриф к встрече и мемо после неё |
| `inbox` | Разбор входящих: обзор почты с готовыми ответами, срочность, задачи, план |
| `docs` | Word/Excel; тяжёлые операции передаёт в Claude Code заявкой |

Первый запуск: создайте пустую папку (например, «Документы → Личный ассистент»), выберите её рабочей и напишите
«настрой ассистента». В этой папке ассистент будет жить: в ней появится `hub` с вашими данными. Ассистент поздоровается (один раз) и проведёт
по шагам: вопросы — формами с вариантами, обязательны только два шага (около 5 минут), остальное можно отложить.
Инструкция — `SETUP.md` (раздел 2, «Вариант Б. Cowork»). Как пользоваться после настройки — `GUIDE.md` или слово «помощь» в чате.

Работает с папкой ассистента (в ней подпапка `hub/`). Выбирайте её рабочей папкой в Cowork при каждом разговоре.
Без папки навыки работают в переносном режиме: результат выдаётся в чат с блоком для сохранения на шину.

Плагин собирается командой `python tools/build.py` в папке стенда; после правки плейбуков пересоберите и переустановите.
