# Пак навыков для практики

У слушателей плагины Claude могут быть не подключены. Поэтому всё полезное, что разрешает лицензия, лежит здесь
и попадает в каждый кейс вместе с его папкой: ничего ставить из каталога для базовой работы не нужно.

## Как устроено

| Что | Где |
|---|---|
| Единый источник навыков | `skills_pack/skills/<навык>/` |
| Что в какой кейс идёт | `skills_pack/manifest.json` (ключ — путь кейса от корня: `1_claude/01_digest`, `2_hermes/01_digest`) |
| Копия в кейсе (руками не править) | `<кейс>/pack/skills/`, лицензии — `<кейс>/pack/licenses/` |
| Подключение | `python tools/build.py` в папке кейса: трек Claude — копирует `pack/skills/*` в `.claude/skills/` и в плагин Cowork; трек Hermes — в `.hermes/skills/` |

Изменили навык или состав — два шага:

```bash
python skills_pack/sync.py
```

затем `python tools/build.py` в затронутых кейсах. Проверить, что копии не разошлись: `python skills_pack/sync.py --check`.

## Что в паке и зачем

| Навык | Откуда | Где применяется | Что нужно для работы |
|---|---|---|---|
| `memory-management` | Productivity (Anthropic) | 2 База знаний, 4 Входящие, 6 Ассистент: словарь людей, сокращений и терминов в `hub/memory/` — агент понимает «как говорит владелец» | ничего |
| `task-management` | Productivity | 3 Встреча, 4 Входящие, 6: приёмы ведения задач. Источник правды в кейсах — `hub/tasks.md`, а не `TASKS.md` навыка | ничего |
| `start`, `update` | Productivity | 6: лёгкая локальная доска `dashboard.html` и сверка задач — запасной вариант, когда страницу claude.ai опубликовать нельзя | ничего; коннекторы трекеров — по желанию |
| `internal-comms` | anthropics/skills | 1 (выпуск дайджеста для коллег), 3 (письмо по итогам встречи), 4 (тон и форматы ответов), 6 (отчёт недели) | ничего |
| `build-dashboard` | Data (Anthropic) | 1 (страница выпуска), 5 (отчётная страница по выгрузке), 6 (разовые страницы-отчёты) | ничего |
| `data-visualization`, `validate-data` | Data | 5 Документ-инженер: графики по выгрузке, проверка чисел перед сдачей документа | Python — для графиков |
| `tavily-cli`, `tavily-search`, `tavily-extract`, `tavily-research` | Tavily | 1 Обозреватель, 3 Встреча, 6: усиленный веб-поиск и разбор страниц | **ключ Tavily и его CLI**; без них кейсы работают на встроенном веб-поиске |
| `skill-creator` | anthropics/skills | все кейсы, уровень L5: сделать собственный навык и проверить его на примерах | Python — для прогона проверок |

Как именно навык используется в кейсе — написано в плейбуках и `SETUP.md` этого кейса (таблица «Навыки пака»).

## Что не скопировано и как подключить самому

Эти навыки и плагины распространять нельзя (все права у правообладателя) либо у них нет файла лицензии.
Кейсы работают и без них; с ними — удобнее.

| Что | Зачем | Как подключить |
|---|---|---|
| `docx`, `xlsx`, `pdf`, `pptx` (Anthropic) | создание и чтение файлов Word, Excel, PDF, PowerPoint | в приложении Claude и в Cowork обычно включены сразу: Настройки → Возможности → Навыки. В Claude Code: `/plugin` → каталог `anthropics/skills` → набор `document-skills` |
| `schedule` и задачи по расписанию | рутины (уровень L4) | встроено в приложение Claude (раздел «Запланированные»); в кейсах расписание создаёт мастер настройки после вашего «да» |
| Desktop Commander: `obsidian-vault`, `knowledge-base` | работа с хранилищем Obsidian и базой заметок вне рабочей папки | каталог плагинов → Desktop Commander → установить; нужен кейсу 2 только на L5 |
| Productivity целиком (с коннекторами Slack, Notion, Asana и др.) | подтягивать задачи из трекеров | каталог плагинов → Productivity; каждый коннектор авторизуете сами |
| Официальный плагин `telegram` (Anthropic, `claude-plugins-official`) | писать Claude Code прямо из Telegram в живую сессию | в Claude Code: `/plugin install telegram@claude-plugins-official`. В кейсах по умолчанию используется свой мост `tools/tg_bridge.py` — он проще и не требует открытой сессии для приёма сообщений |
| Плагины записи встреч (Meeting.ai, Grain и др.) | расшифровка встреч для кейса 3 | каталог плагинов; нужен аккаунт сервиса. В кейсе 3 достаточно вставить заметки или расшифровку в чат |

Происхождение и лицензии скопированного — в [THIRD_PARTY.md](THIRD_PARTY.md).

Замечание: навыки Productivity и Data ссылаются на файл `CONNECTORS.md` исходного плагина (список необязательных
коннекторов к трекерам и хранилищам). В пак он не входит: кейсы работают с файлами `hub/`, коннекторы не нужны.
