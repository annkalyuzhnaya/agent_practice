## 1. Установка

### Выберите, где будете работать

| | А. Claude Code (вкладка «Code») | Б. Cowork | В. Проект claude.ai |
|---|---|---|---|
| Кому подходит | нужны все возможности | не хотите ставить Python | попробовать за 10 минут, работать с телефона |
| Что нужно | приложение Claude для компьютера, Python 3.10+ | приложение Claude для компьютера | любой браузер или приложение Claude |
| Что получите | всё, что описано в кейсе | базу без бота, скриптов и субагентов | ответы по загруженным файлам (уровень L1) |

#### Что где работает

| Возможность | Claude Code | Cowork | Проект claude.ai |
|---|---|---|---|
| Ответы со ссылкой на источник | да | да | да |
| Поиск | локальный индекс | чтением файлов | по материалам проекта |
| Проверка ответа | отдельный субагент-проверяющий | второй проход того же агента | нет |
| Заметки, связи, журнал противоречий, словарь памяти | да | да | нет |
| Уход за базой | скрипт `kb_lint.py` | проход вручную по правилам | нет |
| Страница «База знаний» | да | если доступна публикация страниц | нет |
| Бот Telegram | да | **нет** | нет |
| Рутины | все пять | только «Разбор входящего», если в среде есть расписание | нет |
| Учебные примеры | `demo.py load` | копированием из `demo/hub/`, если папка кейса доступна | загрузить файлы вручную |

**Что в Cowork урезано, коротко.** Нет Python — значит, нет индекса (поиск идёт чтением файлов), нет скриптов ухода
и карты (агент собирает их сам, медленнее), нет моста Telegram. Нет субагентов — ответ проверяется вторым проходом,
и агент прямо говорит об этом. Навык `skill-creator` в плагин не включён. Работу, которой нужен компьютер, агент
записывает заявкой в `hub/handoff/` с пометкой `needs: code`.

### Вариант А. Claude Code — полный

1. **Получите папку кейса.** Скопируйте `agent_practice/02_kb` в удобное постоянное место (на путь будут ссылаться рутины).
2. **Проверьте Python.** Откройте «Терминал» и выполните `python --version`. Нужно `Python 3.10` или новее.
   Нет — установите с python.org; на Windows поставьте галочку «Add python.exe to PATH» и перезапустите приложение Claude.
   Дополнительных библиотек кейс не требует.
3. **Откройте папку в Claude.** Вкладка **Code** → «Новая сессия» → выберите папку `02_kb`.
4. **Напишите в чат:** `настрой`. Агент поздоровается, создаст рабочую папку `hub/` и задаст вопросы формой.

Claude будет спрашивать разрешение на запуск команд вида `python tools/…` — это обычная предосторожность, разрешайте.
Команды скриптов кейса уже внесены в `.claude/settings.json`, а чтение папки с токеном бота там запрещено.

### Вариант Б. Cowork — плагин

1. Откройте Cowork в приложении Claude и перетащите в чат файл `dist/hq-kb.plugin` из папки кейса. Нажмите «Установить».
2. Создайте пустую папку (например, `Документы\База знаний`) и выберите её рабочей. Если кейс уже настроен в Claude Code —
   выберите папку кейса: рабочая папка `hub/` общая.
3. Напишите `настрой`. Агент создаст `hub/` из заготовок, которые лежат внутри плагина.

### Вариант В. Проект claude.ai — без папки

Откройте [prompts/L1_инструкция_для_проекта.md](prompts/L1_инструкция_для_проекта.md): там текст инструкции, который
нужно вставить в Проект, и три проверочных вопроса. Заметки, память и расписание в этом варианте не работают.

## 2. Как идёт настройка

Агент ведёт как мастер установки: **один шаг — один экран**, каждый вопрос — форма с вариантами, совет по умолчанию
стоит первым. Свой ответ вписывается в поле «Другое». У каждого необязательного шага есть «Позже»; вернуться —
словами «продолжи настройку». **Ничего не включается и не публикуется без вашего «да».**

Перед первым шагом агент сам проверяет, что умеет среда, и записывает это в `hub/setup.md` (таблица «Что умеет среда»:
возможность → есть или нет → чем заменено). Недоступные шаги он не предлагает.

| Шаг | Обязателен? | Время | Что делает агент | Что нужно от вас |
|---|---|---|---|---|
| 0. Рабочая папка | **да** | 1 мин | создаёт `hub/` с заготовками | ничего |
| 1. Профиль и первые материалы | **да** | 3–4 мин | записывает роль и темы; кладёт учебные примеры или разбирает ваши файлы | ответить на форму |
| 2. Словарь памяти | нет | 3 мин | записывает ваши сокращения и прозвища | назвать 3–5 слов |
| 3. Obsidian | нет | 2 мин | — (настройки уже лежат в `hub/.obsidian/`) | открыть папку в Obsidian |
| 4. Страница «База знаний» | нет | 1 мин | публикует вашу личную страницу и выгружает данные | сказать «да», закрепить страницу |
| 5. Бот Telegram | нет | 5–7 мин | проверяет бота, настраивает разрешения | создать бота и вписать токен в файл |
| 6. Рутины | нет | 2 мин | создаёт задачи по расписанию | выбрать набор |
| 7. Пробный запуск | нет | 5 мин | задаёт базе учебный вопрос, разбирает одну заметку | посмотреть результат |

## 3. Obsidian

Obsidian — бесплатная программа для заметок; нужна только для удобного просмотра. Без неё всё работает в чате и на странице.

1. Установите Obsidian (obsidian.md) и запустите.
2. «Открыть папку как хранилище» → выберите папку `hub` внутри папки кейса.
3. Откройте заметку `Главная`: в ней ссылки на разделы базы, журнал противоречий и список ухода.
4. Быстрая заметка: создайте файл в `kb/входящее` (шаблон «быстрая заметка») — агент оформит её при разборе входящего.

Заметки можно читать, править и связывать руками: файлы — общие с агентом. Вкладка «Граф» покажет те же связи, что карта на странице.

## 4. Страница «База знаний»

Что на ней: обзор базы; **противоречия** с кнопками «Верно А», «Верно Б», «Обе устарели» и полем комментария; **карта связей**;
журнал вопросов и ответов; список ухода с кнопками «Исправить» и «Оставить как есть».

- **Посмотреть без публикации.** Откройте `artifacts/kb.html` двойным щелчком — страница покажет вымышленные данные
  (учебный режим). Кнопки работают, изменения не сохраняются.
- **Опубликовать.** Скажите агенту «опубликуй страницу». Он опубликует её как вашу личную страницу в claude.ai
  (видна только вам), запишет ссылку в `hub/artifacts.md` и выгрузит данные. Закрепите страницу, чтобы открывать с телефона.
- **Как решения возвращаются агенту.** Страница сама ничего не выполняет: кнопка записывает ваше решение в хранилище
  страницы. Агент забирает его при **сверке** — по слову «сверь страницу», по кнопке «Сверить сейчас» (видна, когда страница
  открыта рядом с разговором) или в рутине. До сверки решение можно отменить кнопкой «Изменить решение».
- **Чего на странице нет:** полных текстов заметок, словаря памяти, токенов, адресов и телефонов.

Если в вашей среде нет публикации страниц, агент так и скажет; учебный режим и чат остаются.

## 5. Свой бот Telegram

Работает только в Claude Code. Бот — ваш личный: принимает сообщения только от вас и пишет только вам.
Ответ не мгновенный — он приходит после очередного опроса (по расписанию или по слову «проверь бота»).

| Вы пишете боту | Что происходит |
|---|---|
| «запомни …», «запиши …», «в базу …», «заметка …» | текст ложится во входящее базы; агент оформит его в заметку |
| пересылаете сообщение или файл | то же, с пометкой «переслано» |
| любой другой текст | это вопрос к базе: придёт ответ со ссылкой на заметку |
| «сводка» | сводка недели: что добавлено, какие противоречия открыты, сколько ждёт разбора |

**Подключение (5–7 минут).** Скажите агенту «подключи бота» — он проведёт по тем же шагам.

1. В Telegram откройте **@BotFather** → команда `/newbot` → придумайте имя и адрес бота → получите **токен** (длинная строка).
2. Агент выполнит `python tools/tg_bridge.py init` — появится файл `hub/.secrets/telegram.json`.
3. **Токен вписываете вы сами:** откройте этот файл в Блокноте и вставьте токен в кавычки после `"token":`. Сохраните.
   В чат токен не отправляйте. Агент этот файл не читает и не показывает.
4. Напишите своему боту `/start`.
5. Агент выполнит `python tools/tg_bridge.py check` — должно появиться «Бот на связи: @…».
6. Агент выполнит `python tools/tg_bridge.py whoami` — покажет ваш номер (`owner_id`). Впишите его в тот же файл в поле `owner_id`.
7. В форме выберите, что разрешить боту: отвечать на вопросы; присылать сводку по пятницам; подтверждать приём
   (для подтверждений поставьте `"ack": true` в файле настроек).
8. Включите рутину опроса `kb-tg-pull` (раздел 6) — иначе бот проверяется только по слову «проверь бота».

**В Cowork мост не работает** (ему нужен Python). Замена: «запомни …» словами в чате, быстрая заметка в Obsidian,
вопросы — в чате. Углублённый вариант для Claude Code — официальный плагин `telegram` из каталога (раздел 8):
сообщения приходят прямо в открытую сессию. В кейс он не скопирован; это задание уровня L5.

## 6. Расписание

Рутина — задача, которую приложение запускает само. Включаются только после вашего «да»; выполняются, пока приложение
Claude открыто на компьютере. Список и статусы — в `hub/routines.md`.

| Набор | Что входит |
|---|---|
| **Минимум** (совет) | `kb-inbox` — разбор входящего по будням в 09:00; `kb-care` — уход за базой в пятницу в 16:30 |
| **Стандарт** | плюс `kb-index` — пересборка индекса по будням в 08:00; при подключённом боте `kb-tg-pull` — опрос каждые 20 минут днём, `kb-weekly` — сводка в пятницу в 17:00 |

Включить: «включи рутины». Перенести время, поставить на паузу, отключить — словами в чате.
Рутины никого не спрашивают и ничего не решают за вас: противоречия не закрывают, заметки не удаляют.
В Cowork доступна только `kb-inbox` (если есть инструмент расписания); остальные агент запишет как «включить в Claude Code».
Без расписания те же работы запускаются фразами: «разбери входящее», «наведи порядок в базе», «проверь бота», «сводка недели».

## 7. Проверка «всё работает»

Скажите агенту «проверь, всё ли работает» или пройдите сами (Claude Code):

| Проверка | Команда или фраза | Что должно быть |
|---|---|---|
| Рабочая папка и среда | `python tools/setup.py status` | список «что есть»; строка «Поиск по базе (FTS5): есть» |
| Учебные примеры | `python tools/demo.py load` | «положено файлов 11» |
| Поиск | `python tools/kb_index.py build`, затем `python tools/kb_index.py search "срок согласования"` | регламент и протокол от 10.09 среди первых результатов |
| Ответ | «Какой срок согласования документов?» | две версии (5 и 3 дня), ссылки, строка «Проверка: …» |
| «В базе нет» | «Какой бюджет пилота системы Маршрут?» | «В базе этого нет» |
| Уход | `python tools/kb_lint.py check` | битая ссылка — 1, без связей — 1, не разобрано — 1 |
| Проверка поиска | `python tools/kb_eval.py` | 4 из 4 |
| Бот (если подключён) | `python tools/tg_bridge.py check` | «Бот на связи: @…»; без токена — понятная подсказка, что вписать |
| Страница | открыть `artifacts/kb.html` | учебный режим, пять вкладок |
| Убрать примеры | `python tools/demo.py clean` | учебные файлы удалены, ваши не тронуты |

Эталон ответов и файлов — в [demo/пример_результата/](demo/пример_результата/), описание набора — [demo/README.md](demo/README.md).

## 8. Навыки и что подключить из каталога

### Навыки, которые уже лежат в кейсе

| Навык | Зачем в этом кейсе | Нужен ли ключ или подключение | Как проверить |
|---|---|---|---|
| `kb` | Библиотекарь: ответы, заметки, противоречия, уход | нет | «что у нас решено по срокам согласования?» — ответ со ссылками |
| `setup` | мастер настройки | нет | «что ещё не настроено?» — таблица шагов |
| `memory-management` (пак) | приёмы ведения словаря людей, сокращений и терминов. В кейсе словарь лежит в `hub/memory/`; файлы навыка по умолчанию (`CLAUDE.md`, `memory/` в корне) не создаются | нет | «запомни в словарь: СК — это ООО „Северный контур“», затем вопрос с «СК» |
| `skill-creator` (пак, только Claude Code) | создать свой навык на уровне L5 | нет; нужен Python | «создай навыком skill-creator навык …» — появится папка в `.claude/skills/` |

Навыка нет в списке (например, плагин собран без него) — агент работает по правилам плейбука `02_kb.md`: словарь он ведёт
и без `memory-management`.

### Что в кейс не скопировано и как подключить

Эти навыки распространяются своими владельцами, поэтому в папке кейса их нет. Они необязательны.

| Что | Зачем | Как подключить | Без него |
|---|---|---|---|
| Desktop Commander: `obsidian-vault`, `knowledge-base` | работать с хранилищем Obsidian или папкой заметок, которые лежат **вне** папки кейса | приложение Claude: Настройки → Возможности (Плагины) → каталог → Desktop Commander → «Установить»; в Claude Code — команда `/plugin` | перенесите заметки в `hub/kb/входящее/` — агент разберёт их сам |
| Официальный плагин `telegram` | сообщения из Telegram приходят прямо в открытую сессию Claude Code (уровень L5) | Claude Code: `/plugin` → найти `telegram` → установить и следовать его инструкции | свой бот через `tools/tg_bridge.py` (раздел 5) |
| `schedule` | создание задач по расписанию, если в среде нет встроенного инструмента | Настройки → Возможности (Плагины) → каталог | запускать работы фразами из раздела 6 |
| `docx`, `pdf` (Anthropic) | читать сложные файлы Word и PDF перед оформлением в заметку | обычно включены в приложении: Настройки → Возможности; в Claude Code — `/plugin` | простые `.docx` читает `python tools/kb_index.py text "путь"`; PDF пришлите в чат или вставьте текст |

После подключения скажите агенту «проверь среду» — он обновит таблицу в `hub/setup.md`.

## 9. Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| «python не найден» | установите Python, перезапустите приложение Claude; до этого кейс работает как в Cowork |
| «Поиск по базе (FTS5): нет» | ваша сборка Python без FTS5 — поиск пойдёт чтением файлов; всё остальное работает |
| поиск не находит новую заметку | «пересобери индекс» (`python tools/kb_index.py build`) |
| бот молчит | «проверь бота»; убедитесь, что вы написали боту `/start` и что `owner_id` вписан |
| `check` сообщает, что токен не задан | откройте `hub/.secrets/telegram.json` и впишите токен сами |
| страница пустая | «сверь страницу»; откройте её в claude.ai под своей учётной записью |
| агент ответил без ссылки | скажите «ответ без источника не принимаю» — и проверьте, что вопрос задан в папке кейса |
| хочу начать заново | переименуйте папку `hub` (например, в `hub_старая`) и напишите «настрой» |
