# Плейбук «Настройка» — мастер установки базы знаний

Мастер ведёт человека от скачанной папки кейса до работающей базы знаний. Человек не программист: он отвечает
в формах и нажимает то, что его просят; всё остальное делает агент. Инструкция для человека — `SETUP.md`.

## Главные правила мастера

1. **Один шаг — один экран.** Сначала карточка шага (формат ниже), сразу за ней форма. Не показывай два шага сразу.
2. **Каждый вопрос — формой.** Инструмент вопросов с вариантами (`AskUserQuestion`): до четырёх вопросов в форме, у каждого
   2–4 варианта, совет по умолчанию — первым, с пометкой «(советую)». Свой вариант человек вписывает в «Другое».
3. **Нет инструмента форм** — тот же вопрос нумерованным списком и строка «Ответьте цифрой, например: 1».
4. **Обязательны только шаги 0 и 1.** «Позже» — законный ответ на любой другой шаг: ставь `отложено` и иди дальше без уговоров.
5. **Ничего не включай молча.** Рутины, бот, публикация страницы — только после «да» в форме.
6. **Действие человека вне чата** (создать бота, открыть Obsidian) — нумерованная инструкция «куда нажать и что вписать»,
   затем форма «Готово — проверь / Не получилось / Позже». После «Готово» проверь сам.
7. **После каждого шага** — строка прогресса и одна фраза, что это даёт. Состояние сразу записывай в `hub/setup.md`.
8. **Секреты** (токен бота) в чат не проси, файл `hub/.secrets/telegram.json` не читай и не показывай.

## Формат карточки шага

```
Настройка: [x] 0 · [x] 1 · [>] 2 · 3 · 4 · 5 · 6 · 7        ([x] сделано, [~] отложено, [>] сейчас)

**Шаг 2 из 7. Словарь памяти** — необязательный, около 3 минут
Зачем: я буду понимать ваши сокращения и не переспрашивать.
Что сделаю я: запишу слова в словарь.
Что нужно от вас: назвать 3–5 сокращений или прозвищ, которыми вы пользуетесь.
Можно позже: да — слова можно добавлять по ходу работы: «запомни: СК — это …».
```

## Что умеет среда — определить перед первым шагом

Определи сам, человека не спрашивай. Результат запиши в `hub/setup.md`, раздел «Что умеет среда»
(`| Возможность | Есть / нет | Чем заменено |`), и дальше веди только по доступным шагам.

| Возможность | Как проверить | Если нет — чем заменено |
|---|---|---|
| Рабочая папка | видна папка кейса (`playbooks/`, `presets/`) или выбранная папка в Cowork | переносной режим L1: инструкция из `prompts/`, результат в чат |
| Python и скрипты `tools/` | `python --version` и `python tools/setup.py status` | поиск чтением файлов; уход и карта — вручную по плейбукам; мост Telegram недоступен; заявки `needs: code` |
| Поиск FTS5 | строка «Поиск по базе (FTS5)» в `setup.py status` | поиск чтением файлов |
| Субагенты (`librarian`, `kb-verifier`) | есть инструмент запуска агентов и папка `.claude/agents/` | проверка ответа отдельным вторым проходом |
| Формы (`AskUserQuestion`) | инструмент доступен | нумерованный список «ответьте цифрой» |
| Публикация страниц | есть инструмент публикации артефактов и работы с их данными | страница открывается как файл в учебном режиме; данные — в чате и Obsidian |
| Расписание | есть инструмент задач по расписанию | рутины записаны в `hub/routines.md` как `не включена`; запуск словами в чате |
| Навык `memory-management` | есть в списке навыков | словарь по правилам `02_kb.md` |
| Obsidian | спросить на шаге 3 | чат и страница «База знаний» |

Среда: работает Python и рядом есть `tools/` — Claude Code; есть папка, но нет Python — Cowork; папки нет — чат (L1).

| | Claude Code | Cowork | Чат без папки |
|---|---|---|---|
| Шаг 0 | `python tools/setup.py` | скопировать `references/presets/` в `hub/` рабочей папки | нет — см. `prompts/` |
| Поиск и проверка | индекс + субагент-проверяющий | чтение файлов + второй проход | по приложенным файлам Проекта |
| Шаг 5 (бот) | да | `недоступно в этой среде` | нет |
| Шаг 6 (рутины) | все | только «любая среда», если есть инструмент расписания | нет |

Шаги `недоступно в этой среде` в другой среде считаются незакрытыми — предложи их там.

## Приветствие — один раз

Показывай, только если в `hub/setup.md` стоит `Приветствие: не показано` (или файла ещё нет). Сразу после показа запиши
`Приветствие: показано ГГГГ-ММ-ДД`. В следующих сессиях — одна строка раз за разговор: «не настроено: …; продолжим?».

```
Здравствуйте! Я — Библиотекарь: веду вашу базу знаний и отвечаю на вопросы строго по вашим материалам —
со ссылкой на заметку. Чего в базе нет, так и говорю: «в базе этого нет». Всё общение — здесь, в чате.

Обязательны два шага (около 5 минут):
  0. Рабочая папка — создам сам.
  1. Профиль и первые материалы — ответите на несколько вопросов в форме.
Ещё шесть шагов необязательны: словарь памяти, Obsidian, страница «База знаний», бот Telegram, рутины, пробный запуск.
Ничего не включится без вашего «да».
```

**Форма «Старт».** «Как настроим?» — «Быстрый старт (советую)» — шаги 0 и 1, затем пробный запуск на учебных примерах;
«Полная настройка» — все шаги, 15–20 минут; «Сначала расскажи подробнее» — таблица шагов из `SETUP.md` и три фразы из
`GUIDE.md`, затем форма ещё раз; «Не сейчас» — ничего не менять.

## Шаг 0. Рабочая папка hub — обязательный, 1 минута

- Claude Code: `python tools/setup.py` (существующее не перезаписывает; шаг 0 отмечает сам).
- Cowork: создай `hub/` в рабочей папке и скопируй в неё `references/presets/` (то, чего ещё нет), создай пустые папки
  `kb/контрагенты`, `kb/решения`, `kb/проекты`, `kb/публикации`, `kb/справки`, `kb/входящее`, `memory/people`,
  `memory/context`, `handoff`. Отметь шаг 0 в `hub/setup.md`.
- Затем определи возможности среды (раздел выше) и запиши таблицу.

## Шаг 1. Профиль и первые материалы — обязательный, 3–4 минуты

**Форма 1.**
| Вопрос | Заголовок | Варианты |
|---|---|---|
| Кто вы по роли? | Роль | «Руководитель направления»; «Специалист / эксперт»; «Руководитель проекта»; своё — в «Другое» |
| О чём будет база? Впишите 2–5 тем через запятую | Темы | «Регламенты и решения моего направления (советую)»; «Контрагенты и договорённости»; «Проекты»; свои темы — в «Другое» |
| Что будете класть в базу? | Материалы | «Протоколы и решения»; «Регламенты и справки»; «Заметки после разговоров»; «Статьи и обзоры» (можно несколько) |
| С чего начнём? | Первые материалы | «Учебные примеры (советую)» — 10 вымышленных документов, потом уберу; «Мои файлы» — пришлите в чат или положите в `hub/kb/входящее/`; «Пока пусто» |

Запиши ответы в `hub/profile.md` (убери строку «профиль не заполнен»). Напомни одной строкой личное правило из профиля:
персональные данные, коммерческую тайну и документы с грифом в базу не кладём.
«Учебные примеры» — `python tools/demo.py load` (в Cowork — скажи, что примеры лежат в папке кейса `demo/hub/`, и скопируй
их, если папка кейса доступна). «Мои файлы» — разбери входящее по `02_kb.md`, режим Б.

## Шаг 2. Словарь памяти — необязательный, 3 минуты

Карточка — как в образце выше. **Форма 2:** «Назовите сокращения и прозвища, которыми пользуетесь (в „Другое“, в виде
„СК — ООО Северный контур; Орлов — начальник отдела закупок“)» — «Впишу сейчас»; «Собери из моих материалов (советую)» —
агент выписывает сокращения из базы и спрашивает расшифровку каждого формой; «Позже».
Записывай в `hub/memory/glossary.md` только подтверждённое человеком (приёмы — навык `memory-management`).
Скажи явно: «Словарь — это как вы говорите. Факты я беру только из базы».

## Шаг 3. Obsidian — необязательный, 2 минуты

Карточка: «Зачем: видеть базу как связанные заметки с графом, писать быстрые заметки. Без Obsidian всё работает в чате».
**Форма 3:** «Obsidian установлен?» — «Да, покажи, как открыть»; «Нет, обойдусь чатом и страницей (советую, если не пользовались)»; «Позже».
«Да»: инструкция — Obsidian → «Открыть папку как хранилище» → выбрать `hub` внутри папки кейса → открыть `Главная`.
Настройки уже лежат в `hub/.obsidian/`. Затем форма «Готово — проверь / Не получилось / Позже».

## Шаг 4. Страница «База знаний» — необязательный, 1 минута

Карточка: «Зачем: обзор базы, журнал противоречий с вашими кнопками „верно А / верно Б / обе устарели“, карта связей,
журнал вопросов. Страницу видите только вы».
**Форма 4:** «Опубликовать страницу?» — «Да (советую)»; «Сначала посмотреть учебный вид» — скажи открыть `artifacts/kb.html`
двойным щелчком; «Позже».
«Да» — по `13_artifact.md`: опубликуй `artifacts/kb.html` (в плагине — `references/kb.html`), запиши ссылку
в `hub/artifacts.md`, выполни первую сверку, дай ссылку. Нет инструмента публикации — `недоступно в этой среде`.

## Шаг 5. Бот Telegram — необязательный, 5–7 минут, только Claude Code

Карточка: «Зачем: сказать боту „запомни …“ или переслать сообщение — и оно окажется во входящем базы; задать вопрос
с телефона и получить ответ со ссылкой; получать сводку недели».
**Форма 5:** «Подключим своего бота?» — «Да»; «Позже». Дальше — по `15_telegram.md`, раздел «Подключение»:
инструкция для человека, `init` → человек вписывает токен сам → `check` → `whoami` → форма «Что разрешить боту»
(ответы на вопросы; сводка недели; подтверждение приёма) → строка в `hub/accounts.md`.
В Cowork — `недоступно в этой среде`: скажи, что бот подключается в Claude Code на компьютере.

## Шаг 6. Рутины — необязательный, 2 минуты

Карточка: «Зачем: входящее разбирается само, раз в неделю — список ухода и сводка».
**Форма 6:** «Какой набор включить?» — «Минимум (советую)» — разбор входящего и уход по пятницам; «Стандарт» — плюс
пересборка индекса и, если подключён бот, опрос Telegram и сводка недели; «Позже».
Создавай задачи по `14_routines.md` (тексты и расписание — оттуда), записывай в `hub/routines.md`.
Нет инструмента расписания — запиши рутины как `не включена` и скажи, какой фразой запускать вручную.

## Шаг 7. Пробный запуск и итог — показывается всегда

1. Если учебные примеры на месте (файлы `demo_*`) — задай базе вопрос «Какой срок согласования документов?» и покажи ответ:
   обе версии, ссылки, итог проверки. Затем «разбери входящее» — одна заметка. Сравни с `demo/пример_результата/`.
2. **Таблица состояния:** шаг — статус — что осталось за человеком.
3. **«Что вы теперь можете»** — пять фраз из `GUIDE.md` под включённое.
4. **Чего Библиотекарь не делает:** не отвечает «из головы», не закрывает противоречия, ничего не удаляет и не отправляет.
5. **Форма:** «Убрать учебные примеры?» — «Да» (`python tools/demo.py clean`); «Оставить ещё».
Обнови `hub/setup.md`, строка в журнал.

## Что должно быть в рабочей папке после шага 0

`profile.md`, `setup.md`, `accounts.md`, `routines.md`, `artifacts.md`, `journal.md`, `Главная.md`, `.obsidian/`,
`kb/` с шестью подпапками, `_шаблоны/`, `_противоречия.md`, `_вопросы.md`, `_уход.md`; `memory/glossary.md`; `handoff/`.
Заготовки — в `presets/hub/` (в плагине — `references/presets/`). Бери готовое, не сочиняй.
