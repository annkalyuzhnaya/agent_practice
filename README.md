# Практика «Личные агенты»

Пять треков — путь от одного тематического ассистента на Claude до флота ассистентов на любых моделях и до
самостоятельной сборки без Claude. Треки живут в двух «мирах»:

- **Мир Claude** — [`1_claude/`](1_claude/README.md): ассистенты работают на Claude.
- **Мир Hermes** — [`2_hermes/`](2_hermes/README.md): Claude собирает ассистентов для открытой среды Hermes Agent,
  дальше они работают на любых моделях по ключу API (а последний трек собирают и вовсе руками, без Claude).

> **Участнику:** откройте [`START.html`](START.html) двойным щелчком — это входная страница: карта кейсов и ссылки
> на руководство каждого. Из любого руководства в неё можно вернуться строкой меню вверху.

## Пять треков

| Трек | Что собираем | Где |
|---|---|---|
| **1** | тематический ассистент на Claude — 5 вариантов, выбираете и собираете один | [`1_claude/`](1_claude/README.md), кейсы `01_digest`…`05_docs` |
| **2** | личный помощник-оркестратор на Claude над всеми тематическими клод-ассистентами | [`1_claude/06_assistant/`](1_claude/06_assistant/README.md) |
| **3** | тематический ассистент для Hermes — Claude соберёт любой (5 готовых сценариев или свой) | [`2_hermes/`](2_hermes/README.md) + [`BUILD.md`](2_hermes/BUILD.md), образец `01_digest` |
| **4** | личный помощник-оркестратор на Claude над ассистентами Hermes (можно удалёнными) | [`2_hermes/orchestrator/`](2_hermes/orchestrator/README.md) |
| **5** | универсальный ассистент Hermes, собранный **руками, без Claude** — для не-программистов | [`2_hermes/manual/`](2_hermes/manual/README.md) |

Пять тематических ролей во всех треках одни и те же: **Обозреватель, База знаний, Встреча, Входящие, Документ-инженер**.
Трек 1 — пять этих ролей по отдельности (выбираете одну); трек 2 — все пять под одним оркестратором на Claude.
Трек 3 — те же роли, но собранные для Hermes; трек 4 — оркестратор над ними. Трек 5 — помощник общего назначения
(не тематический), который человек собирает сам.

## Как читать практику

1. **Начать с трека 1.** Откройте один из кейсов `1_claude/01_digest`…`05_docs` как проект, пройдите его `SETUP.md`
   и `LEVELS.md`. Это основа: понять, что такое шина `hub/`, плейбуки и роли.
2. **Собрать оркестратор (трек 2).** `1_claude/06_assistant` связывает все пять ролей в один стенд со сценарием
   «Мой день».
3. **Перейти в мир Hermes (трек 3).** В `2_hermes/` попросите Claude собрать тематического Hermes-ассистента по
   `BUILD.md` — готовый образец уже есть (`01_digest`).
4. **Оркестратор над Hermes (трек 4).** `2_hermes/orchestrator/` — тот же «Мой день», но роли исполняет флот Hermes,
   в том числе удалённо.
5. **Собрать руками (трек 5).** `2_hermes/manual/` — детальная инструкция для не-программиста собрать универсального
   помощника самостоятельно, без Claude.

## Общее

- [`skills_pack/`](skills_pack/README.md) — пак сторонних навыков с открытой лицензией; раскладывается по кейсам:
  `python skills_pack/sync.py` из корня репозитория.
- `python 2_hermes/sync.py` — переносит в кейсы трека 3 среда-независимые скрипты и учебные данные из мира Claude.
- Рабочие данные — в `hub/` внутри папки кейса; в репозиторий не попадают (как и `.secrets/`).
- Правила кейса — в его `playbooks/`; после правки — `python tools/build.py` в папке кейса. Сгенерированное
  (`.claude/`, `.hermes/`, `AGENTS.md`, плагин) руками не правят. Исключение — трек 5: там заготовки собраны вручную
  и сборки нет.
