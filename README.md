# Практика «Личные агенты»

Три трека: от ассистента, который работает на Claude, к ассистентам, которых Claude создаёт для других сред и моделей.

| Трек | Папка | Уровни | Суть |
|---|---|---|---|
| 1 | [1_claude/](1_claude/README.md) | 1–3 | шесть кейсов: ассистент работает на Claude (Claude Code, Cowork, чат) |
| 2 | [2_hermes/](2_hermes/README.md) | 4 | Claude собирает ассистента для Hermes Agent; дальше он работает на любых моделях по ключу API |
| 3 | `3_custom/` (в планах) | 5 | Claude пишет ассистента на собственном коде, без готовой среды |

Кейсы во всех треках одни и те же: Обозреватель, База знаний, Встреча, Входящие, Документ-инженер, Личный ассистент.
Каждая папка кейса самодостаточна: её можно скопировать отдельно, настроить и пользоваться.

## Общее

- [skills_pack/](skills_pack/README.md) — пак сторонних навыков с открытой лицензией; раскладывается по кейсам обоих
  треков: `python skills_pack/sync.py`.
- `2_hermes/sync.py` — переносит в кейсы трека 2 скрипты и учебные данные из трека 1.
- Рабочие данные — в `hub/` внутри папки кейса; в репозиторий не попадают.
- Правила кейса правятся в `playbooks/`, затем `python tools/build.py` в папке кейса.
