Практика «Личные агенты»

С чего начать

Это входная страница практики. Выберите кейс — откроется его руководство. Вернуться сюда и перейти к другому кейсу можно из строки меню вверху любого руководства.

Руководства открываются в браузере и ничего не устанавливают. Всё, что вы будете делать, происходит в папке кейса: её открывают в Claude Code или в Hermes.

Как устроен любой кейс

Кейс — это папка. Агент становится «Обозревателем» или «Входящими» не от настроек программы, а потому, что в начале разговора читает правила из этой папки.

Папка кейса = проект

Её открывают в Claude Code (или в Hermes). Агент работает только в ней.

Правила

CLAUDE.md (в Hermes — AGENTS.md) и папка playbooks/: кто такой агент, что делает, чего не делает без вашего «да».

Ваши данные — hub/

Появляется при настройке: профиль, результаты, память, задачи. Её ведёт агент; беречь стоит именно её.

Учебные данные — demo/

Готовый пример входных материалов и результата: можно посмотреть, с чем работает агент, ещё до настройки.

Мир Claude агент работает на Claude

Пять тематических агентов — выбираете одного. Личный ассистент объединяет всех пятерых.

Кейс 1

Обозреватель

Дайджест по вашим темам: до 10 публикаций с оценкой и «почему важно вам», ТОП-3.

Открыть руководство → Кейс 2

База знаний

Ответы строго по вашим материалам со ссылкой на источник, заметки, журнал противоречий.

Открыть руководство → Кейс 3

Встреча

Бриф до встречи; мемо, задачи и черновик письма после.

Открыть руководство → Кейс 4

Входящие

Разбор писем и обращений, черновики ответов, задачи. Сам ничего не отправляет.

Открыть руководство → Кейс 5

Документ-инженер

Документы Word и Excel по шаблону, точечные правки с проверкой, версии.

Открыть руководство → Все пять вместе

Личный ассистент

Пять агентов под одним оркестратором: сценарий «Мой день», общая доска, рутины.

Открыть руководство →

Мир Hermes агент работает на любой модели по ключу API

Hermes Agent — открытая программа-агент на вашем компьютере. Подписка Claude для ежедневной работы не нужна: вы платите провайдеру модели за фактический расход.

Тематический ассистент

Обозреватель в Hermes

Тот же Обозреватель, собранный для Hermes: модель под каждую роль, расписание, Telegram.

Открыть руководство → Оркестратор

Помощник над флотом Hermes

Claude-дирижёр: раздаёт задачи ассистентам Hermes, в том числе удалённым, и сводит их в один план дня.

Открыть описание → Своими руками

Универсальный помощник

Сборка помощника на Hermes без Claude — пошагово, для тех, кто не программирует.

Открыть руководство →

Нужен другой тематический ассистент для Hermes (База знаний, Встреча, Входящие, Документ-инженер или свой)? Откройте папку 2_hermes в Claude Code и напишите «собери ассистента для Hermes» — Claude соберёт его по образцу Обозревателя.

Скопировали папку кейса отдельно от практики — её руководство работает само, а ссылки на соседние кейсы в меню ведут в никуда: возвращайтесь к этой странице в исходной папке.

Для авторов практики: skills_pack/ и скрипты sync.py, tools/build.py — служебные, собирают навыки и правила в папки кейсов. Участнику открывать их не нужно. Карта для авторов — README.md.
