# Личный ассистент — комплексный инструмент личной эффективности

Пять агентов из практики, собранные в один связанный стенд: **обозреватель, база знаний, встреча, входящие, документ-инженер** + сценарий **«Мой день»**, который запускает их по цепочке и выдаёт один план дня.

> **Начать здесь:** [SETUP.md](SETUP.md) — установка и настройка под ключ (Claude Code и Cowork).
> **Как пользоваться:** [GUIDE.md](GUIDE.md) — готовые фразы на каждый день; в чате — слово «помощь».
> **Куда расти:** [LEVELS.md](LEVELS.md) — путь от кейсов 1–5 к ассистенту и четыре уровня с заданиями.

Это кейс №6 практики — комплексный. Кейсы 1–5 (`01_digest` … `05_docs` рядом) — те же агенты по одному; их папка `hub/`
устроена так же, поэтому наработанное в них переносится сюда копированием (как — в [LEVELS.md](LEVELS.md)).

## Две папки

| Папка | Что это |
|---|---|
| **Исходник** (эта папка, `agent_practice/06_assistant`) | правила, скрипты, заготовки, сборка плагина. Личных данных здесь нет, ассистент здесь не работает |
| **Папка ассистента** | создаётся при первом запуске (`python tools/install.py "путь"` или «настрой ассистента» в чате). В ней копия системы и шина `hub/` с данными владельца; вся работа идёт там |

Обновление: правки вносятся в исходнике → `python tools/build.py` → `python tools/install.py` (обновляет системные файлы в папке ассистента, `hub/` не трогает).

Ассистент был установлен раньше, когда исходник лежал в корне `agent_practice`? Ничего переустанавливать не нужно: откройте
сессию в `agent_practice/06_assistant` и напишите «обнови ассистента» — раздел 7 в [SETUP.md](SETUP.md).

## Как это устроено

```
        Cowork (плагин personal-hq)                Claude Code (эта папка)
        8 навыков + навыки пака                    8 навыков + навыки пака + 10 субагентов + скрипты tools/
               │                                              │
               └──────────────►  hub/ — общая шина  ◄─────────┘
                                 profile · inbox · tasks · calendar · digest
                                 kb · meetings · docs · handoff · plan · journal
```

- **Шина `hub/`** — единственный способ связи агентов. Каждый читает, что оставили другие, и кладёт результат туда, где его подберёт следующий. Поэтому агенты в Cowork и в Claude Code работают как одна система.
- **Плейбуки `playbooks/`** — единый источник правил. Из них собираются и субагенты Claude Code, и плагин Cowork (`python tools/build.py`).
- **Доска ассистента** — личная интерактивная страница (артефакт claude.ai) с семью вкладками: задачи, почта с готовыми ответами, встречи, дайджест, документы и заявки агентам, противоречия в базе знаний, пульт рутин; в шапке — состояние каналов. Шаблон — `artifacts/hq.html`; открытый с диска двойным щелчком, он показывает учебные данные — так доску можно посмотреть без публикации. Личная доска владельца публикуется из шаблона на шаге 4 настройки, её ссылка — в `hub/artifacts.md` папки ассистента. Правила — `playbooks/13_artifacts.md`.
- **Навыки пака** (`pack/skills/`) — сторонние навыки, которые сборка кладёт рядом с навыками ассистента: словарь владельца, приёмы ведения задач, отчёт недели, страницы-отчёты, усиленный веб-поиск, конструктор навыков. Что для чего — раздел «Навыки пака» в [SETUP.md](SETUP.md).
- **Obsidian** — интерфейс базы знаний: папка `hub/` открывается как хранилище, настройки и шаблоны уже внутри.
- **Заявки `hub/handoff/`** — мост между средами: то, что Cowork не может (скрипты), он оформляет заявкой, а Claude Code выполняет её при следующем запуске.

## Что где работает

Мастер настройки сам определяет, что умеет среда, и ведёт только по доступному; результат проверки записан в `hub/setup.md` (таблица «Среда»).

| Возможность | Claude Code на компьютере | Cowork (плагин) | Чат claude.ai без папки |
|---|---|---|---|
| Письма, встречи, дайджест, база знаний, «Мой день» | да; роли — субагенты, часть шагов параллельно | да; роли — последовательными проходами в одном разговоре | один ответ в чате и блок «сохранить в hub/inbox/new/» |
| Шина `hub/` и память между разговорами | да | да, в выбранной рабочей папке | нет |
| Документы Word и Excel | полный конвейер: шаблон, точечная правка, проверка целостности, версии | простые документы; правка с проверкой и версии — заявкой, её выполнит Claude Code | текстом |
| Поиск по базе знаний | локальный индекс | чтением файлов | — |
| Веб-поиск для дайджеста и брифов | да; усиление — навыки Tavily (по желанию) | да, если веб-поиск включён | да, если включён |
| Почта и календарь (коннекторы) | да | да | да, без записи на шину |
| Свой Telegram-бот | да | нет: мосту нужен Python | нет |
| Рутины по расписанию | все девять | только рутины без Python и только если в среде есть расписание; остальные ждут Claude Code | нет |
| Доска (страница с хранилищем) | да | да, если доступна публикация страниц; иначе «лёгкая доска» с задачами | нет |
| Учебные примеры и пробный запуск | да (`tools/demo.py`) | на своих данных | — |

Агенты и их имена в Claude Code: Обозреватель (`scout`), Библиотекарь (`librarian`), Встреча (`meeting-prep`), Входящие
(`inbox-classifier` → `inbox-drafter` → `inbox-prioritizer`), Документ-инженер (`doc-parser` → `doc-generator` → `doc-validator` → `doc-versioner`).

## Комплексный сценарий «Мой день»

1. **Обозреватель** ищет по темам профиля → дайджест; важное уходит в базу знаний и в предложенные задачи.
2. **Входящие**: классификатор → составитель → приоритизатор. Задачи (только адресованные лично) → `tasks.md`; письма с готовыми ответами → обзор почты `inbox/mail.md`; приглашения → `calendar.md`; работа с документами → заявка документ-инженеру.
3. **Встреча** готовит бриф по каждой встрече ближайших 3 дней: база знаний + открытые источники + свежий дайджест.
4. **Документ-инженер** выполняет заявки: шаблон → отчёт, точечная правка → проверка целостности → версия.
5. **Библиотекарь** принимает всё созданное, связывает заметки, фиксирует противоречия.
6. **План дня** `hub/plan/дата.md`: сегодня / на неделе / делегировать / требует моего решения.

Решения, отправка писем и выбор действующей версии документа всегда остаются за вами: агенты готовят только черновики. Единственное исключение — ответ на письмо, который вы сами отправили кнопкой «Отправить» на доске.

## Первый запуск: «настрой ассистента»

Полная инструкция — в [SETUP.md](SETUP.md). Коротко: откройте папку в Claude и напишите **«настрой ассистента»**. Ассистент поздоровается и поведёт как мастер установки: один шаг — один экран, перед шагом — карточка «зачем / что сделаю я / что нужно от вас», каждый вопрос — форма с вариантами (свой ответ — в поле «Другое»). Обязательны только шаги 0 и 1 (около 5 минут); остальные можно отложить и вернуться словами «продолжи настройку». Состояние хранится в `hub/setup.md`. В конце ассистент показывает, что включено и как им пользоваться.

| Шаг | Обязателен? | Что делает ассистент | Что нужно от вас |
|---|---|---|---|
| 0. Создать папку ассистента | **да** | `python tools/install.py "путь"`: отдельная папка с копией системы, шина `hub/`, заготовки, пресет Obsidian | выбрать место |
| 1. Профиль | **да** | две формы: роль, фокус, рабочие часы, темы, источники, кому делегируете, тон | выбрать ответы |
| 2. Каналы | нет | подключает календарь, личную почту, Telegram; записывает правила доступа в `hub/accounts.md` | нажать «подключить»; для Telegram — создать бота и вписать токен в файл |
| 3. Рутины | нет | показывает наборы «минимум / стандарт / полный» из `playbooks/14_routines.md` и создаёт задачи по расписанию; дальше ими управляют с вкладки «Рутины» доски | выбрать набор и время |
| 4. Доска | нет | публикует личную страницу (задачи, почта, встречи, дайджест, документы, база, рутины) и сверяет её с шиной | закрепить страницу |
| 5. Obsidian | нет | — | «Открыть папку как хранилище» → `hub` |
| 6. Пробный запуск | нет | «Мой день» на учебном наборе или ваших данных | посмотреть результат |
| 7. Итог | — | что включено, готовые фразы, чего ассистент не делает | выбрать, с чего начать |

### Рутины (пресет)
| Рутина | Когда | Что делает |
|---|---|---|
| `hq-morning` | будни 08:30 | утренний «Мой день» и сводка в Telegram |
| `hq-handoff` | будни, каждые 2 часа | заявки из Cowork, которым нужны скрипты |
| `hq-meeting-eve` | будни 17:00 | брифы к завтрашним встречам |
| `hq-evening` | будни 18:30 | итог дня, сверка доски |
| `hq-weekly-review` | пятница 16:00 | обзор недели |
| `hq-kb-care` | пятница 16:30 | уход за базой знаний |
| `hq-weekly-digest` | понедельник 09:00 | дайджест недели |
| `hq-mail-pull`, `hq-tg-pull` | по подключении каналов | забрать почту и Telegram на шину |

Задачи выполняются, пока приложение Claude открыто на компьютере. Ничего не включается без вашего «да».
Вкладка «Рутины» доски — пульт: какие рутины работают, когда был последний запуск и чем закончился, что пропущено;
кнопками можно попросить включить, поставить на паузу, запустить сейчас или сменить время. Страница сама ничего не
запускает: просьбу выполняет ассистент в ближайшем разговоре и только для рутин из этого списка.

### Telegram
Свой бот (создаётся у @BotFather за две минуты) работает как почтовый ящик ассистента: вы пересылаете ему сообщения и пишете просьбы — `tools/tg_bridge.py pull` кладёт их во входящие; ассистент пишет вам сводки и напоминания; в группы из вашего списка — только после вашего «да» на точный текст. Токен вы вписываете сами в `hub/.secrets/telegram.json`. Бот не видит ваши личные переписки и историю групп; ответ не мгновенный — ящик проверяется по расписанию.

## Как пользоваться: просто пишите в чат

Вы общаетесь с одним агентом — оркестратором «Ассистент» (`playbooks/11_chat.md`). Папки и команды знать не нужно:
вставьте письмо, приложите документ, напишите «у меня встреча с … в четверг», «что срочного», «что мы решили по …» —
оркестратор сам разложит это по шине, подключит нужных агентов и покажет результат в чате. Решения («да, подтверждаю»,
«действует новая версия») тоже говорите в чате — он запишет.

1. **Claude Code.** Откройте новую сессию в папке ассистента и пишите обычным языком: роль оркестратора задана в её `CLAUDE.md`.
2. **Cowork.** Установите плагин `dist/personal-hq.plugin` (перетащите файл в чат Cowork и подтвердите установку), выберите папку ассистента рабочей и напишите «ассистент» или сразу свою задачу.
3. **Профиль** расскажите оркестратору словами («мои темы — …, делегирую …») — он обновит `hub/profile.md`.

Команды `/hq`, `/setup`, `/my-day`, `/digest`, `/inbox`, `/meeting`, `/kb`, `/docs` остаются как короткий путь, но не обязательны.
Работать с шиной руками тоже можно: входящие — в `hub/inbox/new/`, документы — в `hub/docs/in/`, заметки — в `hub/kb/входящее/` (в Obsidian новые заметки создаются там сами).

Учебный набор (`demo_*`: 8 входящих, две заметки с противоречием, регламент, выгрузка и шаблоны) загружается в папке ассистента на шаге «Пробный запуск» или командой `python tools/demo.py load`; убрать — `python tools/demo.py clean`. Пример результата — в `demo/пример_результата/`: пробный прогон «Моего дня» на учебном наборе 01.10.2026 (план дня, разбор, черновики, бриф, заявки, противоречия). Он сделан до уточнения плейбуков по итогам прогона, поэтому мелкие детали оформления могут отличаться (например, в таблицах нет колонки «ID» — её добавляет сверка с доской). Этот же пример служит эталоном для проверочных прогонов на инженерном уровне ([LEVELS.md](LEVELS.md)).

## Доступ с разных устройств

- Плагин Cowork привязан к вашей учётной записи, но **шина — это папка на этом компьютере**. Чтобы агенты на другом устройстве видели ту же шину, папку нужно синхронизировать (облачный диск) либо запускать задачи на этом компьютере удалённо.
- Без папки (например, чат с телефона) навыки работают в **переносном режиме**: результат выдаётся в чат вместе с блоком «сохранить в hub/inbox/new/», и при следующем запуске на компьютере попадает на шину.
- Документный конвейер со скриптами работает только там, где есть Python, — то есть в Claude Code на этом компьютере. С других устройств ставьте ему задачи заявками.
- `hub/` исключена из git (`.gitignore`): в ней личные данные. Синхронизировать шину через GitHub стоит, только если репозиторий приватный.

## Скрипты

| Команда | Назначение |
|---|---|
| `python tools/parser.py файл` | структура документа: разделы/листы с хэшами |
| `python tools/generator.py fill шаблон данные.json --out …` | документ по шаблону (`{{ключ}}`, `{{rows:список}}`) |
| `python tools/generator.py update-section док.docx --section … --text-file … --out …` | точечная правка раздела |
| `python tools/integrity_diff.py до после --allow "раздел"` | проверка: изменилось только разрешённое |
| `python tools/versions.py add / list / diff` | версионное хранилище документов |
| `python tools/kb_index.py build / search "запрос"` | локальный поиск по шине |
| `python tools/build.py` | пересобрать субагентов, навыки и плагин после правки плейбуков |
| `python tools/install.py "путь" [--demo]` / без аргументов / `where` | **только в исходнике**: создать папку ассистента (`--demo` — сразу с учебными примерами); обновить её системные файлы (`hub/` не трогается); показать, где она |
| `python tools/setup.py` / `status` | в папке ассистента: досоздать шину и пресет Obsidian из `presets/hub/`; показать состояние настройки |
| `python tools/tg_bridge.py init / check / whoami / pull / send` | мост Telegram ↔ шина |
| `python tools/demo.py load / clean` | учебный набор |

## Ограничения

- Только нативные `.docx/.xlsx` (не PDF и не сканы). Точечная правка заменяет абзацы раздела; таблицы раздела не трогает.
- Почта и календарь подключаются коннекторами claude.ai (их включаете вы), Telegram — своим ботом; пока не подключены, входящие и встречи попадают на шину через чат. Правила доступа — в `hub/accounts.md`.
- Доска обновляется при сверке (в начале разговора, в «Моём дне», в утренней и вечерней рутинах), а не мгновенно. Кнопки на ней записывают ваше решение; выполняет его ассистент при сверке.
- Навыки пака — сторонние, на английском языке и рассчитаны на свои файлы (`TASKS.md`, `memory/`); ассистент берёт из них приёмы, а хранит всё по правилам шины. Навыкам Tavily нужна отдельная программа и учётная запись сервиса.
- Поиск по базе — полнотекстовый (по словам с усечением окончаний), не семантический.
- Рутины по расписанию работают, только пока приложение Claude открыто; мост Telegram и документный конвейер — только в Claude Code на компьютере.
