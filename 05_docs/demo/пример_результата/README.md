# Пример результата

Так выглядит рабочая папка после обработки трёх учебных заявок (прогон 2026-10-04, все данные вымышленные).

| Файл | Что это |
|---|---|
| `ход_конвейера.txt` | команды и вывод скриптов как есть: парсер, генератор, валидатор, версионер, отрицательный случай, хук, эвалы |
| `2026-10-04_demo_регламент.docx` | регламент после точечной правки раздела 3 (версия v3) |
| `2026-10-04_demo_отчёт_сентябрь.docx` | отчёт, собранный по шаблону из данных |
| `2026-10-04_сравнение_demo_reglament_v2-v3.html` | локальная страница сравнения версий — откройте двойным щелчком |
| `проверки/` | отчёты целостности: один «соблюдена», один «нарушена» (правка коллеги задела разделы 2.2 и 7) |
| `заявки/` | закрытые заявки с разделом «Результат»: две дошли до этапа «версия», одна «отклонено» |
| `registry.md` | реестр заявок, документов и проверок |

Действующая версия ни у одного документа не назначена: это решение человека.
