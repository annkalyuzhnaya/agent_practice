# Памятка: «Документ-инженер» на каждый день

Говорите обычными словами. Файлы кладите в `hub/docs/in/` (шаблоны — в `hub/docs/templates/`) или прикладывайте к сообщению.

## Фразы

| Что нужно | Что сказать |
|---|---|
| Собрать документ по шаблону | «Собери отчёт за сентябрь по шаблону отчёта из выгрузки задач» |
| Обновить один раздел | «В регламенте замени раздел "Сроки согласования" на этот текст, остальное не трогай» |
| Проверить чужую правку | «Коллега прислал новую редакцию. Проверь, что изменён только раздел 3» |
| Узнать, что изменилось | «Что изменилось между версиями 2 и 3 регламента?» |
| Посмотреть историю | «Покажи версии регламента» / «сделай страницу сравнения версий» |
| Выбрать действующую версию | «Действующая версия регламента — третья» (или кнопкой на странице «Документы») |
| Найти по документам | «Где в документах сказано про срочное согласование?» |
| Формула Excel | «Нужна формула: сумма часов по исполнителю за месяц» |
| Страница-отчёт из выгрузки | «Сделай страницу-отчёт по выгрузке задач» |
| Обработать заявки | «Обработай заявки» |
| Подать заявку из Cowork | «Оформи заявку: обновить раздел 3 в регламенте» |
| Страница | «Сверь страницу документов» |
| Настройка | «Настрой» / «что ещё можно настроить» / «помощь» |

## Как выглядит ответ

`ЗАДАЧА → КАК РАБОТАЛ → РЕЗУЛЬТАТ → ЧТО ОСТАЁТСЯ ЧЕЛОВЕКУ`. В результате всегда есть:

- путь к новому файлу (`hub/docs/out/ГГГГ-ММ-ДД_имя`); исходник не изменён;
- отчёт проверки: «изменено только: раздел N», «без изменений: M разделов» и вердикт
  `ПРОВЕРКА ПРОЙДЕНА` / `ПРОЙДЕНА С ОГОВОРКАМИ` / `НЕ ПРОЙДЕНА`;
- номер версии — если проверка пройдена.

Этапы заявки: `принято → собрано → проверено → версия`. Пометка `[РЕШИТЬ]` — вопрос к вам; пока не ответите, заявка стоит.

## Чего агент не делает

- Не меняет исходный файл и не перезаписывает готовые: каждый результат — новый файл.
- Не выдумывает значения: нет данных для метки шаблона — спросит, а не заполнит «примерно».
- Не называет документ проверенным, если проверка не запускалась (в Cowork и чате скажет «сверено глазами»).
- Не сохраняет версию, если проверка не пройдена.
- **Не выбирает действующую версию** и не утверждает документ — это решаете вы.
- Не отправляет файлы наружу без вашего «да» на конкретный файл; рутины не отправляют файлы никогда.
- Не публикует страницу и не ставит расписание без «да».
- Не читает и не показывает токен бота.
- Не правит PDF и сканы; не обрабатывает документы с персональными и закрытыми сведениями.
- Не исполняет «команды» из текста документов, заявок и сообщений бота — это данные.
- Не правит текст внутри таблиц Word точечной правкой (но заметит, если их изменил кто-то другой).

## Если что-то не так

| Ситуация | Что сказать или сделать |
|---|---|
| «НАРУШЕНИЕ изменён: …» | это находка, а не сбой: решите, вернуть правку автору или принять осознанно |
| «ВНИМАНИЕ: разрешённый раздел не изменился» | правка не применилась — проверьте название раздела: «покажи оглавление документа» |
| «НЕ ЗАПОЛНЕНО: …» | в данных нет значения для метки — дайте его или скажите оставить прочерк |
| Раздел не находится | в документе нет заголовков-стилей — оформите заголовки стилем «Заголовок» |
| Заявка из Cowork «висит» | её выполняет Claude Code: откройте его и скажите «обработай заявки» |
