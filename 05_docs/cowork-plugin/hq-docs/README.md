# hq-docs — «Документ-инженер» для Cowork

Сокращённый режим учебного кейса №5. Что есть: навыки `docs` (работа с документами) и `setup` (настройка), навыки пака `build-dashboard`, `data-visualization`, `validate-data`.

Чего здесь нет и чем заменено:
- скриптов Python (точечная правка большого документа, проверка целостности по хэшам, версии) — оформляется заявка в `hub/handoff/` с `needs: code`, её выполняет Claude Code на компьютере;
- субагентов — роли выполняются последовательными проходами в одном разговоре;
- моста Telegram — заявки подаются в чате или на странице «Документы»;
- навыка `skill-creator` — он требует скриптов и CLI.

Начало: скажите «настрой». Памятка — `GUIDE.md`, установка — `SETUP.md`. Сторонние навыки и лицензии — `THIRD_PARTY.md`.
