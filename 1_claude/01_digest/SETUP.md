# Установка Обозревателя

Три способа — выберите свой. Везде дальше вы общаетесь с агентом в чате: папки и команды — его дело.

| Способ | Что получите | Что нужно |
|---|---|---|
| **А. Claude Code** | всё: субагенты, скрипты, страница, расписание, Telegram-бот | Claude Code на компьютере, Python 3.9+ |
| **Б. Cowork** | выпуск, отметки, страница и расписание (если доступны в вашей среде) | приложение Claude с Cowork |
| **В. Проект claude.ai** | выпуск в чате по вставленным ссылкам и текстам (уровень L1) | только браузер |

## А. Claude Code — полная версия

1. Скачайте папку `01_digest` и откройте её в Claude Code (в приложении: «Открыть папку»; в терминале: `claude` из
   этой папки).
2. Напишите: **«настрой»**. Мастер сам:
   - проверит, что умеет среда (Python, веб-поиск, расписание, публикация страниц), и запишет это в `hub/setup.md`;
   - создаст рабочую папку `hub/` (ваши данные; в git она не попадает);
   - задаст четыре вопроса и заполнит профиль: роль, темы, «не интересно», источники.
3. Дальше — по желанию и в любой день («продолжи настройку»): пробный выпуск, страница, расписание, Telegram, Tavily.

Разрешения. В папке лежит `.claude/settings.json`: агенту заранее разрешены скрипты кейса и веб-поиск и **запрещено
чтение `hub/.secrets/`**. Остальное Claude Code спросит по ходу.

Если вы правили плейбуки — пересоберите: `python tools/build.py` (обновит `.claude/agents`, `.claude/skills`, плагин).

## Б. Cowork — плагин `hq-digest`

1. Установите плагин: файл `dist/hq-digest.plugin` (Настройки → Возможности / Плагины → установить из файла; название
   пункта зависит от версии приложения).
2. Создайте пустую папку (например, «Документы → Обозреватель»), выберите её рабочей папкой и напишите **«настрой»**.

**Что в Cowork урезано и чем заменено** (честно):

| Нет в Cowork | Чем заменено |
|---|---|
| Субагенты «разведчик» и «проверяющий» | один агент выполняет те же роли последовательными проходами; проверка — отдельным проходом «чужими глазами» |
| Python-скрипты (сбор лент RSS, сверка памяти, проверка формы, приёмка, карточка) | агент делает то же чтением файлов по разделу «Если скриптов нет»; для сбора лент — заявка в `hub/handoff/` с `needs: code`, её выполнит Claude Code |
| Мост Telegram | утренний ТОП-3 приходит в чат запланированной задачи; ссылки «посмотри это» — вставкой в чат |
| Навыки Tavily и `skill-creator` | встроенный веб-поиск; свой навык — в Claude Code |
| Страница и расписание | работают, если в вашей среде есть публикация страниц и запланированные задачи; иначе — выпуск по слову «дайджест» и карточка-файл |

## В. Проект claude.ai — без установки (L1)

1. В claude.ai создайте Проект «Обозреватель».
2. В поле инструкций Проекта вставьте текст из [prompts/L1_проект_claude_ai.md](prompts/L1_проект_claude_ai.md),
   заполнив в нём блок «Мой профиль».
3. В чате Проекта вставьте 5–10 ссылок или текстов и напишите «дайджест». Для пробы возьмите
   [demo/digest_10источников.md](demo/digest_10источников.md) — прикрепите файл к чату.

Память «уже видел» в этом режиме — список в конце каждого выпуска: вставляйте его в следующий раз.

## Проверка «всё работает»

Попросите агента: **«проверь установку на учебном примере»**. Он выполнит (в Claude Code):

| Шаг | Команда | Что должно получиться |
|---|---|---|
| 1 | `python tools/setup.py status` | профиль, выпуски, шаги настройки — списком |
| 2 | `python tools/demo.py load` | учебный пакет и строка в памяти «уже видел» |
| 3 | выпуск за `2026-10-02` по пакету | файл `hub/digest/2026-10-02.md` |
| 4 | `python tools/issue.py check 2026-10-02` | «Форма в порядке» |
| 5 | `python tools/evals.py` | «приёмка пройдена» (эталон — [demo/пример_результата/](demo/пример_результата/README.md)) |
| 6 | `python tools/demo.py clean` | учебные объекты убраны, ваш профиль не тронут |

Учебный выпуск (`hub/digest/2026-10-02.md`) после разбора агент удаляет по вашему слову.
В Cowork шаги 3 и 5 агент выполняет чтением: сравнивает свой выпуск с ожидаемыми решениями из учебного набора.

## Страница «Дайджест»

- **Посмотреть до публикации:** откройте `artifacts/digest.html` двойным щелчком — учебный режим с вымышленными данными.
- **Опубликовать:** скажите «сделай страницу». Агент опубликует её как личный артефакт claude.ai с хранилищем данных,
  запишет ссылку в `hub/artifacts.md` и выгрузит последний выпуск. Страница видна только вам; доступ открываете только
  вы — меню «Поделиться».
- **Как работают отметки:** кнопка на странице записывает вашу просьбу в хранилище; агент выполняет её при сверке
  (в начале разговора, после выпуска, по слову «сверь страницу» или по кнопке «Сверить сейчас», если страница открыта
  рядом с разговором).
- **Нет публикации страниц в вашей среде:** выпуск в чате, отметки номерами, для коллег — карточка
  `hub/digest/cards/ГГГГ-ММ-ДД.html` («карточка для коллег»).

## Расписание

Скажите «включи расписание». Наборы:

| Набор | Что включается |
|---|---|
| Минимум | дайджест недели — понедельник 09:00 |
| Стандарт | + уход за темами (пятница 16:00) и, если подключён бот, приём из Telegram каждые 30 минут днём |
| Ежедневный | короткий выпуск по будням в 08:30 вместо недельного |

Задачи выполняются, пока приложение Claude открыто на компьютере; пропущенный запуск сработает при следующем открытии.
Нет инструмента запланированных задач — агент скажет об этом, выпуск остаётся по слову «дайджест».
Отключить: «поставь дайджест на паузу» / «отключи расписание».

## Telegram-бот

Свой бот — личный канал между вами и агентом. **Только Claude Code на вашем компьютере.**

Что бот делает в этом кейсе: утром присылает вам ТОП-3 выпуска; принимает пересланные вами ссылки и посты «посмотри
это» в очередь источников; понимает слова `дайджест`, `топ`, `темы` (выполняются при очередном опросе, а не мгновенно).
Бот пишет только вам и принимает сообщения только от вас.

1. В Telegram откройте `@BotFather` → `/newbot` → задайте имя и адрес бота → получите токен.
   **Токен в чат с агентом не вставляйте.**
2. Скажите агенту «подключи телеграм». Он выполнит `python tools/tg_bridge.py init` и назовёт путь к файлу
   `hub/.secrets/telegram.json`. Откройте файл сами (Блокнотом) и впишите токен в поле `token`. Агент этот файл не
   читает и не показывает — токен использует только скрипт.
3. Агент выполнит `python tools/tg_bridge.py check` — ответ «Бот на связи: @имя».
4. Напишите своему боту `/start`. Агент выполнит `python tools/tg_bridge.py whoami` и покажет строку с вашим номером
   `owner_id`. Впишите этот номер в поле `owner_id` того же файла сами.
5. Проба (по вашему «да»): бот пришлёт вам «Обозреватель на связи».
6. Приём сообщений: рутина `digest-tg-pull` (входит в набор «Стандарт») или слова «забери телеграм».

Проверить приём без сети и без бота: `python tools/tg_bridge.py pull --from-file demo/tg_updates_demo.json --owner 1000001`.

**В Cowork мост не работает** (нужен Python на вашем компьютере). Замена: ТОП-3 — в чат запланированной задачи,
ссылки — вставкой в чат.

**Альтернатива для уровня L5** — официальный плагин `telegram` для Claude Code: живой диалог с ботом из открытой
сессии. Подключается из каталога плагинов (в Claude Code — команда `/plugin`), настраивается по его документации.
Здесь он не копируется. Не используйте его и мост кейса с одним и тем же ботом одновременно: сообщения достанутся
тому, кто опросил первым. Заведите второго бота.

## Навыки

Навыки пака лежат в `pack/skills/` и подключаются сборкой — отдельно ставить их не нужно.

| Навык | Зачем в этом кейсе | Нужен ли ключ / подключение | Как проверить |
|---|---|---|---|
| `tavily-search` | поиск со свежестью «за неделю» и по новостям, когда встроенный поиск приносит мало | командная строка `tvly`; первые запросы — без ключа, дальше — вход `tvly login` (бесплатный ключ Tavily) | `python tools/setup.py status` → «команда tvly найдена»; фраза «найди через Tavily …» |
| `tavily-extract` | чистый текст страницы, которую не открыл встроенный инструмент | то же | «открой через Tavily: ссылка» |
| `tavily-research` | разовый глубокий обзор одной темы со ссылками (не выпуск) | `tvly` и вход с ключом | «разбери тему глубоко: …» |
| `internal-comms` | сопроводительный текст к карточке выпуска для коллег | нет | «карточка для коллег» → текст из трёх частей: главное, что это значит для нас, что нужно от читателя |
| `build-dashboard` | разовая страница-обзор за месяц (без хранилища) | нет | «сделай обзор выпусков за месяц страницей» |
| `skill-creator` | собрать свой навык (уровень L5) | только Claude Code | «создай навык …» |

**Tavily — необязательное усиление.** Базовый путь — встроенный веб-поиск. Как поставить командную строку `tvly`
и войти, описано в навыке `tavily-cli` из пака (фраза «поставь Tavily» — агент покажет шаги). Ключ вы вводите
сами в окне входа Tavily; агенту его не сообщайте. После установки скажите «продолжи настройку» — агент отметит шаг 6
и впишет Tavily в `hub/accounts.md`.

**Что не скопировано в кейс (лицензии) и как подключить из каталога.** В приложении: Настройки → Возможности /
Плагины; в Claude Code: команда `/plugin`.

| Что | Зачем могло бы пригодиться | Запасной путь без него |
|---|---|---|
| Навыки Anthropic `docx`, `xlsx`, `pptx`, `pdf` | выгрузить выпуск документом Word или слайдом; прочитать PDF-источник | выпуск остаётся в Markdown и карточкой HTML; PDF — вставить текст в чат |
| `schedule` (запланированные задачи) | расписание выпусков | выпуск по слову «дайджест»; напоминание в своём календаре |
| Desktop Commander | работа с файлами вне рабочей папки | не нужен: кейс работает только внутри своей папки |
| Официальный плагин `telegram` | живой диалог с ботом (L5) | мост `tools/tg_bridge.py` с опросом по расписанию |

## Если что-то пошло не так

| Признак | Что сделать |
|---|---|
| Агент не знает слова «настрой» | папка открыта не та (нужна `01_digest`) или не собраны навыки: `python tools/build.py` |
| «Рабочая папка не создана» | скажите «настрой» — или `python tools/setup.py` |
| Выпуск пустой | темы слишком узкие или источники недоступны из вашей сети: «покажи, что не удалось открыть» |
| В выпуске повторы | «синхронизируй память» (`python tools/seen.py sync`) |
| Много лишнего | отмечайте «не интересно» — в пятницу агент предложит правки; или сразу: «не интересно: тема» |
| Telegram молчит | приложение Claude было закрыто; проверьте `python tools/tg_bridge.py check` |
