Агент на Claude: от папки до первого результата

Одна инструкция для любого кейса — Обозреватель, База знаний, Встреча, Входящие, Документ-инженер, Личный ассистент — и для своего агента. Шаги одинаковые; отличается только то, что вы скажете агенту после настройки.

Подробное руководство по каждому кейсу (снимки окон, все варианты, разбор ошибок) — по ссылкам в таблице ниже. Здесь — короткий путь.

1Принцип за минуту

Кейс — это папка. Claude становится нужным агентом, потому что в начале разговора читает правила из этой папки. Всё, что агент узнал о вас и сделал, он складывает в папку hub/ внутри неё же.

Папка кейсаправила CLAUDE.md и playbooks/, скрипты, учебные данные
→
Claude Codeоткрыт в этой папке, читает правила
→
«настрой»агент расспрашивает вас и создаёт hub/ с профилем
→
Работавы пишете обычной фразой, результат — в чате и в файлах hub/

Что лежит в папках и как выглядят исходные файлы — на странице «С чем будем работать?».

3Пять шагов — одинаковые для любого кейса

1

Скопируйте папку кейса в постоянное место

Из agent_practice\1_claude\ — например, в D:\Агенты\Входящие. На путь к папке потом будут настроены рутины, поэтому после настройки её не переносят.

2

Проверьте Python

В терминале: python --version — нужен 3.10 или новее. Нет — поставьте с python.org (на Windows галочка «Add python.exe to PATH») или попросите Claude на следующем шаге: «проверь Python и установи, если нет».

3

Откройте папку в Claude Code

Приложение Claude → вкладка Code → новая сессия → выберите скопированную папку. (В терминале — команда claude в этой папке.)

4

Напишите настрой

Обязательны два шага — рабочая папка и профиль, около 5 минут. Остальные (пробный запуск, страница, расписание, Telegram) можно отложить ответом «Позже» и вернуться словами продолжи настройку.

Хотите сначала посмотреть, как работает, — выберите учебный пример: агент загрузит вымышленные данные из demo/.

5

Первая рабочая фраза

Из таблицы выше. Первый результат готовится 3–5 минут: агент читает материалы, сверяет, проверяет себя. Пока ждёте — откройте в проводнике hub/ и посмотрите, что агент записал о вас в profile.md, или откройте второй кейс в новой сессии.

Разрешения. Claude спрашивает разрешение на команды python tools/… — это скрипты кейса, разрешайте. Если увидите «публикацию заблокировал автоматический режим разрешений», переключите режим разрешений с автоматического на обычный (в терминале — Shift+Tab) и скажите опубликуй страницу: публикация — действие наружу, поэтому её подтверждаете вы.

4Свой агент

На основе похожего кейса

Скопируйте кейс, который ближе всего к вашей задаче, откройте его в Claude Code и напишите:

Переделай этот кейс под мою задачу: [что агент делает, на каких
материалах, что отдаёт]. Правила меняй в playbooks/, затем
пересобери: python tools/build.py

Устройство остаётся тем же — меняются правила роли.

С нуля

Создайте пустую папку, откройте её в Claude Code и напишите:

Сделай в этой папке агента: [роль], работает с [материалы],
результат — [что и в каком виде]. Правила запиши в CLAUDE.md,
мои данные веди в папке hub/. Начни с вопросов ко мне.

Это тот же принцип в минимальном виде: правила + папка с данными.

6Подробнее — по желанию

Другие способы: Cowork и Проект в claude.ai
СредаЧто этоЧего нет
Claude Code (основной путь)агент работает с папкой на вашем компьютере—
Coworkагент в приложении Claude; правила приходят плагином из dist/*.plugin кейсаскриптов Python, субагентов (проходы идут по очереди), своего бота Telegram
Проект в чате claude.aiинструкция из prompts/ кейса вставляется в Проектпамяти в файлах, страницы, расписания — только «попробовать идею»

Как поставить каждый вариант — в руководстве кейса, раздел «Установка».
