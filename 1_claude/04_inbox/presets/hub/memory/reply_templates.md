# Шаблоны ответов

Основа для коротких ответов (2–5 предложений). Составитель подставляет факты письма и ничего не обещает сверх них.
В фигурных скобках — то, что берётся из письма, профиля или памяти; нет данных — фраза с этой подстановкой не используется.
Поправьте формулировки под себя: агент будет писать вашими словами.

## Тон
- Руководству и официальным организациям — формально, по имени-отчеству (если оно есть в памяти).
- Коллегам — по-деловому, коротко, без канцелярита.
- Студентам и соискателям — доброжелательно и прямо.
- На незапрошенные коммерческие предложения — вежливо, одна-две фразы.

## Шаблоны
| Случай | Текст |
|---|---|
| Подтвердить получение поручения | {обращение}, добрый день. Задачу приняла, {что будет сделано} подготовлю к {срок из письма}. |
| Нужно время на решение | {обращение}, добрый день. Спасибо, письмо получила. Мне нужно {что уточнить}; вернусь с ответом до {дата}. |
| Уточнить срок или детали | {обращение}, добрый день. Уточните, пожалуйста: {вопрос}? После этого сразу займусь. |
| Согласовать | {обращение}, добрый день. {Что} согласовываю. {Следующий шаг, если он назван в письме}. |
| Попросить правки | {обращение}, добрый день. В текущей редакции согласовать не могу: {причина}. Прошу {что изменить}. |
| Принять приглашение | {обращение}, добрый день. Спасибо за приглашение, с удовольствием приму участие. Пришлите, пожалуйста, {что нужно}. |
| Вежливо отказать | {обращение}, добрый день. Спасибо за предложение. К сожалению, сейчас принять его не могу. Буду рада вернуться к разговору позже. |
| Переадресовать | {обращение}, добрый день. Этим вопросом занимается {кто — только из профиля или памяти}; передаю письмо ему. |
| Ответ студенту или соискателю | {обращение}, здравствуйте! Спасибо за интерес к нашему направлению. Пришлите, пожалуйста, {резюме / детали} — я посмотрю и вернусь с ответом. |
