# Шпаргалка промптов по уровням

В фигурных скобках — то, что подставляете вы. Фразы для Cowork и Claude Code можно говорить короче: правила уже в навыке `docs`.

## L1. Чат: документ по шаблону

```
Ты собираешь документ по фиксированному шаблону. Вход: данные ниже + шаблон «{ТИП}».
Заполни каждый раздел шаблона данными, ничего не выдумывая. Соблюдай структуру шаблона буквально:
те же разделы, тот же порядок, те же названия полей. Нет значения — поставь [НЕТ ДАННЫХ: что именно].
Верни готовый документ и список того, чего не хватило.

Данные:
{ДАННЫЕ}
```

Формула Excel (любая среда):

```
Нужна формула Excel. Таблица: столбцы {A — исполнитель, B — дата, C — часы}. Нужно: {сумма часов по исполнителю за месяц}.
Дай формулу для русской версии Excel, объясни каждую часть и покажи проверку на трёх строках примера.
```

## L2. Точечная правка с доказательством (Claude Code)

```
В документе {файл} замени раздел «{название раздела}» на текст из {файл с правкой}.
Остальное не трогай. Покажи отчёт проверки целостности: что изменено и сколько разделов без изменений.
```

```
Коллега прислал новую редакцию: {файл}. Исходник: {файл}. Менять разрешалось только раздел «{название}».
Проверь и перечисли всё, что изменено вне этого раздела. Ничего не исправляй.
```

В чате (без доказательства целостности):

```
Ниже раздел документа. Внеси правку: {что изменить}. Верни только новую редакцию этого раздела
и отдельным списком — что именно изменено. Ничего другого не меняй и не улучшай.
{ТЕКСТ РАЗДЕЛА}
```

## L3. Конвейер, версии, заявки

```
Собери {отчёт} по шаблону {шаблон} из {выгрузка}. Покажи, откуда взято каждое значение,
проверь числа по выгрузке, сохрани версию.
```

```
Что изменилось между версиями {2} и {3} документа {название}? По разделам, словами. Потом сделай страницу сравнения.
```

```
Действующая версия документа {название} — {третья}.
```

Cowork — подать заявку для Claude Code:

```
Оформи заявку для Claude Code: в {файл} обновить раздел «{название}», новый текст — {файл или текст ниже}. Срок — {дата}.
```

## L4. Страница, расписание, бот

```
Опубликуй страницу документов.        Сверь страницу документов.
Поставь на расписание набор минимум.   Подключи телеграм.
Отправь мне в телеграм файл {имя} — да, именно его.
```

Боту в Telegram (текст + файл по желанию):

```
Обнови раздел «Сроки согласования» в регламенте: срок 3 рабочих дня. Остальное не трогать.
```

## L5. Инженерный

```
Где в действующих версиях документов сказано про {срочное согласование}? Назови документ, версию и раздел.
Прогони проверочные случаи конвейера и покажи таблицу.
Добавь проверочный случай: {добавлен новый раздел без разрешения} — проверка должна упасть.
Создай навык для моего шаблона {название}: какие данные нужны, откуда их брать, что проверять.
```

## Формат ответа, который стоит требовать всегда

```
ЗАДАЧА → КАК РАБОТАЛ → РЕЗУЛЬТАТ → ЧТО ОСТАЁТСЯ ЧЕЛОВЕКУ
```
