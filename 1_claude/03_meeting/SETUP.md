# Кейс «Подготовка к встрече»: установка и настройка

Эта инструкция — для человека. Агент ведёт настройку сам, в чате, по одному шагу; сюда заглядывают, когда нужно
понять, что происходит, или что-то пошло не так.

## 1. Выберите, где будете работать

| | А. Claude Code | Б. Cowork (плагин) | В. Чат claude.ai (Проект) |
|---|---|---|---|
| Что нужно | приложение Claude с вкладкой Code, Python 3.9+ | приложение Claude с Cowork | только браузер или телефон |
| Уровни | L1–L5 | L2 и часть L4 | L1 |
| Время на запуск | 10 минут | 5 минут | 5 минут |

Не знаете, что выбрать: начните с **В** (сразу виден результат), затем переходите на **А**.

## 2. Вариант А. Claude Code — полная версия

1. Скопируйте папку `03_meeting` целиком в удобное место, например `Документы/Встречи`. Папка самодостаточна.
2. Откройте терминал в этой папке и выполните:
   ```
   python tools/build.py
   python tools/setup.py
   ```
   Первая команда собирает субагентов и навыки, вторая создаёт папку `hub` — вашу рабочую шину (календарь, задачи, досье).
3. Откройте папку в Claude Code и напишите: **«настрой»**. Мастер задаст вопросы формами. Обязательных шагов два
   (среда и профиль, около 4 минут); остальные можно отложить.
4. Напишите **«покажи на примере»** — агент подготовит бриф и мемо на учебном наборе.

## 3. Вариант Б. Cowork — плагин

1. В папке кейса есть готовый файл `dist/hq-meeting.plugin` (если нет — его создаёт `python tools/build.py`).
2. В приложении Claude: Cowork → «Настроить» (или Настройки → Плагины) → «Загрузить плагин» → выберите этот файл.
3. Создайте пустую папку, например `Документы/Встречи`, выберите её рабочей папкой и напишите **«настрой»**.

**Что в Cowork урезано — честно:**

| Чего нет | Что вместо этого |
|---|---|
| Субагентов: четыре роли брифа не работают параллельно и независимо | один агент делает четыре прохода по очереди; проверка — отдельным проходом, но той же моделью |
| Скриптов Python (`meetings.py`) | встречи без брифа и просроченные задачи агент находит чтением таблиц; печатной версии A4 и автоматической приёмки `check`/`eval` нет |
| Моста Telegram | заметки вставляете в чат; бот — только в Claude Code |
| Навыков `tavily-research`, `skill-creator` | встроенный веб-поиск; свой навык — в Claude Code |
| Рутин со скриптами (`meet-tg-pull`) | рутины `meet-eve`, `meet-memo`, `meet-weekly` работают, если в вашей версии есть задачи по расписанию |

## 4. Вариант В. Чат claude.ai — без папки (уровень L1)

Откройте `prompts/L1_инструкция_для_проекта.md` и следуйте ей: создать Проект, вставить инструкцию, приложить материалы.
Календаря, таблицы задач и расписания в этом варианте нет — мемо и задачи агент отдаёт блоком «Сохранить».

## 5. Шаги настройки (варианты А и Б)

| Шаг | Обязательность | Время | Что происходит |
|---|---|---|---|
| 0. Папка и среда | обязательный | 1 мин | агент проверяет, что доступно, и записывает таблицу «возможность → есть/нет → чем заменено» в `hub/setup.md` |
| 1. Профиль | обязательный | 2–3 мин | роль, с кем встречаетесь, тон писем и **что нельзя обещать без согласования** — это попадёт в каждый бриф |
| 2. Календарь и досье | по желанию | 2–5 мин | встречи называете в чате или подключаете календарь (только чтение) |
| 3. Telegram-бот | по желанию, только Code | 5 мин | раздел 6 |
| 4. Расписание | по желанию | 2 мин | раздел 8 |
| 5. Страница «Встречи» | по желанию | 1 мин | раздел 7 |
| 6. Пробный запуск | по желанию | 5–10 мин | бриф и мемо на учебном наборе, сравнение с эталоном |

Вернуться к отложенному: «продолжи настройку». Посмотреть состояние: «что ещё не настроено» или `python tools/setup.py status`.

**Адаптивная установка.** Если чего-то в вашей среде нет, агент не останавливается, а заменяет: нет субагентов —
делает роли по очереди; нет веб-поиска — бриф только по вашим материалам; нет расписания — записывает рутины как
`не включена` и вы запускаете их фразой; нет публикации — страницу можно открыть с диска в учебном режиме.

## 6. Свой Telegram-бот (Claude Code)

Бот нужен для двух вещей: получить накануне выжимку брифа и надиктовать заметки сразу после встречи.

1. В Telegram откройте чат **@BotFather** → `/newbot` → имя (например, «Мои встречи») → адрес, оканчивающийся на `bot`.
   BotFather пришлёт токен. **Никому его не показывайте и в чат с агентом не присылайте.**
2. `python tools/tg_bridge.py init` — создаст файл `hub/.secrets/telegram.json`. Откройте его **сами** в Блокноте,
   вставьте токен между кавычками в строке `"token": ""` и сохраните. Агент этот файл не читает и не показывает.
3. `python tools/tg_bridge.py check` — должен ответить именем вашего бота.
4. Отправьте боту `/start`, затем `python tools/tg_bridge.py whoami` — покажет ваш номер. Впишите его в поле
   `owner_id` того же файла: бот будет слушать только вас.
5. Сценарии: вы → боту — заметки после встречи, «встреча с … в четверг в 15:00», пересланное письмо контрагента;
   бот → вам — выжимка брифа накануне, напоминание о мемо, сводка задач в пятницу.
6. Чтобы сообщения забирались сами — включите рутину `meet-tg-pull` (раздел 8).

Ограничения: бот отвечает не мгновенно (сообщения забираются по расписанию или когда открыт Claude Code); голосовые
сохраняются файлом, но не расшифровываются — пользуйтесь диктовкой на клавиатуре телефона. Контрагентам бот не пишет.

**В Cowork мост не работает** (нет Python и доступа в сеть из скриптов). Альтернатива для опытных — официальный
плагин `telegram` (уровень L5): в Claude Code `/plugin install telegram@claude-plugins-official`; он передаёт
сообщения в открытую сессию Claude Code. Свой мост проще и не требует открытой сессии для приёма.

## 7. Страница «Встречи»

Страница показывает ближайшие встречи с готовностью брифа, чек-лист подготовки, задачи из встреч и контрагентов.
На ней можно отмечать пункты, вписать заметки после встречи и нажать «Оформить мемо сейчас».

- **Посмотреть без публикации:** откройте `artifacts/meetings.html` двойным щелчком — страница запустится в учебном
  режиме с вымышленными данными (ничего не сохраняет).
- **Опубликовать:** скажите агенту «опубликуй страницу встреч». Он опубликует её как вашу личную страницу в claude.ai,
  запишет ссылку в `hub/artifacts.md` и заполнит данными с шины. Страницу видите только вы; доступ другим открываете вы сами.
- **Сверка:** «сверь страницу встреч» — агент переносит ваши отметки со страницы на шину и обновляет страницу.
- Нет инструмента публикации — пользуйтесь чатом и печатной версией брифа.

## 8. Расписание

| Набор | Что входит | Когда |
|---|---|---|
| Минимум | `meet-eve` — бриф накануне встречи | будни, 17:00 |
| Стандарт | + `meet-memo` — напоминание оформить мемо; `meet-weekly` — контроль задач из встреч | будни 18:30; пятница 16:00 |
| С каналами | + `meet-tg-pull` — забрать сообщения бота; `meet-cal-pull` — сверить календарь (только чтение) | каждые 20 минут днём; будни 8:00 |

Скажите «включи расписание» — агент покажет таблицу и создаст задачи после вашего «да». Задачи выполняются, пока
приложение Claude открыто на компьютере. Посмотреть и отключить: «какие рутины включены», «отключи meet-memo»,
а также раздел «Запланированные» в приложении. Нет инструмента расписания — те же действия запускаются фразами из `GUIDE.md`.

|---|---|---|---|

| `internal-comms` | приёмы письма по итогам встречи: сначала решения, затем «кто — что — срок» | нет | черновик в `hub/inbox/drafts/` начинается с решений |

## 10. Проверка «всё работает»

| Что проверяем | Команда или фраза | Что должно быть |
|---|---|---|
| Сборка | `python tools/build.py` | строка «Версия … плагин: dist/hq-meeting.plugin» |
| Шина | `python tools/setup.py status` | список шагов с отметками |
| Учебный набор | `python tools/demo.py load` | «файлов добавлено 6, строк календаря 2, строк задач 4» |
| Встречи без брифа | `python tools/meetings.py upcoming --today 2026-10-06` | встреча 07.10 с пометкой «БЕЗ БРИФА» |
| Контроль задач | `python tools/meetings.py tasks --today 2026-10-06` | три просроченные задачи |
| Бриф | «Сегодня 6 октября 2026. Подготовь бриф к встрече с Северным контуром» | бриф с 9 разделами и пометками `[РЕШИТЬ]` |
| Приёмка | `python tools/meetings.py check hub/meetings/2026-10-07_северный-контур_бриф.md`, затем `eval` с тем же файлом | «ПРИНЯТО по форме»; не меньше 80% |
| Telegram (если подключали) | `python tools/tg_bridge.py check` | имя бота; без токена — понятная подсказка, что сделать |
| Страница | открыть `artifacts/meetings.html` | плашка «Учебный режим», три вкладки |
| Уборка | `python tools/demo.py clean` | учебные файлы и строки убраны |

В Cowork проверка — три фразы: «что ещё не настроено», «покажи на примере», «задачи из встреч».

## 11. Если что-то пошло не так

- **«python не найден»** — установите Python с python.org (галочка «Add to PATH») или работайте в варианте Б.
- **Вместо русских букв — знаки вопроса** — в терминале выполните `chcp 65001` или запускайте команды через агента.
- **Агент не видит навыков и субагентов** — выполните `python tools/build.py` и откройте папку в Claude Code заново.
- **`Нет папки hub/`** — выполните `python tools/setup.py`.
- **Бот молчит** — `python tools/tg_bridge.py check`; проверьте, что токен вставлен без пробелов и что вы отправили боту `/start`.
- **Бриф получился на две страницы** — «сократи до 500 слов, оставь факты с источниками».
- **Начать заново** — переименуйте папку `hub` (не удаляйте: в ней ваши данные) и выполните `python tools/setup.py`.

## 12. Где ваши данные

Всё ваше — в папке `hub` внутри папки кейса; она не попадает в git (исключена в `.gitignore` учебного каталога).
Токен бота — в `hub/.secrets/`. Перенос на другой компьютер — скопировать папку кейса вместе с `hub`.
Переход на комплексного ассистента (кейс 6) — см. `README.md`, раздел «Как вырасти до комплексного ассистента».
