# Рубрика приёмки: бриф и мемо

Этой рубрикой проверяют результат трое: вы сами, скрипт (`meetings.py check` и `eval` — форма и обязательные факты)
и независимый проверяющий — субагент `meeting-checker` (соответствие источникам). Баллы: 2 — выполнено; 1 — частично; 0 — нет.

## Бриф (максимум 20)

| № | Критерий | Как проверить | 0 / 1 / 2 |
|---|---|---|---|
| 1 | Одна страница: не больше 500 слов, 9 разделов | `python tools/meetings.py check ФАЙЛ` | |
| 2 | «Главное» — ровно 5 строк, по ним одним можно идти на встречу | прочитать только их | |
| 3 | У каждого числа, срока и имени есть источник | выбрать 5 фактов наугад и открыть источник | |
| 4 | Найдены расхождения между источниками (на учебном наборе — письма Лебедева и Котовой) | раздел «Интересы сторон», «Главное» | |
| 5 | Показаны невыполненные обещания обеих сторон, в том числе наши | «История отношений» | |
| 6 | Интересы участников названы предположениями, а не фактами | слово «предположение» рядом | |
| 7 | Карта возражений: не меньше трёх возражений, у каждого ответ с опорой | таблица | |
| 8 | «Что нельзя обещать» выведено из решений и профиля, а не придумано | ссылки в разделе | |
| 9 | Чего нет в материалах — в «Не подтверждено» или `[РЕШИТЬ]`, а не досочинено | поискать «лишние» факты | |
| 10 | Вопросы идут от самого важного и требуют ответа по существу | раздел «Вопросы» | |

## Мемо и всё, что после встречи (максимум 20)

| № | Критерий | Как проверить | 0 / 1 / 2 |
|---|---|---|---|
| 1 | Решения отделены от обсуждений: «посмотрим», «подумаю» — в открытых вопросах | разделы «Решения», «Открытые вопросы» | |
| 2 | У каждой задачи — кто, что, срок датой; «до пятницы» превращено в дату | таблица задач; `meetings.py check` | |
| 3 | Срок, которого не называли, не выдуман («срок не назван») | задача Арсеньева | |
| 4 | Сверка с брифом: что из «нельзя обещать» соблюдено, что нарушено | раздел «Сверка с брифом» | |
| 5 | Сверка с прошлой встречей: старые обещания не пропали молча | там же; `meetings.py tasks` | |
| 6 | Задачи дописаны в `hub/tasks.md` со ссылкой на мемо; строки не удалены | открыть таблицу | |
| 7 | Досье дополнено, а не переписано | сравнить с исходным | |
| 8 | Письмо — черновик в `hub/inbox/drafts/`, не отправлено; в нём нет внутренних задач и необещанного | открыть черновик | |
| 9 | Календарь: встреча `проведена`, ссылка на мемо, следующая встреча добавлена | `hub/calendar.md` | |
| 10 | В ответе агента есть «Что остаётся человеку» и строка в бортжурнале | чат, `hub/journal.md` | |

## Порог

- **Принято:** не меньше 16 из 20 и ни одного нуля в критериях 3 и 9 брифа, 1–3 мемо (это критерии «не выдумывать»).
- **Скрипт:** `python tools/meetings.py eval ФАЙЛ` — не меньше 80% проверок из `demo/evals.json`.
- Скрипт проверяет наличие фактов, но не их правильность: 100% у скрипта при нуле в критерии 3 — это «не принято».

## Как записать результат

Строка в `hub/journal.md`: `| дата | приёмка | бриф 18/20, eval 93%; мемо 17/20, eval 86%; замечания: … | … |`.
Сравнивайте не «похоже ли на эталон слово в слово», а «нашёл ли агент то же самое»: эталон — один из верных ответов.
