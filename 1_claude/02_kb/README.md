# Кейс 2. База знаний / «второй мозг»

Личный агент **Библиотекарь**: отвечает на вопросы **строго по вашим материалам** — со ссылкой на заметку и раздел.
Чего в базе нет, так и говорит: «в базе этого нет». Новые материалы сам оформляет в заметки, связывает их между собой
и записывает расхождения в журнал противоречий. Какая версия верна, решаете только вы.

**Для кого.** Руководители и специалисты, у которых регламенты, протоколы и договорённости разбросаны по файлам и чатам.
Программировать не нужно: всё общение — в чате Claude.

Все учебные данные вымышлены. Свои документы с персональными данными, коммерческой тайной и грифом в базу не кладите.

## Как это устроено

```
 вы в чате: вопрос ─────────────► Библиотекарь ──► ответ со ссылками ──► Проверяющий ──► вам
 вы: «запомни…», файл, бот ──► hub/kb/входящее/ ──► заметка по шаблону + связи [[…]]
                                                      │
                                расхождение фактов ──► hub/kb/_противоречия.md ──► решаете вы
                                                      │
 страница «База знаний» ◄── сверка ──► файлы hub/ (источник правды) ◄── Obsidian (по желанию)
```

- **База `hub/kb/`** — «что известно»: заметки с источниками. Только из неё берутся ответы.
- **Память `hub/memory/`** — «как вы говорите»: сокращения, прозвища, имена. Помогает понять вопрос, но фактом не служит.
- **Страница «База знаний»** (`artifacts/kb.html`) — обзор, противоречия с кнопками «Верно А / Верно Б / Обе устарели»,
  карта связей, журнал вопросов, список ухода. Полных текстов заметок на странице нет.
- **Бот Telegram** — «запомни …» и пересланное попадают во входящее; вопрос — ответ со ссылкой; по пятницам сводка.

## Где что работает

| Возможность | Claude Code на компьютере | Cowork (плагин `hq-kb`) | Чат claude.ai без папки |
|---|---|---|---|
| Ответ строго по материалам со ссылкой | да | да | да (Проект, уровень L1) |
| Поиск по базе | локальный индекс (FTS5) | чтением файлов — на большой базе медленнее | по материалам Проекта |
| Независимая проверка ответа | субагент `kb-verifier` | второй проход того же агента | нет |
| Заметки по шаблонам, связи, противоречия | да | да | нет — только текст заметки в чат |
| Словарь памяти | да | да | нет |
| Уход за базой (битые ссылки, дубли, без связей) | скриптом | проходом агента вручную | нет |
| Страница «База знаний» | да | да, если доступна публикация страниц | нет |
| Рутины по расписанию | все пять | только разбор входящего, если есть расписание | нет |
| Бот Telegram | да | нет: мосту нужен Python | нет |
| Учебные примеры одной командой | да | копированием из `demo/hub/` | загрузить файлы в Проект |

Что в Cowork недоступно, агент оформляет заявкой в `hub/handoff/` с пометкой `needs: code` — её выполнит Claude Code.

## Уровни

| Уровень | Что добавляется | Где работает | Признак «уровень взят» |
|---|---|---|---|
| L1. Проект | ответы по загруженным материалам со ссылкой | чат claude.ai | три вопроса: ссылка, две версии, «в базе нет» |
| L2. Папка и Obsidian | рабочая папка, поиск, ссылки `[[…]]`, рубрика приёмки, страница в учебном режиме | Cowork, Claude Code | пять вопросов набора совпали с эталоном |
| L3. Агент ведёт базу | входящее, шаблоны, связи, противоречия, словарь памяти, Проверяющий, уход | Cowork (урезано), Claude Code | новая заметка связана, противоречие поймано и закрыто вами |
| L4. Живёт сам | рутины, бот Telegram, страница с хранилищем, правила доступа | Claude Code (бот и часть рутин — только он) | решение со страницы дошло до файлов; бот ответил со ссылкой |
| L5. Инженерный | проверочные вопросы, свой навык, хуки и разрешения, свой источник через MCP, метрики | Claude Code | изменение подтверждено прогоном на эталоне |

Задания и критерии — в [LEVELS.md](LEVELS.md).

## С чего начать

Новичку: откройте двойным щелчком **[START.html](START.html)** — пошаговое руководство с картинками: установка, настройка, типовые запросы.

1. Установка — [SETUP.md](SETUP.md): Claude Code (полный вариант), Cowork (плагин) или Проект claude.ai.
2. Напишите в чат `настрой` — агент проведёт по шагам с формами. Обязательны два шага, около 5 минут.
3. Фразы на каждый день — [GUIDE.md](GUIDE.md). Готовые промпты — [prompts/шпаргалка_промптов.md](prompts/шпаргалка_промптов.md).

## Что в папке

| Путь | Что это |
|---|---|
| `playbooks/` | правила агента — единый источник, из него собирается всё остальное |
| `tools/` | скрипты (только стандартная библиотека Python): `setup.py`, `demo.py`, `kb_index.py` (поиск), `kb_lint.py` (уход, сводка), `kb_map.py` (карта для страницы), `kb_eval.py` (проверка поиска), `tg_bridge.py` (бот), `build.py` (сборка) |
| `presets/hub/` | заготовки рабочей папки, шаблоны заметок, настройки Obsidian |
| `demo/` | учебный набор (10 документов, одно противоречие) и эталонный результат |
| `artifacts/kb.html` | шаблон страницы; открытый с диска показывает учебные данные |
| `prompts/` | инструкция для Проекта claude.ai (L1) и шпаргалка промптов |
| `pack/` | навыки пака (сторонние; лицензии — `pack/THIRD_PARTY.md`) |
| `.claude/`, `cowork-plugin/`, `dist/` | собирает `python tools/build.py`; руками не править |
| `hub/` | ваша рабочая папка; появляется при настройке, в git не попадает |

## Как вырасти до комплексного ассистента

Рабочая папка `hub/` этого кейса устроена так же, как у комплексного ассистента (кейс 6, `06_assistant`): те же имена
и форматы `kb/`, `memory/`, `_противоречия.md`, `journal.md`, `handoff/`. Поэтому переход — это копирование.

1. Установите ассистента по `06_assistant/SETUP.md` и пройдите его обязательные шаги.
2. Закройте разговоры с Библиотекарем. Скопируйте содержимое своей `hub/` в `hub/` папки ассистента:
   **новые файлы добавлять, существующие не заменять**.
3. Не переносите `hub/.secrets/`, `hub/setup.md`, `hub/routines.md`, `hub/artifacts.md` — у ассистента они свои.
   `_вопросы.md` и `_уход.md` можно перенести: ассистент их не использует, но и не тронет.
4. Строки общих таблиц (`kb/_противоречия.md`, `memory/glossary.md`, `journal.md`) копированием не объединяются:
   попросите ассистента «перенеси строки из файла кейса» и приложите файл.
5. Отключите рутины этого кейса (`kb-…`), иначе одна работа будет выполняться дважды. У ассистента свои рутины и своя
   доска: на её вкладке «База» те же противоречия с теми же кнопками.
6. В папке ассистента скажите: «проверь, всё ли на месте в hub, и обнови индекс базы знаний».

## Если хотите доработать кейс

Правьте `playbooks/` и таблицы в `tools/build.py`, затем `python tools/build.py`. Папку `pack/` наполняет
`python skills_pack/sync.py` из корня `agent_practice`.
