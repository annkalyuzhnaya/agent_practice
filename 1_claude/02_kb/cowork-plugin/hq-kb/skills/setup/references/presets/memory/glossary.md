# Словарь памяти

«Как я говорю»: сокращения, прозвища, внутренние названия. По нему агент понимает ваши вопросы и заметки.
Фактов здесь нет: сроки, суммы и решения лежат в базе (`kb/`) — с источниками.
Подробности о людях — в `memory/people/`, о компании и командах — в `memory/context/`.
