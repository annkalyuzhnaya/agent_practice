# Ассистент — главная

Это хранилище — шина личного ассистента. Писать сюда можно: быстрые заметки кладите в `kb/входящее/`, остальное ведут агенты.

## Каждый день
- [[tasks|Задачи на контроле]]
- [[inbox/mail|Обзор почты]]
- [[calendar|Встречи]]
- [[_противоречия|Противоречия — ждут моего решения]]
- Планы дня — папка `plan/` (последний — внизу списка)
- Дайджесты — папка `digest/`

## База знаний
- `kb/контрагенты/` — по одной заметке на компанию или человека
- `kb/решения/` — решения, протоколы, договорённости
- `kb/проекты/` — обзорные заметки по проектам со ссылками на всё связанное
- `kb/публикации/` — важное из дайджестов
- `kb/справки/` — регламенты, справочная информация
- `kb/входящее/` — мои быстрые заметки, которые Библиотекарь ещё не разобрал
