# Обзор почты

Одна строка на письмо или сообщение. Статусы: `новое` → `ответ утверждён` → `отправлено` / `в черновиках почты` / `игнор`; для писем, где ответ не нужен, — `без ответа`. Ответы предлагает агент, утверждает владелец (на вкладке «Почта» доски или в чате); письмо уходит, только когда владелец нажал «Отправить» на доске, — иначе ответ ложится в черновики почты.
