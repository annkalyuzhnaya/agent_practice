# Учётные записи и каналы

Что подключено к ассистенту и что агентам разрешено. Паролей и токенов здесь нет и быть не должно.

| Канал | Как подключён | Статус | Что агентам разрешено | Забрано до |
|---|---|---|---|---|
| Личная почта | | не подключено | читать, раскладывать на шину, создавать черновики; не отправлять, не удалять, не менять метки и фильтры | |
| Telegram | | не подключено | забирать пересланное боту; писать владельцу; в группы из списка — только после «да» на точный текст | |
| Календарь | | не подключено | только чтение | |
| Облачный диск | | не подключено | читать указанные папки; файлы не менять и не удалять | |
