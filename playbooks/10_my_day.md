# Плейбук «Мой день» — комплексный сценарий

Оркестратор: запускает агентов в правильном порядке и собирает из их результатов один план дня.
Каждый шаг выполняется по своему плейбуку; данные между шагами идут через шину `hub/`.

```
           ┌──────────────┐      ┌──────────────┐
           │ 1 Обозреватель│      │ 2 Входящие    │   (шаги 1 и 2 независимы — в Claude Code параллельно)
           │  веб → дайджест│     │ классификатор │
           └──────┬───────┘      │ → составитель  │
                  │              │ → приоритизатор│
                  │              └──┬───┬───┬────┘
                  │       встречи   │   │   │ заявки на документы
                  │   ┌─────────────┘   │   └──────────────┐
                  │   ▼                 ▼ задачи            ▼
                  │ ┌──────────┐   tasks.md         ┌───────────────┐
                  │ │3 Встреча  │                    │4 Документ-     │ (скрипты: только Claude Code;
                  │ │ бриф      │                    │  инженер       │  в Cowork заявка ждёт в handoff/)
                  │ └────┬─────┘                    └──────┬────────┘
                  ▼      ▼                                 ▼
               ┌────────────────────────────────────────────────┐
               │ 5 Библиотекарь: заметки, связи, противоречия     │
               └───────────────────────┬────────────────────────┘
                                       ▼
                         6 План дня → человек решает
```

## Шаги

0. **Осмотр шины.** Забери новое из подключённых каналов (`hub/accounts.md`) и ответы человека с доски (сверка «со страницы на шину» по `13_artifacts.md`). Прочитай `hub/profile.md`, `hub/tasks.md`, `hub/calendar.md`, заявки `status: new` в `hub/handoff/`, последний план в `hub/plan/` (нет — это первый запуск, иди дальше). Определи среду: команда `python --version` работает и рядом есть папка `tools/` — полный режим (Claude Code); иначе — режим без скриптов (Cowork).
1. **Обозреватель** (плейбук №1). Пропусти, если дайджест за сегодня уже есть или в профиле нет тем. Заметки в базу он здесь не создаёт — это шаг 5.
2. **Входящие** (плейбук №4): три роли подряд. Пропусти, если `hub/inbox/new/` пуст.
3. **Встреча** (плейбук №3, режим А) — для каждой встречи из `hub/calendar.md` в ближайшие 3 дня (сегодня и два следующих), по которой ещё нет брифа. Учитывай свежий разбор входящих; просмотри сегодняшний дайджест — публикации по контрагенту или теме встречи добавь в бриф.
4. **Документ-инженер** (плейбук №5) — по каждой заявке `to: docs`. Нет скриптов — оставь заявку `new` и отметь в плане «ждёт Claude Code».
5. **Библиотекарь** (плейбук №2, режим Б) — принять всё созданное на шагах 1–4 (включая публикации дайджеста с оценкой 4–5 и заявки `to: kb`), проставить связи, проверить противоречия. В полном режиме в конце пересобери индекс: `python tools/kb_index.py build`.
6. **План дня** `hub/plan/ГГГГ-ММ-ДД.md`:
   - **Главное за 30 секунд** — 3 строки.
   - **Сегодня / На неделе / Делегировать** — из разбора входящих и `tasks.md` (в т.ч. просроченные задачи).
   - **Требует моего решения** — все `[РЕШИТЬ]`, открытые противоречия, выбор действующей версии документов.
   - **Встречи** — ссылки на брифы.
   - **Почта** — сколько писем ждут ответа и какие из них срочные; сами ответы — в `hub/inbox/mail.md` и на вкладке «Почта».
   - **Готовые документы** — ссылки.
   - **ТОП-3 дайджеста.**
   - **Ждёт другой среды** — заявки, которые не удалось выполнить здесь.
   - **Не выполнено и почему** — пропущенные шаги и сбои.
   - **Что остаётся человеку.**
7. **Бортжурнал** — одна строка в `hub/journal.md` по сценарию целиком (агенты шагов своих строк не пишут).
8. **Доска** — сверка по `13_artifacts.md`, если в `hub/artifacts.md` есть ссылка и доступен инструмент: задачи, обзор почты с готовыми ответами, встречи с брифами, дайджест и шапка «Главное за 30 секунд» попадают на страницу.

## Правила оркестратора
- В Claude Code шаги 1 и 2 запускай параллельно субагентами (`scout` и цепочка `inbox-classifier → inbox-drafter → inbox-prioritizer`); шаги 3–5 — после них. Субагентов с такими именами нет — выполни их роли сам по тем же плейбукам. В Cowork выполняй шаги последовательно сам.
- Агентам шагов сообщай, что они работают внутри «Моего дня»: заметки по дайджесту и строку журнала они не пишут.
- Сбой одного шага не останавливает сценарий: запиши в плане, что не выполнено и почему, и иди дальше.
- Сценарий можно запускать несколько раз в день: уже сделанное не переделывай, обрабатывай только новое.
- В итоговом сообщении покажи план прямо в чате: «Главное за 30 секунд», «Сегодня», «Требует моего решения» — полностью, остальное — по строке; путь к файлу плана — в конце. Дальше веди разговор по плейбуку `11_chat.md`: принимай решения человека и записывай их на шину.
