# Личный ассистент — папка-исходник

Это **исходник** системы «Личный ассистент»: правила, скрипты и заготовки. Ассистент здесь **не живёт** и личных данных
здесь нет. При первом запуске из исходника создаётся отдельная **папка ассистента** — в неё копируется система,
там появляется шина `hub/` с данными владельца, там идёт вся работа.

## Что делать, когда человек пишет в этой папке
1. **«Настрой ассистента», «начать», «первый запуск» или любая рабочая просьба** (письмо, встреча, «мой день»):
   выполни `python tools/install.py where`.
   - Ассистент ещё не установлен → веди **установку** по разделу «Установка из исходника» в `playbooks/12_setup.md`:
     приветствие, форма «Старт», форма «Папка», затем `python tools/install.py "путь"`.
   - Уже установлен → скажи одной строкой, где он живёт, и попроси открыть новую сессию в той папке. Рабочие просьбы
     здесь не выполняй и `hub/` здесь не создавай.
2. **«Обнови ассистента»** → `python tools/build.py`, затем `python tools/install.py` (обновит системные файлы
   в папке ассистента; `hub/` не трогает).
3. **Просьба доработать систему** (плейбуки, скрипты, инструкции) → работай как обычный инженер по правилам ниже.

Вопросы с выбором задавай формой (`AskUserQuestion`), а не сплошным текстом.
**Путь для папки ассистента всегда спрашивай сам** — формой «Папка»: предложи готовые пути (их печатает
`python tools/install.py`) и скажи, что свой путь можно вписать в «Другое». Не давай человеку команду установки
для самостоятельного запуска: получил ответ — запусти установку сам. В той же форме спроси, положить ли
учебные примеры (форма «Примеры»; «да» → ключ `--demo`).


## Что где лежит
- `playbooks/` — единственный источник правил агентов. `tools/build.py` собирает из них `.claude/agents/`, `.claude/skills/`,
  `cowork-plugin/personal-hq/` и `dist/personal-hq.plugin`. Сгенерированное руками не править.
- `presets/hub/` — заготовки шины для нового пользователя; `presets/home/CLAUDE.md` — правила для папки ассистента
  (там модель — оркестратор «Ассистент»).
- `tools/install.py` — установка и обновление папки ассистента; путь к ней хранится в `.install-target` (не в git).
- `tools/setup.py` — создаёт шину внутри папки ассистента (его вызывает установка).
- `SETUP.md` — инструкция по установке для человека, `GUIDE.md` — памятка «как пользоваться», `artifacts/hq.html` — шаблон доски.

## После правок
`python tools/build.py` → `claude plugin validate cowork-plugin/personal-hq` → `python tools/install.py` (если ассистент установлен).

## Жёсткие правила
- Личные данные (`hub/`) в исходнике не создавать и в git не добавлять.
- Папку ассистента правит только `tools/install.py`; её `hub/` из исходника не читать и не менять без просьбы владельца.
- Ничего не коммитить и не публиковать без просьбы. Токены и пароли в чат не просить.
