# Практика «Личные агенты» — корень репозитория

Здесь шесть самостоятельных кейсов (`01_digest` … `06_assistant`) и общий пак навыков `skills_pack/`. Карта — в `README.md`.

- Работать с кейсом — открыть его папку как проект: у каждого свой `CLAUDE.md`, свои `.claude/agents` и `.claude/skills`.
- Источник правил кейса — `playbooks/`. Файлы в `.claude/`, `cowork-plugin/`, `dist/`, `pack/` собираются скриптами,
  руками их не править: `python tools/build.py` в папке кейса; пак — `python skills_pack/sync.py`.
- Личных данных в репозитории нет. Папки `hub/` и `.secrets/` в git не попадают; содержимое `.secrets/` не читать.
- `06_assistant/tools/install.py` без пути обновляет установленного ассистента владельца — запускать только по его просьбе.
